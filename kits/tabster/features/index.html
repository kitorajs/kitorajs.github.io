    Each tile in arrange mode shows 5 hover-highlighted drop zones (top/right/bottom/left/center) so the directional outcome is visible before commit.

  • Per-group color chip

  • Default VSCode-style map

    Built-in shortcuts are `@kitora/keyboard` commands (`tabster.*`), so a host provider lists and remaps them; Close all is the chord Mod+K, then W. All overridable via the `keyboard` prop.

    live
  • Per-shortcut override

    Pass `{ closeTab: 'mod+x' }` etc. to remap any single action.

    live
  • Disable shortcuts

    Pass `keyboard={false}` to fully unbind — useful when embedded inside another keyboard-heavy UI.

    live
  • Command palette integration

    Tabster's keys are `tabster.*` commands, so a host `KeyboardProvider` lists them in its palette and cheatsheet. The dock's own `dock.*` commands (move tab to, float, pop out) come from `@kitora/dock/keyboard`, which Tabster does not install yet.

  • F6 region cycle

  • Adapter contract

    `TabsterAdapter` = `load() / save(snapshot) / clear?()`. Sync or async. Plug into localStorage, IndexedDB, OPFS, REST, GraphQL — anything.

    live
  • localStorage adapter

    `createLocalStorageAdapter({ key })` — namespace auto-prefixed, SSR-safe, catches quota / private-mode errors.

    live
  • In-memory adapter

    `createInMemoryAdapter({ initial })` for tests + Storybook + "wire your own persistence on top". Exposes `peek()` for assertions.

    live
  • Server-backed adapter recipe

    Docs include a fetch-based adapter template. Tabster catches reject/throw and falls back to `initialPanels` — restore can't crash the dock.

    live
  • Versioned snapshot schema

    `{ version, layout, meta? }` envelope. `version` prop declares current; bump on breaking changes.

    live
  • Migrator chain

    `migrators={{ 1: snap => v2(snap), 2: snap => v3(snap) }}` chains automatically from stored version → current. Missing / failing migrators discard the snapshot rather than crash.

    live
  • Auto-persist toggle

    `autoPersist` defaults to ON when an adapter is provided. Pause on `enterEditMode` so drafts don't leak into storage until Save.

    live
  • `onLayoutChange` / `onActiveChange` / `onRestore`

    Wire to breadcrumb, URL, analytics, save indicators. Fires after adapter restore on boot.

    live
  • Safe restore

    Bad JSON, schema-version mismatch → fall back to `initialPanels`; unknown components restore as a placeholder tab. Layouts saved under dockview are converted (`DOCKVIEW_MIGRATOR`). Never throws.

    live
  • Layouts saved under dockview

    Snapshots written before the move to `@kitora/dock` hold dockview JSON; `DOCKVIEW_MIGRATOR` converts grid, floating and popout groups on load and the next save writes the new shape.

    live
  • Imperative escape hatches

    `api.snapshot()` / `api.restore(snap)` / `api.persist()` / `api.reload()` for tests + manual control.

    live
  • Debounced saves

    `persistDebounceMs` prop coalesces a burst of layout events (drag-resize, multi-tab shuffle) into one adapter write. Default 0 = immediate. Pending save flushes on unmount so nothing is lost.

    live
  • Idempotent addPanel

    `api.addPanel({ id })` is a no-op if `id` already exists. React StrictMode double-effects + double-clicks don't throw "panel already exists".

    live
  • Group-name persistence

    Names registry currently in-memory only — survives within a session, lost on reload. Roll into snapshot.meta.

    planned
  • useEffect cleanup on close

    Panel components unmount when `api.removePanel(id)` runs — return a cleanup fn from `useEffect` to close terminal sessions, websockets, video, etc.

    live
  • `useTabsterPanel()` hook

    Inside any panel: returns `{ id, title, params, isActive, api }` from a React context wrapper (`api` is the dock's). No prop drilling required for deep children.

    live
  • `useTabsterPanelClose(fn)`

    Subscribe to your own panel's close from inside the panel. Built on `useEffect` cleanup with latest-handler ref. Pair with `renderer: "always"` so it fires only on real close, not tab switches.

    live
  • `useTabsterPanelVisible(fn)`

    Subscribe to your own panel's visibility — wire to `<Term>` resize, video pause, etc.

    live
  • `useTabsterPanelActive(fn)`

    Subscribe to focus/active changes for just this panel.

    live
  • `useTabsterContainerApi()`

    Convenience accessor for the dock's api — open a sibling tab from inside a panel without threading refs.

    live
  • onPanelClose callback

    App-level hook on TabsterProps — fires after every panel removal. Use for telemetry, etc. For per-panel logic, prefer `useTabsterPanelClose` inside the panel.

    live
  • `renderer: "always"`

    Per-panel + `defaultRenderer` prop. Keep the panel mounted across tab switches so terminals / iframes / video survive when not active. Default is `"onlyWhenVisible"`. Kept-alive panels move between groups without remounting (`moveBefore`).

    live
  • Per-panel error boundary

    One bad panel can't crash the dock. Render-time throws are caught and a small fallback ships with a Reset button that re-mounts the panel subtree. Override via TabsterProps.panelErrorFallback.

    live
  • Cancellable close

    Block the close until the user confirms unsaved changes. The dock has `beforeClose`; Tabster does not expose it as a prop yet.

    planned
  • Draft / committed split

    `api.enterEditMode()` snapshots current state and pauses auto-persist. User rearranges freely. `saveEditMode()` commits + persists; `discardEditMode()` restores the pre-edit snapshot.

    live
  • `isEditing()` query

    Read whether edit mode is active — wire to toolbar UI / dirty indicators.

    live
  • `data-editing` attribute

    Tabster sets `data-editing="true"` on its root while in edit mode — CSS can dim non-layout chrome to reinforce the mode change.

    live
  • Async save

    `saveEditMode()` returns a Promise — adapters that hit a server can resolve when commit lands. Edit-mode UI can show a spinner.

    live
  • Light / dark variants

    Pass `theme={{ name: 'light' | 'dark' | 'auto' }}` — `auto` follows the page, `dark` scopes the dark tokens to Tabster.

    live
  • CSS-var overrides

    The dock's `--dock-*` variables default to the Kitora tokens — restyle by overriding tokens.

    live
  • Custom theme class

    Wrap in a CSS scope and override `--dock-*` directly for fully bespoke skins (zero-specificity defaults, so a plain rule wins).

    live

  • State preserved on move

    The dock moves kept-alive panels with `moveBefore`, so React state, iframes, video and canvas survive a move where the browser has it (Chromium); elsewhere iframes reload.

    Tabs and strips drag after a touch long-press (a swipe still scrolls); larger sash targets under a coarse pointer. Proven by emulated touch headless; not checked on a phone.
