Kits

Composable headless kits, fully wired showcases.

Each kit is a package, @kitora/<name>, in layers: a headless core, DOM helpers, React hooks and styled parts, with an adapter wherever data comes from outside. The galleries below run every feature end to end, each with its code.

Core

The engines most apps are built around: data, forms, design languages, keys, drag and drop, docking, overlays and windows.

Datagrid

Adapter-driven datagrid — search, sort, cursor pagination, density, columns, bulk actions, group + virtual variants.

Form engine

Batteries-included forms — controlled store, typed paths, validation, derived, arrays, discriminated-union variants, async-search selects, composites, plugins. Build any form on one kernel.

Theme

Foundations and theming — OKLCH colour scales from one brand colour with contrast-checked pairs, radius, spacing, type and density scales, a ThemeProvider for light, dark, system and per-subtree themes, a live theme designer with CSS and Tailwind export, and a WCAG contrast checker.

Keyboard

A VS Code-grade keyboard system — typed command registry, chords, when-clauses, default / plugin / user keybinding layers, conflict analysis, IME and layout safety, focus-aware arbitration.

Drag and drop

From-scratch drag-and-drop on Pointer Events — sortable lists, grids, kanban, trees, multi-select, free canvas, virtualized 10k lists, tables, OS file drops, three keyboard models and screen-reader announcements.

Dock

Docking layouts in the Golden Layout / FlexLayout / react-mosaic class — n-ary splits with px limits, priorities and collapse, tab groups that reorder and close, layouts as plain JSON with a pure reducer, save and restore.

Overlay kit

One stack for every modal, sheet, popover and panel — kinds × surfaces, JSX / imperative / route drivers, close guards, typed results, return focus, anchors, specials.

Windows

Free-floating window manager in the WinBox / macOS / Windows style — move, resize from every edge, snap to halves and quarters, maximise and restore, z-order, saved layouts, touch and pen.

Sidebar

The application sidebar for power users — expanded panel, icon rail with flyouts, floating, inset and double sidebars, drag resize on the one splitter, nav tree with sections, favourites and drag reorder, badges, presence, menus, rename, mobile sheet.

Building blocks

Parts an app composes into its own screens.

Pickers

Date, time and colour pickers — typed-segment fields, calendars (single, multiple, range), range presets, month and year, date-time, time zones, an RRULE recurrence editor and a colour picker. Keyboard-first, Intl-localised, RTL.

Collections

One headless collection model with APG-correct Listbox, Select, Combobox (async search, create), MultiSelect, TagsInput, Menu with nested submenus, Menubar, ContextMenu, Toolbar, TreeView (async children, checkboxes), TreeSelect and Cascader. Virtual windows for 10,000 rows.

Feedback

Everything an app says back — toasts with a queue, stacking, swipe, pause on hover, undo and promise states, dedupe and six positions; a notification centre with a bell; banners, inline alerts, progress, spinners, skeletons, empty states and result pages.

Display

Data display for power-user apps — code blocks with highlighting, copy, line numbers and file tabs; description lists; a searchable JSON tree with copy path; timelines; stat cards and KPI tiles with sparklines; avatars with presence; badges and tags; carousel; accordion and tab variants; hints and hover cards; image lightbox.

Shell

The application frame on the sidebar kit — header with breadcrumbs, search, notifications and account menu, page header with tabs, a resizable inspector, status bar, phone drawer, and sidebar, double, top-nav and settings layouts.

Form builder

Visual form builder on the form engine — drag fields from a palette, reorder on a canvas of live widgets, edit label, name, required, rules, options, conditions and defaults, sections and wizard steps, preview, undo and redo, export and import as the JSON definition AutoForm renders.

Tabster

VSCode-style tabbed dock — drag-reorder, dock-to-split, float / popout, nested groups, vertical sidebar, keyboard shortcuts.

Search

Search and data tools — a global search box with recents, grouped instant results, highlighting and ⌘K spotlight, a faceted results page with sort and pagination, a visual AND/OR query builder with JSON, and a CSV import wizard that maps, validates and fixes rows.

Upload

Files and media — a dropzone with real validation, an upload queue on a pluggable, resumable adapter, an image cropper, avatar upload, a media library with folders and bulk actions, and image, PDF, video and audio viewers.

Charts

Line, area, bar (grouped, stacked, horizontal), combo, pie and donut, radar, radial bar, gauge, funnel, scatter and bubble, sparkline and heatmap on plain SVG, plus a ranked bars list — crosshair tooltips, legend toggles, table view, keyboard reading, SVG and PNG export, light and dark palettes, no chart library.

i18n

One message catalog for every kit — typed namespaces with English defaults, locale bundles with fallback, single-key overrides, interpolation and plurals through Intl.PluralRules, a nesting provider with no global state, a language picker and direction from the locale.

Tour kit

Onboarding — product tours with a spotlight that span routes and resume, beacons, hotspots and coach marks, a getting-started checklist, a stepper and a what's-new feed.

Task lists

Headless task-list system — adapter-driven, multi-list board, kanban, virtualization, saved views, bulk actions.

Apps

Whole app surfaces, ready to drop in.

Spreadsheet

Excel-style grid — virtualised 10,000 × 50, range selection, keyboard editing, formulas with dependency-ordered recalculation, fill handle, TSV clipboard, formats, sort, frozen panes, undo.

Editors

Rich text on Tiptap (toolbar, bubble menu, slash commands, mentions, tables, code blocks, images, markdown import and export), a markdown editor with live preview, and a CodeMirror 6 code editor, with shortcuts on the keyboard kit.

Scheduling

Event calendar and Gantt — month, week, day, agenda and resource timeline views, drag to move, resize and create, all-day lanes, overlap layout, time zones, RRULE recurrence; Gantt with dependencies, drag bars, zoom levels and a today line.

AI chat

The UI for an AI assistant — streaming markdown, a composer with attachments and slash commands, tool-call cards, agent step traces, a context-usage meter, a model selector, citations, reasoning, regenerate and edit into branches, an artifacts panel and a conversation list, over one adapter seam for any backend.

Chat

Messaging and collaboration — Slack-style channels, threads, reactions, mentions, typing and seen receipts, edit and delete, attachments; comments anchored to text and blocks; an activity feed; an audit log with diffs. Pluggable realtime adapter.

Flow

Node and flow editor in the React Flow class — infinite canvas with pan, zoom and pinch, custom nodes with typed ports, bezier / step / straight edges, drag to connect, marquee, snap and alignment guides, minimap, auto-layout, undo, clipboard, keyboard navigation, JSON.

Whiteboard

Infinite SVG canvas — shapes, freehand, select / move / resize / rotate, groups, z-order, undo, SVG / PNG / JSON — plus an auto-laid-out mind map and an org chart with search.

Commerce

Pricing tables with a billing toggle and comparison matrix, a cart with coupons and tax, a checkout whose card field never stores data, orders and invoices, and a Calendly-style booking widget across time zones — on fake adapters you swap for your backend.

Auth

Auth and account UI on a pluggable adapter — sign in with password, magic link or OAuth, sign up with a strength meter, password reset, two-step verification with OTP and backup codes, email verification, account and security settings with sessions and a QR setup, and a roles × permissions matrix with members and invites.

Maps

Maps and location on MapLibre with no API keys — markers, clusters, popups, fit to bounds, light and dark basemaps, a location picker with search, drag and reverse lookup, an address autocomplete over a pluggable geocoder, a store locator and route lines.

Terminal

Developer views — a terminal emulator view with ANSI colours, scrollback, input history and a pluggable session, a virtualised log viewer with levels, search, follow tail and JSON expansion, split and unified diffs with word highlights, and a JSON / YAML tree diff. Fast at 100k lines.

Collab

Real-time collaboration primitives — presence with idle and away, avatar stacks, live cursors, shared selection, follow mode, an undo/redo history with grouping and time travel, over BroadcastChannel, in-memory or Yjs awareness.
