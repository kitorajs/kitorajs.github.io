Keyboard

Every editor command is a @kitora/keyboard command with a default key. Under a KeyboardProvider they join the app's registry: users rebind them in the shortcuts editor and the change reaches the editor and its tooltips at once. Without a provider each editor runs a local engine, so shortcuts always work.
