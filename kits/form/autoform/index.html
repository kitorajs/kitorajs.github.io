AutoForm (definition-driven)

Describe the form as data → get a styled, validated, isolated form. The model definition (defineForm) is the serializable model JSX also compiles to; a JSON Schema maps to the same definition through fromJSONSchema. (The older field manifest still works through fromManifest, deprecated.) Two recipes:

  • On this page:
  • From a definition
  • From a JSON Schema
  • Your own layout with AutoField
  • One question per screen with AutoQuestion

01From a definition

defineForm → <AutoForm def>: rules, a conditional block, and the definition's JSON beside it. Pick Team to reveal the company fields.Built frombuttonAddressField · formCardExpiryField · formCardNumberField · formCheckboxCardsField · formCheckboxField · formCheckboxGroupField · formColorField · formUsed inFormPreview · form-builder

The definition (toJSON)
{
  "version": 1,
  "fields": [
    {
      "kind": "field",
      "name": "plan",
      "type": "radio",
      "label": "Plan",
      "required": true,
      "options": [
        {
          "value": "solo",
          "label": "Solo"
        },
        {
          "value": "team",
          "label": "Team"
        }
      ]
    },
    {
      "kind": "field",
      "name": "email",
      "type": "email",
      "label": "Work email",
      "required": true
    },
    {
      "kind": "scope",
      "visibleIf": {
        "==": [
          {
            "var": "plan"
          },
          "team"
        ]
      },
      "children": [
        {
          "kind": "field",
          "name": "company",
          "type": "text",
          "label": "Company",
          "required": true
        },
        {
          "kind": "field",
          "name": "seats",
          "type": "number",
          "label": "Seats",
          "rules": [
            {
              "rule": "min",
              "value": 2
            }
          ]
        }
      ]
    }
  ]
}

02From a JSON Schema

A backend's JSON Schema (+ a uiSchema widget hint) mapped by fromJSONSchema; its constraints become field rules.Built frombuttonAddressField · formCardExpiryField · formCardNumberField · formCheckboxCardsField · formCheckboxField · formCheckboxGroupField · formColorField · formUsed inFormPreview · form-builder

The definition (toJSON)
{
  "version": 1,
  "fields": [
    {
      "kind": "field",
      "name": "name",
      "type": "text",
      "label": "Name",
      "required": true,
      "rules": [
        {
          "rule": "minLength",
          "value": 2
        }
      ]
    },
    {
      "kind": "field",
      "name": "email",
      "type": "email",
      "label": "Email",
      "required": true,
      "rules": [
        {
          "rule": "email"
        }
      ]
    },
    {
      "kind": "field",
      "name": "topic",
      "type": "radio",
      "label": "Topic",
      "required": false,
      "options": [
        {
          "value": "sales",
          "label": "sales"
        },
        {
          "value": "support",
          "label": "support"
        },
        {
          "value": "press",
          "label": "press"
        }
      ]
    },
    {
      "kind": "field",
      "name": "message",
      "type": "textarea",
      "label": "Message",
      "required": false,
      "rules": [
        {
          "rule": "maxLength",
          "value": 500
        }
      ]
    }
  ]
}
