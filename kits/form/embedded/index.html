Editor-embedded subform — controlled mode

The host editor owns the document and its undo history; the form is controlled with useForm({ value, onChange }). Host writes (undo, redo, a toolbar insert) apply with origin external and never echo back; only user edits reach onChange. The document is items[] of polymorphic FAQ / step / tab blocks — a Variant on each row's .type.
