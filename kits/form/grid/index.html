Editable grid

A virtualized spreadsheet over a form array: arrow-key navigation, type-to-edit, tab-separated paste in one undo step, per-cell errors across all rows (rendered or not), bulk edit on selected rows. A keystroke re-renders one cell.

03A whole-form schema on 1,000 rows

A Standard Schema has no "validate one path" call, so on a big form every keystroke used to walk all 1,000 rows. schemaScopes maps rows.* to the row's own sub-schema: an edit validates one row (the whole schema runs on submit). Measure compares whole / scoped / debounced on fresh stores.Built frombuttoncheckboxinputOptionSelect · formSheetSelect · formUsed inAutoForm · formFieldPreview · form-builderFormDialog · formFormSheet · formQuestionFlow · formWizard · formWizardNav · form
