    `useForm({ toSubmit })` maps form state to the submit payload (rename, restructure, parse); the payload type is its return type. Worked example: a FuncTool's `customData` JSON string sent as a parsed `data` object. · Demo: /kits/form/tools · Test: packages/form/src/core/__tests__/submit-baseline.test.ts

    live
  • Phased submit pipeline (G4)

    `useSubmitPipeline(phases)` / `createSubmitPipeline`: save → per-row calls (`ctx.each`) → ticket → finish as ONE store submit; a failing phase (or item) is a retryable `SubmitError` the store reports, Retry resumes at that phase and item, a done phase is skipped and its result reused (no second ticket) unless its `inputs` changed; `SubmitPhases` renders per-phase status. · Demo: /kits/form/service-booking · Test: packages/form/src/core/__tests__/submit-pipeline.test.ts

    live
  • Baseline, dirty, commit, reset

    live
  • Sensitivity (PII/PCI/PHI)

  • Big forms: scoped schema (H9)
