Responsive surfaces

Open one, then resize across 768 px: it changes surface without remounting. SSR: useResolvedSurface renders base (or ssrSurface) on the server and during hydration, then switches — no mismatch.

04Above the phone keyboard (O51)

On a phone, focus the field: the sheet sits on top of the keyboard with its Done button visible, and a half-snapped sheet shows whole until the keyboard closes. The inset comes from visualViewport (and the VirtualKeyboard API when the page sets overlaysContent); with interactive-widget=resizes-content it is 0 because the page itself shrank.Built fromAnchoredSurface · overlayConfirmView · overlayDefaultGuardConfirmView · overlayEntryView · overlayImagePreviewHost · overlayInlineSurface · overlayLightbox · overlayModalRoot · overlayUsed inaffixalert-dialogapi-key-cardattachmentautocompletecomboboxdialogfilter-bar

05Scroll lock without layout shift (O52)
