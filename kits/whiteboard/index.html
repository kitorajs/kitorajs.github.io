Whiteboard kit

An infinite canvas for diagrams and workshops. Pick a tool from the bar (or press its key), drag to draw, click a shape to select it, drag its handles to resize or the round knob to rotate, Shift-click or drag a box to select several. Everything is undoable, and the ⋯ menu saves, opens and exports.

03Layers

Use just the engine, the headless parts with your own markup, or the styled presets.

core@kitora/whiteboard/coreShape model and document, geometry, move / resize / rotate maths, freehand smoothing, camera, history, the board store with its pointer state machine and hit testing, SVG description and export, versioned JSON, keymaps, mind map and org chart models, tree layout. No DOM, no React.
dom@kitora/whiteboard/domCanvas text measuring, the BoardFiles adapter (PNG rasterising, downloads, file picking) with its browser default, localStorage and memory BoardStorage, pointer and wheel translation.
react@kitora/whiteboard/reactThe compound Whiteboard.Root / Canvas / Shapes / Selection / Marquee / Grid / TextEditor (controlled or uncontrolled doc, selection and tool), useBoardState, useBoardActions, usePanZoom, useMindMap + MindMapCanvas, useOrgChart + OrgChartCanvas.
ui@kitora/whiteboard/uiWhiteboardEditor and WhiteboardControls.Toolbar / StylePanel / Zoom / Menu; MindMap / MindMapView; OrgChart / OrgChartView; built only from the public parts. `@kitora/whiteboard` re-exports every layer.
