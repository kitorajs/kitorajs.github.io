Columns

Columns are defined once via defineColumns<TRow>()() (an identity helper that preserves literal id types) and consumed by every layer — the grid itself, the column-visibility menu, sort, group-by, export, layouts.

Shape

interface DataGridColumn<TRow> {
  id: string
  header: string | ((ctx: ColumnHeader<TRow>) => ReactNode)
  cell: (row: TRow, rowIndex: number) => ReactNode
  size?: number       // default width (px); default 160
  minSize?: number
  maxSize?: number
  meta?: ColumnMeta<TRow>
}

interface ColumnMeta<TRow> {
  align?: 'start' | 'center' | 'end' | 'left' | 'right' // start / end follow the reading direction
  className?: string
  label?: string                    // visibility-menu label; falls back to id
  sortFieldId?: string              // header gets a sort affordance
  filterFieldId?: string            // header menu → opens filter picker for this field
  hideable?: boolean                // default true
  resizable?: boolean               // default true
  draggable?: boolean               // header drag-reorder, default true
  pin?: 'start' | 'end' | 'left' | 'right' // sticky pinned column
  edit?: ColumnEditConfig<TRow>     // click-to-edit cell (see below)
  aggregate?: AggregateConfig<TRow> // footer aggregation
  copyValue?: (row: TRow) => string // right-click → Copy cell as text
  treeChevron?: boolean             // column owns the tree expand chevron
  hasChildren?: (row: TRow) => boolean
}

Custom cell rendering

Cells receive the row plus the row index. Compose freely.

const columns = defineColumns<User>()([
  {
    id: 'user',
    header: 'User',
    cell: (row) => (
      <div className="flex items-center gap-2">
        <Avatar src={row.avatarUrl} fallback={initials(row.name)} />
        <div className="flex flex-col">
          <span className="font-medium">{row.name}</span>
          <span className="font-mono text-xs text-muted-foreground">{row.email}</span>
        </div>
      </div>
    ),
    size: 240,
    meta: { sortFieldId: 'name' },
  },
])

Pinning

Pin a column to the inline start or end; it sticks while horizontal scrolling. start and end follow the reading direction (under dir="rtl" a start column sticks to the right edge, as MUI X does); left and right keep their physical meaning in both directions.

{ id: 'actions', header: '', cell: rowMenu, meta: { pin: 'end', hideable: false } }
{ id: 'name', header: 'Name', cell: (r) => r.name, meta: { pin: 'start' } }

A subtle gradient renders at the boundary so users see the divide; for start / end it mirrors with the direction.

Drag-resize + drag-reorder

Both on by default. Disable per column via meta.resizable: false / meta.draggable: false. Pinned columns reorder within their pinned band only.

Column widths persist via useDataGridUI().columnSizes — saved views capture them; URL sync persists them.

Inline editing

Wire meta.edit to enable click-to-edit. The editor type is inferred from your config:

edit: {
  type: 'text' | 'number' | 'select',
  /* For 'select': */
  options?: { value: string, label: string }[],
  /* For 'number': */
  min?: number, max?: number, step?: number,
  /* Current value. Default: the row's own [col.id] property. */
  read?: (row: TRow) => string | number | null | undefined,
  /* Required: the editor's value (string, or number | null for 'number')
     as a Partial<TRow>. Narrow it here, e.g. check a select value is
     a member of the field's union. */
  patch: (value: string | number | null) => Partial<TRow>,
}

Behavior:

  • Double-click cell → editor opens with current value
  • Enter commits via mutators.updateRow(id, patch)
  • Esc cancels
  • Blur commits

Auto-hidden when the adapter doesn't implement updateRow. Pair with mutators.bulkUpdate to surface the "Edit selected (N)" item in the header menu.

Aggregations

Footer row appears when any column has meta.aggregate:

meta: {
  aggregate: {
    fn: 'sum' | 'avg' | 'min' | 'max' | 'count' | ((rows) => ReactNode),
    label?: string,
  },
}

Aggregates run over the current page of rows by default — pass scope: 'total' to use totalCount instead (caller's responsibility to compute or fetch).

Hiding columns

Every column is hideable by default. Mark must-show columns:

{ id: 'actions', header: '', cell: rowMenu, meta: { hideable: false } }

Group-by sections

Set useDataGridUI().groupByColumnId to any column id — rows group under sticky section headers showing the group value + row count. Toolbar control: <DataGridGroupBy columns={...}>.

Tree expansion

Adapters that expose childrenOf?(parentId) + hasChildren? light up tree rows. One column owns the chevron via meta.treeChevron: true. Children fetch lazily on expand — the chevron shows a tiny loading dot during the round-trip.

Density

useDataGridUI().density ('compact' | 'comfortable') flows down into cell padding. Toggle: <DataGridDensityToggle>.

Header groups

columnGroups on <DataGrid> adds header rows above the leaf headers, MUI X's columnGroupingModel shape. columns stays a flat list, so column order, visibility, sizes, pinning, saved views, CSV export and bulk edit work as before; the groups only say which headers span which columns.

const groups = defineColumnGroups<typeof columns>()([
  { id: 'name', header: 'Name', children: ['first', 'last'] },
  {
    id: 'contact',
    header: 'Contact',
    description: 'Where to reach the person',
    children: [{ id: 'address', header: 'Address', children: ['street', 'city'] }, 'email'],
  },
])

<DataGrid columns={columns} columnGroups={groups} />
  • One header row per nesting level. A group cell spans its visible, contiguous leaves; hide a column and its group narrows, and a group whose leaves are split (a column reordered between them, or a pin boundary) draws one cell per contiguous run, each with the group's label.
  • Pinned groups stick with their pinned leaves. Columns in no group (and the checkbox, grip and action columns) get an empty cell down to the leaf headers.
  • With groups set, a column can be dragged only within its innermost group, by pointer and by keyboard; dragging whole groups is not supported.
  • Group cells are <th scope="colgroup" colSpan> (with cellSelection, role="columnheader" and aria-colspan); description is the tooltip and the aria-description; a long label truncates with an ellipsis and a title. Leaf headers keep their aria-sort.
  • They read the design language's table slot: the head height (--dk-table-head-h), weight (--dk-table-head-weight) and divider (--dk-table-divider).
  • defineColumnGroups<typeof columns>() types the leaf ids from the column definitions, so they autocomplete and a typo does not compile.
