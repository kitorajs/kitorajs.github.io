  • Adapter pattern

    Single `DataGridAdapter<TRow, TWhere>` interface — swap REST / GraphQL / Prisma / in-memory by implementing `load(query)`. Mutators (`updateRow / deleteRow / duplicateRow / bulkUpdate / bulkDelete`) are all optional.

    live
  • Capability auto-detection

    `inspectCapabilities(adapter)` derives a `{ updateRow, deleteRow, … }` boolean map. Plug-in features hide their UI for unimplemented mutators.

    live
  • Two-provider composition

    `<DataGridProvider>` runs the adapter; `<DataGridUIProvider>` holds search / filters / sort / pagination / selection / columns / density. Both required; clean separation of data vs. UI state.

    live
  • Identity helpers

    `defineColumns<TRow>()` / `defineFilterFields<TWhere>()` / `defineSortOptions<TFieldId>()` preserve literal types — column ids, filter ids, sort field ids autocomplete everywhere.

    live
  • In-memory reference adapter

    `createInMemoryAdapter` applies search / filters / sort / cursor pagination over a JS array. Use for prototyping or as a pattern reference for real adapters.

    live
  • Filter pickerf

    Two-stage popover: searchable + grouped field list, then a value editor per type. Arrow-key nav across both stages.

    live
  • Editable filter pills

    Each active filter renders as a pill with field · operator · value. Click to re-edit; × to remove.

    live
  • Text filter

    Operators: contains / not contains / eq / neq / starts with / ends with / is empty / is not empty.

    live
  • Number filter

    Operators: eq / neq / gt / gte / lt / lte / between / is empty / is not empty.

    live
  • Boolean filter

    True / False with T/Y and F/N hotkeys for instant commit.

    live
  • Select filter

    Single (`eq` / `neq`) or multi (`in` / `notIn`) — operator decides the picker shape. Search auto-shows when 4+ options.

    live
  • Multi-select filter

    Checkbox list for IN / NOT IN. Space toggles, Enter applies, search input never traps spaces.

    live
  • Date filter

    The pickers kit `Calendar` in a popover; the value is the picked day's local midnight as an ISO timestamp. Operators: eq ("is", the whole calendar day: the in-memory adapter matches the day range and `dayBounds(value)` gives a `toWhere` the same inclusive range) / gt / gte / lt / lte. New filters start on gte.

    live
  • Date-range filter

    Two-month calendar with a sidebar of 7 presets (Today / Yesterday / Last 7d / Last 30d / MTD / QTD / YTD). Click a preset to commit instantly.

    live
  • Relation filter

    Server-side debounced combobox via `loadOptions(query)`. Caches per query, dedupes in-flight requests, persists labels for URL roundtrips.

    live
  • Relation multi filter

    Same combobox, multi-pick mode. Stacks values into an IN clause.

    live
  • buildWhere engine

    Merges every field's `toWhere(condition)` partial into a single `TWhere`. Bridges loose `FilterCondition` to the field's typed condition union — single cast at the engine boundary.

    live
  • Operator allowlist per field

    Each field can override its allowed operators via `operators?: FilterOperator[]`. Smart-default operator picked when adding a new filter.

    live
  • Always-on search input/

    Adapter declares `search: { placeholder, toWhere }` → `<DataGridSearch>` renders. 300ms debounce, clear button, `/` shortcut hint.

    live
  • Search-to-where translator

    `search.toWhere(query)` returns a `Partial<TWhere>` merged with filters. Adapters implement free-text however they want (LIKE, full-text, embeddings).

    live
  • Multi-rule sorts

    Stack arbitrary number of sort keys. Trigger label shows primary + arrow + "+N" badge.

    live
  • Drag-reorder sort priority

    GripVertical handle on every active rule — grab and drop to rerank. Up/down chevrons also work.

    live
  • Per-rule asc/desc toggle

    Click the ↑/↓ icon on any rule to flip direction without losing priority.

    live
  • Header-click sort

    Click a sortable header → asc → desc → cleared. Works alongside the dropdown.

    live
  • Add asc OR desc directly

    Each available field shows ↑ / ↓ icons in the dropdown — click either to add a rule pre-set to that direction.

    live
  • Clear all

    Appears when ≥ 2 active rules. One click resets sort.

    live
  • Custom cell renderers

    `cell: (row, idx) => ReactNode`. Compose freely — avatars, badges, sparklines, anything.

    live
  • Column visibilityc

    Dropdown toggles columns on/off. Honors `meta.hideable: false` for non-hideable action columns.

    live
  • Drag-to-resize

    Drag the right edge of any header. Min 40px. Per-column override stored in `useDataGridUI().columnSizes`.

    live
  • Drag-to-reorder

    Grab any header and drop on another to rearrange. Visual primary-line drop indicator.

    live
  • Header sort affordance

    Sortable columns show ↕ / ↑ / ↓ chevron next to the header label.

    live
  • Per-column align / className

    Override alignment + arbitrary className on header AND body cells via `meta`. `align: "start" | "end"` follow the reading direction (`end` for numbers); `"left" | "right"` stay physical.

    live
  • Per-column header menu

    Chevron on each header → Sort asc / Sort desc / Clear sort / Filter… / Hide column. Filter… opens the picker pre-seeded with the column's `meta.filterFieldId`. Hover-only so headers stay clean.

    live
  • Pinned columns (start/end, left/right)

    `meta.pin: "start" | "end"` (follow the reading direction: under `dir="rtl"` a start column sticks to the right edge, with its edge shadow mirrored) or the physical `"left" | "right"` — column stays visible while horizontally scrolling. Cumulative offsets computed automatically. Subtle gradient + inset border on the boundary cell. Pinned cols opt out of drag-reorder.

    live
  • Column-level permissions

    `meta.canRead(row)` → render placeholder ("—") instead of value. `meta.canEdit(row)` → fall back to read-only even when adapter has `updateRow`. Both row-context aware; distinct from hidden.

    live
  • Auto-resize columns (fit-to-content)

    Double-click a column's resize edge to fit it to its widest visible cell (Excel / Notion shape). Toolbar action "Auto-fit all columns" to size every visible column at once. Computed against the current page's rendered DOM; respects `meta.minSize` / `meta.maxSize`. Per-column override stored in `useDataGridUI().columnSizes` so the result survives next render.

    planned
  • Multi-header column groups

    `columnGroups` on `<DataGrid>` (MUI X's `columnGroupingModel` shape): `{ id, header, children: (columnId | group)[], description?, className? }`, typed by `defineColumnGroups<typeof columns>()`. `columns` stays flat, so order, visibility, sizes, pinning, saved views, CSV export and bulk edit are unchanged. One header row per nesting level; a group cell spans its visible, contiguous leaves and splits into one cell per run when a hidden or reordered column or a pin boundary cuts it; pinned groups stick with their leaves; ungrouped columns get an empty cell. `<th scope="colgroup">` (`columnheader` + `aria-colspan` in grid mode); `description` is the tooltip and `aria-description`; labels truncate with a title. A column drags only within its group (pointer and keyboard). Reads the `table` slot head height, weight and divider. `<DataGridVirtual>` takes the same `columnGroups`.

    live
  • Column spanning (cell `colSpan`)

    Per-row override: `meta.colSpan?: (row, rowIndex) => number` on a column. When `> 1`, the cell expands across the next N - 1 visible columns; those columns' cells render as empty for this row only. Useful for "section break" rows (subtotal rows that span every numeric column), category headers, or visually highlighting a single big value across an analytic table. Composes with pinning + group headers. Refs AG Grid `colSpan`.

    planned
  • Row spanning (cell `rowSpan`)

    Per-column override: `meta.rowSpan?: (row, rowIndex, allRows) => number` — the cell extends vertically over the next N - 1 rows. Most common use: merging duplicate values in a sorted column (e.g. "Country" cells with the same value collapse into one tall cell). Pairs with `meta.aggregateRowSpan?: "sameValue" | "manual"` to auto-detect runs. Renders via real `<td rowSpan>` so screen readers + selection work correctly. Refs AG Grid `rowSpan`.

    planned
  • Row numbers column

    Built-in virtual column `meta.rowNumbers: true` (or shorthand prop `rowNumbers` on `<DataGrid>`) — renders a left-most monospace column showing the 1-indexed row position. Configurable: `start` (offset for pagination — auto-syncs with `pagination.page * pageSize`), `format: (n) => ReactNode` for custom rendering (Roman numerals, letters, etc.), `sticky` (pins under column-pin layer when horizontal scroll). Excludes from CSV / JSON exports unless `exportable: true`.

    planned
  • Row checkboxes

    Auto-rendered when `selectable !== false`. Selection state lifted to UI provider so a bulk bar can render anywhere.

    live
  • `data-row-id` on every `<tr>`

    Stable row identifier emitted on every table row by `<DataGrid>`. Lets pointer-based selection hooks (rubber-band, long-press) work against the table view with zero extra wiring.

    live
  • Shift-click range select

    Plain click sets the anchor index; Shift-click any subsequent row extends the selection to every row between anchor and current. Works on the row body OR the checkbox cell.

    live
  • ⌘/Ctrl-click toggle

    Meta/Ctrl-click on a row toggles its selection without committing select mode (no anchor reset). Mix with shift-click for additive range builds — classic Finder/Mail behavior.

    live
  • Header indeterminate

    Header checkbox: empty / indeterminate (some) / checked (all on this page). Click toggles.

    live
  • `<DataGridBulkActions>` bar

    Floating bottom bar visible when `selectedIds.length > 0`. Built-in Delete + custom children.

    live
  • Adapter-driven Delete

    Bulk Delete button auto-hides when adapter doesn't implement `bulkDelete`. No prop wiring.

    live
  • Selection-aware bulk-edit

    `<DataGridBulkEditPopover columns>` — column header menu shows "Edit selected (N)" when adapter has `bulkUpdate` AND col has `meta.edit` AND selection > 0. Dialog reuses the column's edit input (text/number/select) → dispatches `mutators.bulkUpdate(selectedIds, patch)`. Drawn by the overlay kit's modal: no close while the update runs, a failed update stays in the dialog as an inline error, focus returns to the column menu's trigger.

    live
  • Selection indicator chip

    `<DataGridSelectionIndicator />` — inline "N selected" chip with × Clear button. Layout-agnostic; mount in toolbar / page-header / sticky-footer. Hidden when count = 0 unless `alwaysShow`.

    live
  • Auto-enter select-mode hook

    `useDataGridSelectMode(count)` derives a layout-agnostic select-mode boolean from the live selection count. Returns `{ selectMode, enter, exit, reset }` for Apple-Photos-style explicit override. Used by MediaGrid; available for any layout.

    live
  • Selection keyboard shortcuts

    `useDataGridSelectionShortcuts({ hostRef, onSelectAll, onClear })` — ⌘A select-all + Esc clear as keyboard kit commands scoped to the grid element (`scope.datagrid-<n>`); ⌘A in a text field selects its text. Drop in any layout root; pair with layout-specific arrow nav.

    live
  • Open a row from the keyboard

    With `onRowClick` set, cards and `<DataGridVirtual>` rows are Tab stops (a kanban board is one, its arrows walk the cards) and **o** on the focused card or row opens it; Enter opens too when the row has no drag (on a draggable row Enter and Space pick it up). The keys are on each row as `aria-keyshortcuts` and listed in `<DataGridShortcutsHelp>`.

    live
  • Rubber-band selection hook

    `useDataGridRubberBand({ hostRef, selector, getRowId, onSelect })` — pointerdown drag-to-select marquee that hit-tests any element matching the selector. Default selector `[data-row-id]`. Plug into table list-view, cards, kanban, media-grid — selector is parameterized.

    live
  • Long-press selection hook

    `useDataGridLongPress({ selector, getRowId, onLongPress })` — touch long-press helper. Selector + row-id extractor parameterized, defaults to `[data-row-id]`. Suppresses the synthetic click via `shouldSuppressClick()`.

    live
  • Drag-ghost pill helper

    `buildDataGridDragGhost(count, { noun?: "row" / "card" })` — builds a tiny "N items" chip. The table view's row reorder renders it as the DnD-kit drag preview under the pointer (a `<tr>` cannot be cloned outside its table).

    live
  • Clear selection mechanisms

    Four entry points compose: Esc keyboard shortcut, × on `<DataGridSelectionIndicator>`, × on `<DataGridBulkActions>` bar, imperative `setSelectedIds([])` via `useDataGridUI()`.

    live
  • Cell range selection

    `cellSelection` on `<DataGrid>`: the table becomes a WAI-ARIA grid with one roving tab stop; press-and-drag (auto-scroll at the edges), Shift-click and Shift + arrows / Home / End / Mod+Home / Mod+End / PageUp / PageDown select a rectangle of data cells, Shift+Space the row, Mod+A every cell on the page, Esc clears it (then the rows). Enter, F2 or a click on the focused editable cell edits it. Long press then tap on touch; arrows mirrored in RTL. The range lives in `<DataGridUIProvider>` (`cellSelection` / `defaultCellSelection` / `onCellSelectionChange`, `selectedCellRange`), cleared on sort, filter, page and column changes. Keys are keyboard-kit commands (`datagrid.cell…`, `datagrid.extendRange…`). Utility columns are never in a range; row drag starts only from the grip. `<DataGridVirtual>` takes the same `cellSelection` (plus copy, paste, undo and `columnGroups`) over every row, with `aria-rowindex` / `aria-colindex` on the mounted window and keys that scroll the row in.

    live
  • Cmd+C selection

    With `cellSelection` on: Mod+C copies the cell range, else the selected rows (every visible data column, in display order), else the focused cell, as TSV through the spreadsheet kit's `toTsv` (or a `clipboardCodec`). Text per cell: `meta.copyValue(row)`, else `meta.edit.read`, else the row's own field, else `meta.searchValue`; `canRead` false copies empty. `copyHeaders` adds the header line; the right-click menu has Copy cells / Copy rows / Copy with headers. Read from the provider's rows, never the DOM.

    live
  • Cross-page selection persistence

    Picking 2 rows on page 1, 3 on page 2, 5 on page 3 → `selectedIds` accumulates all 10 ids in `<DataGridUIProvider>`. Selection survives page navigation in `paged` mode (and in `numbered` mode once shipped) — the UI provider state is page-agnostic; ids are kept in a Set keyed by `getRowId(row)`. Selected rows on a re-visited page automatically re-paint their checkboxes. Required across every layout (table / cards / kanban / media-grid).

    planned
  • Select-all-matching flag

    Sticky flag `selectionMode: "specific" | "all-matching"` in `<DataGridUIProvider>`. When `all-matching`, the selection conceptually includes *every row matching current filters / search / sort*, not just loaded ones — header checkbox flips to "All 12,480 selected" + "Clear" affordance, every row's checkbox paints checked regardless of which page is visible. Bulk actions dispatch either against the literal `selectedIds` (specific mode) or via a new adapter method `bulkUpdateMatching(where, patch)` / `bulkDeleteMatching(where)` (all-matching mode) so backends don't have to enumerate millions of ids. Gracefully falls back to `fetchAll() → enumerate` when the adapter doesn't implement the *Matching methods.

    planned
  • Header checkbox three-state across pages

    When the user has picked rows across multiple pages, the per-page header checkbox is computed only against the *current page's* rows, but a sibling "All N selected (every page)" badge appears in `<DataGridSelectionIndicator>` so users can tell which mode they're in. ⌘A on a focused grid offers "select all on this page" → "select all matching" (Gmail pattern).

    planned
  • Bulk-action adapter contract — `bulkUpdateMatching` / `bulkDeleteMatching`

    Optional adapter methods that receive the active `where` clause instead of an id array. Used by select-all-matching mode so the server can run `UPDATE … WHERE …` in one round-trip instead of N. Capability-detected by `inspectCapabilities()`; if absent, the kit falls back to `fetchAll() → bulkUpdate(allIds, patch)` (slower but works on any cursor adapter).

    planned
  • Pagination - Cursor-based prev/next (`paged` mode)

    Provider passes `first/after` (forward) or `last/before` (backward) to `adapter.load()`. Linear / GitHub-shape — works with any Relay-style backend. Default mode.

    live
  • Pagination - Page size selector

    Dropdown with caller-supplied options (default 10 / 20 / 50 / 100). Resets cursor to first page on change.

    live
  • Pagination - `<DataGridPageSizeSelect>` (mode-agnostic)

    Standalone page-size picker — works in `paged` / `infinite` / `numbered`. ui's `PaginationPageSize` (a `Select` named by its visible label, `Infinity` shown as "All", the current size always offered) wired to `useDataGridUI().pageSize`. `<DataGridPagination>`'s "Rows per page" control is the same part. Useful when you want the size selector decoupled from the prev/next paginator (e.g. you're using `<DataGridNumberedPagination>` which doesn't bundle one).

    live
  • Pagination - `<DataGridPaginationStatus>` (mode-aware readout)

    Shape-shifts on `paginationMode`: `paged` → "Showing 21–40 of 213"; `numbered` → "Page 3 of 27 · 530 results"; `infinite` → "Loaded 90 of 800" (or "Loaded 90" when total unknown). Optional `format` prop overrides the rendered string entirely for i18n / custom shape.

    live
  • Pagination - Row range readout

    "1–20 of 213" rendered when `totalCount` is supplied by the adapter.

    live
  • Pagination - Auto-reset on filter change

    Pagination jumps back to page 1 whenever search / filters / sort change.

    live
  • Pagination - Infinite scroll (auto-sentinel)

    Set `<DataGridProvider paginationMode="infinite">` and mount `<DataGridInfiniteAnchor direction="up | down" />` anchors. Cursor pages append (down) or prepend (up) into the same `rows` array. Live at `/kits/datagrid/infinite` (table) and `/kits/datagrid/media` (gallery).

    live
  • Pagination - Bidirectional infinite

    Both `direction="up"` and `direction="down"` anchors supported. `up` fires when user lands mid-feed via deep-link cursor and scrolls up; provider issues backward cursor query and prepends results.

    live
  • Pagination - IntersectionObserver sentinel hook

    Layout-agnostic `useDataGridInfiniteScrollSentinel({ enabled, onTrigger, rootRef?, rootMargin? })` — bring your own UI; the hook just attaches an observer to a sentinel ref. Powers `<DataGridInfiniteAnchor>` and any custom load-more affordance.

    live
  • Pagination - Windowed renderer (virt)

    Drop-in `<DataGridVirtual>` powered by `@tanstack/react-virtual` — flat (`/kits/datagrid/virtual`) or with sticky group headers, Linear-style (`/kits/datagrid/grouped`). 5,000 rows scroll at 60fps. Composes with `paginationMode="infinite"` — fetch in pages, render only the window.

    live
  • Pagination - Numbered offset mode (`numbered`)

    New `<DataGridProvider paginationMode="numbered">`. Adapter accepts `{ offset, limit }`; provider derives offset from page number. Backed by `<DataGridNumberedPagination>` default UI. Required for "jump to page 17" / "page 1 of 42" UX. Adapter capability flags (`cursorPagination` / `offsetPagination`) detect support automatically.

    live
  • Pagination - `<DataGridNumberedPagination>` (ellipsis)

    Default UI for numbered mode. Renders `1 2 3 … 17 18 19 [Next]` with adaptive ellipsis compression based on `totalPages`. Keyboard-navigable (←/→/Home/End).

    live
  • Pagination - `<DataGridJumpToPage>`

    Inline `Go to page __` input for numbered mode: ui's `PaginationJumpToPage` wired to the numbered pager. The typed page is clamped to `totalPages` before dispatching; Enter or Go jumps, Escape clears; the visible label names the input; no inner `<form>`, so it sits inside a host form, and two grids never share an id.

    live
  • Pagination - `<DataGridFirstLastButtons>` (⏮ ⏭)

    First / Last quick-jump controls. Works with both `paged` (cursor reset to head/tail) and `numbered` (jump to page 1 / totalPages). Disabled when `hasPrev` / `hasNext` is false.

    live
  • Pagination - `<DataGridLoadMoreButton>` (manual infinite)

    Manual variant of `<DataGridInfiniteAnchor>` — same `infinite.loadMore()` hook, but waits for an explicit button click instead of auto-firing on scroll. Pinterest / "Load more results" pattern. Live at `/kits/datagrid/load-more`.

    live
  • Pagination - `useDataGridPagination()` unified hook

    One discriminated-union hook abstracts all three modes (`paged` / `infinite` / `numbered`). Build your own pagination UI in ~20 lines — works for any mode, switches gracefully when the provider mode flips.

    live
  • Pagination - Adapter offset/limit query fields

    `DataGridQuery` gains optional `offset` + `limit` (additive, non-breaking). `inspectCapabilities(adapter)` reports `cursorPagination` / `offsetPagination` flags. Adapters can support either, both, or neither.

    live
  • Pagination - Capability-mismatch guard

    At mount the provider throws a named error when `paginationMode="numbered"` meets a cursor-only adapter, or the reverse, so the mismatch fails loudly instead of leaving an empty grid.

    live
  • Pagination - Date-bucket separator

    Ships as `defineDateBucketColumn<TRow>({ bucketKey, format })` (factory) + `<DataGridDateBucketActivator>` (imperative activator). Piggy-backs on the existing groupBy infra — `meta.groupValue` + `meta.groupLabel` extractors render "Today" / "Yesterday" / "Mar 14" section headers between rows. Works on top of *any* pagination mode (paged / infinite / numbered) because it groups whatever the renderer is showing. Helpers `startOfDayKey()` + `formatRelativeDay()` exported for the common Slack-style label set. Live at `/kits/datagrid/log-stream`.

    live
  • Pagination - `<DataGridLiveTail>`

    Sticky "N new ↓" badge + auto-scroll-to-bottom + pause-on-hover / manual scroll. State machine: `following → paused → following`. Detects new rows via `useDataGrid().rows.length` delta — provider grows that array via `adapter.subscribe` push, `loadMore` cursor append, or manual refresh; all three trigger the same code path. Composes with any pagination mode. Configurable `pauseWhen` (hover / manualScroll) + `stickThreshold` + `badge` render override. tail -f / Datadog Logs shape. Live at `/kits/datagrid/log-stream`.

    live
  • Pagination - "All" / unpaginated

    Set `defaultPageSize={Infinity}` on `<DataGridUIProvider>` and skip the paginator entirely. Adapter returns everything; renderer (use `<DataGridVirtual>` for thousands+) decides what to show.

    live
  • Pagination - Keyset / `search_after`

    Server-side cursor variant where the cursor is the values of the last row's sort columns (e.g. `(created_at, id)`) rather than an opaque token. Server queries `WHERE (sortCols) > (lastValues) LIMIT n` — uses the sort index, faster than offset at scale. Used by Elasticsearch (`search_after`), MongoDB, most big-data systems. From the kit's perspective looks identical to cursor; server picks the encoding. Will document the recipe + ship a reference encoder/decoder helper.

    planned
  • Pagination - Hybrid cursor + jump-to-anchor

    Bluesky-style "jump to date" — combine cursor pagination with named anchor points (date / id / user-supplied key). Calendar scrubber or timeline UI dispatches to a specific anchor; provider resets cursor + bidirectional infinite takes over from there.

    planned
  • Pagination - Hash / random-sampling feeds

    TikTok-style ranked feeds — each scroll fetches a *fresh sample* rather than the "next page." Cursor is a session/seed used by a recommendation engine, not an order-stable position. No total count, no jump-to-N. Adapter exposes `loadSample(seed, n)` instead of paged `load()`. Recommendation engine is out of the kit's scope; this entry is a placeholder for when we wire the UI affordances.

    planned

  • Single-row drag

    Press anywhere on the row (or Space on the grip, then arrows, then Space; Escape cancels) — DnD kit. The pointer's half of the hovered row picks before / after (2px primary line on that edge); dropping after the last row appends. Drops that change nothing never reach the adapter. Each step is announced through the kit's live region.

    live
  • Drag visuals

    live
