Terminal kit

Developer views for power users: a terminal emulator view with a pluggable session, a virtualised log viewer, a split and unified diff viewer and a JSON / YAML tree diff, all fast at 100k lines, on a framework-free core.

Tree diff

Structural diffs of JSON and YAML: objects by key, arrays by index or by an id key, with added, removed, changed and moved nodes, change counts and next / previous change.

  • On this page:
  • package.json
  • A Kubernetes rollout (YAML)
  • Arrays: by index or by id key
