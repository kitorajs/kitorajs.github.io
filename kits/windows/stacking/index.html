Stacking and modality

Modal windows join the overlay kit's stack, so Escape, focus return and page shortcuts behave like every other dialog in the app. The desktop paints in its own band below overlays, so menus and dialogs opened from a window are never covered by another window.

01Modal windows

App-modal blocks every other window behind a scrim; a window-modal sheet blocks only its owner. Escape closes the modal one; focus goes back to the launcher.Built fromWindowFrame · windowsUsed inDock · dockDockStyles · dock
