Sidebar kit

One sidebar for every power-user app. Collapse it to an icon rail (the toggle, ⌘B, or drag the edge past half its minimum), drag the edge to resize, open spaces and folders, hover a row for "+" and "…", right-click for the menu, double-click or F2 to rename, drag rows to reorder or move them between sections and folders, type in Search to filter. Everything you change survives a reload.

02Layers

Every layer ships today; listed in build order.

coreNav model, rows, section states, filter and highlight, badge roll-up, active matching, moves with drop rules and replay, Favourites and Recents sections, the virtual window, messages, state reducer and store, versioned snapshot with migrations. No DOM.
domlocalStorage, cookie and memory storage; responsive bands from matchMedia; hover intent; reduced motion.
reactSidebarProvider (live announcements, messages), useSidebar, SidebarLayout on the dock's SplitView (overlay, hover-peek, top bar, edge swipe), the headless NavTree (tree semantics, roving keys, drag on the dnd kit, virtualisation, per-row memo).
uiSidebar, SidebarNav, NavRowView, rail and mini rail with flyouts, AppRail, switcher, user menu, Customise menu, search, skeletons, mobile sheet with the carried theme, --sb-* tokens (resolved on the layout, so a nested token scope reaches them), solid or translucent surface, bar, fill or pill active row.
keyboard@kitora/sidebar/keyboard: commands and default keys on the keyboard kit, item jumps, next unread, palette provider, F6 regions and skip links.
devtools@kitora/sidebar/devtools: state, snapshot, stored value and active match in a panel.
