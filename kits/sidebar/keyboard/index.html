Keyboard and commands

The sidebar's opt-in keyboard entry: commands on the keyboard kit's registry (rebindable, listed in the palette and the cheatsheet), a Go to command for every item that shows a shortcut, next and previous unread, a palette page listing every nav item, F6 to cycle between the sidebar and the content, and skip links from the same regions. Inside the tree: arrows, Home and End, typeahead, Left and Right, F2, Alt+Arrow and Shift+F10.
