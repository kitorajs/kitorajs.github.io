Drag & drop kit

One engine for pointer, keyboard and touch drags, built in layers: a framework-free core, a dom layer, then React bindings and presets. Each page proves rows of the feature catalog.

Layers

Every layer ships today; listed in build order.

coreState machine, collision, modifiers, MoveOp, fractional index, scripted sensor. No DOM.
domPointer and keyboard sensors, measurement, auto-scroll, edge cases.
dom presentationTop-layer preview, placeholder, shift and drop animation, moveBefore, indicators.
reactDndProvider, useSortable, per-item stores, devtools.
html5OS files, text and URLs through the HTML5 bridge (opt-in entry).
ui presetsSortableList, SortableGrid, Kanban, FreeCanvas, DragHandle, DropIndicator.
tree + multi-selectFlatten and build, depth from the horizontal offset, reparent, spring-loaded expand, SortableTree, selection batches.
accessibilityGrab-arrow, Move menu and Tab-to-target keyboard models, live-region announcements from a replaceable catalog, instructions, one tab stop per list, focus restore, forced colours.
table, virtualTable rows, virtual lists.
