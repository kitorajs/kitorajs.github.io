  • Per-list cursor pagination

    Each list shows first N tasks + "Load more". Adapter implements `loadGroupTasks({ first, after })`. See `/kits/tasklists`.

    live
  • Per-list Prev/Next pager

    Swap the default Load-more footer for a Prev / Page N / Next pager via the `pagerSlot` prop on `<TaskListBoard>`. Reuses the full board (subtasks, multi-select, drag-drop, status pickers, inline-add). Backed by the new `mutators.setGroupPage` (replaces vs `loadMoreTasks` which appends); cursor history tracked at the route level so Prev rewinds correctly. See `/kits/tasklists/board-virt`.

    live
  • Per-list virt scroll

    Same `<TaskList>` rendering, internally wrapped in `@tanstack/react-virtual`. Activate by passing `virt={{ containerHeight }}` directly to `<TaskList>` or `taskListVirt` to `<TaskListBoard>`. Subtask expansion auto-remeasures via `measureElement`. See `/kits/tasklists/board-scroll`.
