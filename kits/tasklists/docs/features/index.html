Feature flags

Pass a features map to <TaskListProvider>. Anything you leave undefined defaults to enabled when the adapter implements the underlying mutation.

Available flags

FlagWhat it controls
dragDrag-to-reorder within a list and across lists
dragSelectionWhole-selection drag when the dragged task is selected
multiSelectRow select checkboxes + bulk action bar
subtasksSubtask expand chevron + nested rendering
inlineRenameDouble-click title to rename
contextMenuRight-click row menu
inlineComposerInline task composer at top + bottom of each list
drawerPreviewRight-side Sheet preview when a task is opened
statusPickerClick the row status icon → dropdown
reorderListsDrag lists by their header grip to reorder
collapsibleListsClick chevron to collapse / expand a list
kanbanRender the kanban view tab
savedViewsSave filter combinations as named presets

inlineComposer also accepts an object: { top: false, bottom: true } to show only one of the two composers.

Examples

Read-only viewer

<TaskListProvider
  adapter={readOnlyAdapter} // only implements load()
>
  <ConnectedTaskListBoard />
</TaskListProvider>

Every interactive UI hides automatically because no mutation is wired.

Full-feature, no kanban

<TaskListProvider
  adapter={fullAdapter}
  features={{ kanban: false }}
>
  <ConnectedTaskListBoard />
</TaskListProvider>

The Kanban view tab is suppressed even though updateTask is implemented (which would otherwise enable it).

Mobile / minimal mode

<TaskListProvider
  adapter={fullAdapter}
  features={{
    drag: false,
    contextMenu: false,
    multiSelect: false,
    subtasks: false,
    kanban: false,
    inlineComposer: { top: true, bottom: false },
  }}
>
  <ConnectedTaskListBoard />
</TaskListProvider>

Strips heavy interactions for small screens. Only the top composer + tap to open detail remain.

Force a feature even with no adapter support

<TaskListProvider
  adapter={partialAdapter} // no `moveTask` implemented
  features={{ drag: true }} // force-on anyway
>
  <ConnectedTaskListBoard />
</TaskListProvider>

The drag handles render, but drops will be no-ops since the adapter can't persist the move. Useful for previews or progressive enhancement.

Live demo

Open /kits/tasklists/headless — the left panel has a Switch for every flag. Toggle them and watch the board re-wire instantly.
