Getting started

The task list system is headless — UI primitives + a swappable data adapter. Drop it into any React app, point it at your data, decide which features to expose.

Install

It's already part of the kit. Import from a single barrel:

import {
  TaskListProvider,
  ConnectedTaskListBoard,
  createInMemoryAdapter,
  type TaskListAdapter,
  type TaskListFeatures,
} from '@kitora/task-list'

Minimal example

import { seed } from './my-seed'

function App() {
  const adapter = createInMemoryAdapter({ initial: seed })

  return (
    <TaskListProvider adapter={adapter}>
      <ConnectedTaskListBoard />
    </TaskListProvider>
  )
}

That's it. Every interactive feature — drag, multi-select, subtasks, inline rename, context menu, status picker — turns on automatically because the in-memory adapter implements every mutation.

Three layers

The kit is split into independently usable layers:

  1. UI primitives (<TaskList>, <TaskListBoard>, <KanbanBoard>) — pure React components driven by props. Use these directly when you want full manual control over state.
  2. Adapter contract (TaskListAdapter) — the data interface. Implement to bridge any backend.
  3. Provider + Connected components (<TaskListProvider> + <ConnectedTaskListBoard>) — wire UI to adapter via React Context.

You can mix and match. Use the provider for the batteries-included experience, or skip it and pass props yourself.
