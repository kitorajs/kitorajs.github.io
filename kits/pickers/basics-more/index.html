Basics: recurrence, colour, numbers, codes and inline edit

A recurrence is one RRULE string (FREQ=WEEKLY;BYDAY=MO,WE, empty for does not repeat) with a readable summary; a colour is one hex string (#3b82f6, with alpha #3b82f6cc); a number is a plain number (or null when empty) typed and shown in the locale; an inline edit holds any value and writes it only when saved.
