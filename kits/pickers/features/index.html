Pickers kit

Date, time and colour pickers for power users: typed-segment fields, calendars in single, multiple and range mode, range presets, month and year, time zones, recurrence rules and a colour picker. Keyboard-first, Intl-localised, RTL.

Live = built and shown and/or tested end to end in headless Chrome or jsdom (the page and test files are named and checked by a test). In progress = built, waiting for a device or browser test, or shown only in part; each such row says what is missing. Planned = queued, not built yet; the row names its step.
