Basics: actions and branches

A thread is a tree. Regenerate and edit never overwrite: they add an alternative beside the old message, and ‹ › switches between them.

  • On this page:
  • Copy and feedback
  • Regenerate into branches
  • Edit and resend

01Copy and feedback

Copy puts the reply's text on the clipboard; thumbs set a rating, pressing again clears it.Built frommessage-scrollerChatMessageView · ai-chat

What does Array.prototype.at(-1) return?

✦

The last element of the array, or undefined when the array is empty. Negative indexes count back from the end.

Feedback on the last reply: none

02Regenerate into branches

Press the circular arrow under the reply. Each run adds an alternative; ‹ 2 / 3 › walks them.Built frommessage-scrollerChatMessageView · ai-chat

Name a good variable for a retry counter.

✦

attempt — it reads well in attempt < maxAttempts.

03Edit and resend

Hover the question, press the pencil, change it and Send. The original question and its answer stay one ‹ away.Built frommessage-scrollerChatMessageView · ai-chat

Translate 'good morning' to French

✦

Bonjour — French uses one greeting for the whole morning and afternoon.
