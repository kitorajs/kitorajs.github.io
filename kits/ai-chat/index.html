02The scripted assistant

The script behind the demos: steps of chunks, pauses and texts to stream, chosen by keywords in the question.

Open the Code tab to read the script. Swap `demoAdapter` for an adapter over your own backend and nothing else changes.

03Layers

One package, four layers, each importing only the ones below and each its own entry.

coreMessage and part types, the thread tree (branches from edit and regenerate), stream folding, streaming-safe markdown parser, composer and list decisions, ChatStore, the ChatAdapter seam and a scripted fake adapter. No DOM, no React.
domHeadless browser behaviour: stick-to-bottom scrolling, textarea autosize, the AttachmentAdapter seam (default object URLs), clipboard, download and roving focus. No React, no styling.
reactHooks with no markup: useChat / useChatStore and the context, useComposer (draft, files, slash menu, submit and stop as prop getters), useStickToBottom (from @kitora/primitives/react), useDisclosure, useControllable. Copying goes through @kitora/display (CopyButton, useCopy).
uiCompound parts (ChatMessages.* on ui's MessageScroller, Message.* on ui's Message, Bubble, Attachment, MessageStatus and the MessageActions toolbar, Composer.*) and the presets built only from them, plus Markdown with renderer slots (drawn through ui's Prose, the look the editors kit's preview shares), ToolCallCard, ReasoningView, Trace (steps with plan, queue and subagent presets, the reasoning fold and tool steps on its status map), ContextUsage (the context window as a ring for the composer toolbar, details in a popover, on the feedback kit's Meter), ModelSelector (a model picker on ui's Select: models grouped by provider with descriptions and tags, searchable above 8, a bottom sheet on a phone, `name` for a form), SourceList, ArtifactPanel, ConversationList, ChatEmptyState and ChatLayout on the dock's SplitView.
