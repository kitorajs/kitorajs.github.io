Customizer

Make your own design language: start from a built-in, edit colours, type and every component slot with controls generated from the slot schema, watch it live, then save it in this browser, duplicate, delete, import or export it as JSON, or copy its CSS variables. The same component is behind "Customize…" in the site header.
