Theme kit

Foundations and theming: OKLCH colour scales from one brand colour with contrast-checked pairs, radius, spacing, type and density scales, a ThemeProvider for light, dark, system and per-subtree themes, a live designer and a WCAG contrast checker, on a framework-free core.

Basics: export

The core is plain TypeScript, so a theme can be generated in a build script and written to a file.
