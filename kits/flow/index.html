Flow kit

Flow kit

Drag nodes, drag from a port to connect, drag empty space to pan (Shift+drag to select a box), ⌘/Ctrl + wheel or pinch to zoom. Tab into the canvas for the keyboard: arrows walk between nodes, Alt+arrows move them, ⌘Z undoes.

02Layers

One package, four layers; each imports only the ones below and has its own entry (@kitora/flow/core, /dom, /react, /ui).

coreModel (nodes, ports, edges, viewport), geometry and edge paths, pan and zoom maths, grid snap and alignment guides, the layered auto-layout, nearest-node navigation, connection rules, copy and paste, versioned JSON, the editor reducer with undo history, the key map. No DOM.
domBrowser readings with no React: hit testing by data attributes, key chords, pointer points, wheel intent, node measuring, and the system-clipboard adapter.
reactUnstyled: useFlow (the controller, controlled or uncontrolled, with clipboard and layout adapters), useFlowCanvas (the pointer, wheel and key engine), the compound Flow.* parts, and the headless useMiniMap.
uiStyled presets built only from the parts: FlowCanvas, FlowControls, MiniMap, FlowPanel, and NodeCard with rowPorts for labelled port rows.
