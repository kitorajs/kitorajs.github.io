Flow kit

A node and flow editor in the React Flow class: an infinite canvas with pan, zoom and pinch, custom React nodes with ports, bezier, step and straight edges, drag to connect, marquee selection, snapping and alignment guides, minimap, auto-layout, undo, clipboard, keyboard navigation and JSON, on a framework-free core.
