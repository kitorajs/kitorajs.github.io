Display kit

Data display for power-user apps: code blocks with a built-in highlighter, description lists, a JSON viewer, timelines, stat cards with sparklines, avatars with presence, badges and tags, a carousel, accordion and tab variants, hints and hover cards, and images that open in the overlay kit's Lightbox.
