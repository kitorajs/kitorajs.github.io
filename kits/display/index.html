02What is in the kit

Everything comes from the barrel, @kitora/display; the lower layers are also their own entries: /core, /dom, /react.

CodeCodeBlock, CodeTabs, InlineCode, CopyButton; a built-in tokenizer for ts/tsx/js/jsx, json, css, html, bash, python, go, rust, sql, yaml, markdown and diff, Shiki as the exact engine (the `/shiki` entry below), or bring your own.
DataDescriptionList (inline, stacked, grid), JsonViewer (fold, search, copy path as JS / JSON Pointer / jq, tree keys), Timeline (icons, tones, groups, relative times).
MetricsStatCard, StatGrid, KpiTile, KpiStrip, Sparkline (the charts kit's sparkline with a trend-picked tone), TrendBadge; `invert` for metrics where down is good.
People and labelsPersonAvatar, AvatarStack (optional colour ring per person), PresenceDot, PersonLabel, PersonCard (a full-width person row: avatar, name, secondary line, trailing slot, optionally a button), StatusBadge, StatusDot (general status in the badge tones, pulse, sizes), CountBadge, Tag, TagList.
FormattersFormatNumber (decimal, currency, percent, unit, compact), FormatBytes (binary KiB or decimal kB), FormatDate (a `<time dateTime>`), RelativeTime (live: ticks every second, minute or hour by distance; SSR-safe). All read the formatter adapter; each takes its own `locale`.
SurfacesCarousel (scroll-snap, keys, loop, autoplay), DisplayAccordion, DisplayTabs (underline, pills, segmented, enclosed), Hint, InfoHint, PreviewCard, Kbd (from the keyboard kit), ZoomImage and ImageGallery (grid, mosaic or masonry, on the overlay kit's Lightbox), and Masonry with MasonryItem (mixed heights packed into columns, the DOM and Tab order kept in source order).
Compound partsEvery stateful preset is built only from public parts you can recompose: CodeBlock.Root / Header / Title / Language / WrapToggle / Copy / Body / Line, JsonViewer.Root / Toolbar / Search / MatchCount / Tree / Row, Carousel.Root / Viewport / Track / Prev / Next / Dots / PlayToggle, Timeline.Root / Group / Item / Dot / Content / Time, StatCard.Root / Label / Value / Footnote, StatusDot.Root / Indicator / Label, DescriptionList.Root / Item / Term / Details. Presets take `className` plus `classNames` per part; state is controlled or uncontrolled.
AdaptersDisplayProvider swaps the highlighter, the clipboard, the number, byte, date and time formatters and the avatar palette for everything below it; the defaults are the built-in tokenizer, the Clipboard API, Intl and a hue per name.
/coreFramework-free, no DOM: highlightLines, parseLineRanges, the JSON model (flattenJson, searchJson, formatJsonPath), trendOf, formatNumber, formatBytes, formatDate, formatRelative, relativeTickMs, initials, splitOverflow, pageAt, groupConsecutive, masonryLayout and resolveMasonryColumns, and the adapter interfaces with their pure defaults.
/dom and /react/dom: navigatorClipboard, carousel scrolling and measuring, reduced motion. /react: DisplayProvider, HighlighterProvider, useHighlight, useControllableState, useRelativeClock, useCopy, and the markup-free useCodeBlock, useJsonTree and useCarousel for your own markup.
/shikishikiHighlighter(): Shiki behind the highlighting seam, from shiki/core with the JavaScript regex engine (no WASM), each grammar a lazy chunk; blocks show the built-in colours until their grammar loads, then exact, with the same lines. shiki is an optional peer.
