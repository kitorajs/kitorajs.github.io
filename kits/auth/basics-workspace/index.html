Basics: workspaces

The other half of the sidebar's WorkspaceSwitcher: a create-workspace form on the form engine (a name, an address suggested from it until you edit it, an optional availability check, a server error in place), the same form in a dialog for the switcher's actions, and the first-run page for a signed-in user with no workspace.
