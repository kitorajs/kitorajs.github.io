02Layers

One package, four layer entries plus the barrel; use only the core on a server, only the dom adapters or hooks with your own markup, or the styled parts and presets.

core@kitora/auth/coreThe adapter contracts (AuthAdapter, AccountAdapter, TeamAdapter) with coded results and in-memory fakes; the auth flow state machine; password policy and a pluggable strength estimator; the OTP input model; backup codes; TOTP secrets and otpauth URIs; a QR encoder; roles, permissions with dependencies, diffs, invites. No React, no DOM.
dom@kitora/auth/domBrowser behaviour behind adapters: ClipboardAdapter (browserClipboard), FileSaver (browserFileSaver, saveBackupCodes), capsLockOn. Imports only the core; no React.
react@kitora/auth/reactAuthKitProvider (adapters, policy, estimator, clipboard, file saver), useAuthAction, useOtpInput and usePasswordReveal (prop getters), usePasswordStrength, useRoleMatrix, useControllableState, useCooldown, useNow, useCopy, useQrCode. Headless: no styling.
ui@kitora/auth/ui (also the @kitora/auth barrel)Parts (AuthCard, AuthField, AuthInput, AuthMessage, SubmitButton, OtpInput, AuthPasswordInput (ui's PasswordInput wired to the field; a bare password input is @kitora/ui/password-input), PasswordStrengthMeter, PasswordChecklist, OAuthButtons, QrCode) and the presets built only from them: sign in, sign up, forgot and reset, two-step challenge, email verification, AuthFlow, account and security settings (framed by @kitora/shell's SettingsSection), role matrix, members, invites.
