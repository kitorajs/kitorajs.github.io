Get started

Use it your way.

ES modules only, with "use client" where the browser is needed, so a server component imports the components directly. Install what you use; your Tailwind build generates exactly their classes.

In a Tailwind CSS v4 app

Install the packages, then point your stylesheet at them.

pnpm add @kitora/ui @kitora/theme
@import "./tokens.css";
@import "@kitora/primitives/styles.css";
@import "@kitora/ui/tailwind.css";

The tokens come from @kitora/theme; the install guide has every step.

Without a build step

One HTML file: an import map names React once, esm.sh serves the packages as ES modules, and Tailwind's browser build styles them at runtime.
