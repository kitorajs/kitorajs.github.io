Packages

  • @kitora/ai-chat

    Kitora's AI chat UI: a framework-free chat core (message tree with branches, stream folding, streaming-safe markdown, a pluggable adapter seam with a scripted fake) with React bindings and styled parts: transcript, composer with attachments and slash commands, tool-call cards, agent step traces, a context-usage meter, a model selector, citations, reasoning, artifacts panel, conversation list.

  • @kitora/auth

    Kitora's auth and account UI: a framework-free core (adapter contract with a fake, password strength and policy, OTP model, backup codes, TOTP URIs, a QR encoder, sessions, roles and permissions, invites), a browser-behaviour layer (clipboard and file-save adapters), headless React hooks, and styled presets for sign in, sign up, password reset, two-step verification, email verification, account and security settings, and roles and members.

  • @kitora/charts

    Kitora's charts on plain SVG: line, area, bar (grouped, stacked, horizontal), combined, pie and donut, radar, radial bar, gauge, funnel, scatter, sparkline and heatmap, plus a ranked bars list in HTML, with axes, legends, crosshair tooltips, a table fallback, keyboard reading, SVG and PNG export and light and dark palettes. Scale and shape maths live in the kit; no chart library.

  • @kitora/chat

    Kitora's messaging and collaboration kit: a framework-free chat core (timeline grouping, reactions, mentions, receipts, a pluggable realtime adapter with a fake one for demos), anchored comment threads, an activity feed and an audit log with diffs, plus compact styled React parts.

  • @kitora/collab

    Kitora's real-time collaboration primitives: presence with idle and away, live cursors, shared selection highlights, follow mode and an undo/redo history with time travel, over a transport-agnostic adapter (BroadcastChannel, in-memory, Yjs awareness).

  • @kitora/collections

    Kitora's collection components: one headless collection model (items, sections, selection, disabled, typeahead, virtual window, async loading, trees) with APG-correct Listbox, Select, Combobox, MultiSelect, TagsInput, Menu, Menubar, ContextMenu, Toolbar, TreeView (drag to reorder, inline rename, and a FileTree preset of folders and files), TreeSelect and Cascader on it.

  • @kitora/commerce

    Kitora's commerce kit: pricing tables with a billing toggle and comparison matrix, a cart with coupons and tax, a checkout flow with a card field that never stores data, order summaries and invoices, and a Calendly-style booking widget across time zones, on a framework-free core with pluggable adapters.

  • @kitora/datagrid

    Kitora's headless, adapter-driven datagrid: providers, filters, sort, pagination, infinite scroll, layouts (table, cards, kanban, media grid), saved views, row reorder and the styled parts.

  • @kitora/display

    Kitora's data display components: code blocks with a built-in highlighter, description lists, a JSON viewer, timelines, stat cards with sparklines, avatars with presence, person cards, badges, count badges and tags, a copy button, a carousel, a masonry layout that keeps reading order, accordion and tab variants, hints, hover cards and an image gallery on the overlay kit's Lightbox.

  • @kitora/dnd

    Kitora's drag-and-drop kit: a framework-free engine, DOM sensors and presentation, trees, React bindings, styled presets, an HTML5 bridge and devtools.

  • @kitora/dock

    Kitora's docking engine: an n-ary layout model with a pure reducer and size solver, the one SplitView splitter, tab groups, floating windows and popouts, and React bindings with styled parts.

  • @kitora/editors

    Kitora's editors: a Tiptap rich-text editor (compact toolbar, bubble menu, slash commands, mentions, links, tables, code blocks, images, markdown import and export), a markdown editor with live preview, and a CodeMirror 6 code editor, with shortcuts on the keyboard kit.

  • @kitora/feedback

    Kitora's feedback kit: toasts (queue, stacking, swipe, pause, undo, promise, dedupe, positions) with an imperative API and a provider, a notification inbox with a bell, banners and inline alerts (on the ui Alert primitive), progress, the stepper (Stepper parts, Steps and StepProgress), spinners, skeletons, empty states and result pages, on a framework-free core.

  • @kitora/flow

    Kitora's node and flow editor: a framework-free graph core (ports, edges, viewport, layered auto-layout, connection rules, undo history, clipboard, JSON) with a React canvas on the dnd kit's activation and interactive-press rules and the keyboard kit's keymap (pan, zoom, pinch, drag, marquee, connect, snap and guides, keyboard) and styled minimap, controls and node cards.

  • @kitora/form

    Kitora's form engine: a framework-free core, React bindings, the field catalog, auto forms, data sources, server validation, Yjs collaboration and devtools.

  • @kitora/form-builder

    Kitora's visual form builder: a field palette, a drag-to-reorder canvas of live widgets, a properties panel (label, name, required, rules, options, conditions, default), sections and wizard steps, preview, undo and redo, and export / import as the form engine's JSON definition rendered by AutoForm.

  • @kitora/i18n

    Kitora's shared message catalog: typed per-kit namespaces with English defaults, locale bundles with fallback (de-AT → de → en), single-key overrides, {name} interpolation and Intl.PluralRules plurals, a nesting I18nProvider with no global state, and a locale-to-direction bridge to the theme kit.

  • @kitora/keyboard

    Kitora's keyboard kit: a framework-free command registry, keybinding layers with user overrides, when-clauses, chords and sequences, conflict analysis, DOM dispatch, roving focus, React bindings, a VS Code-style shortcuts editor, a cheatsheet, palette rows and key hints.

  • @kitora/maps

    Kitora's maps and location kit: a framework-free geo core (bounds, distance, clustering, routes, a geocoder adapter, an autocomplete state machine), a MapLibre engine seam, React parts (map, markers, popups, clusters, routes) and styled presets (location picker, address autocomplete). Each layer is its own entry (`/core`, `/dom`, `/react`, `/ui`), plus opt-in `/samples` data. No API keys.

  • @kitora/overlay

    Kitora's overlay stack: a headless core, React bindings, styled presets, a router adapter and an imperative API.

  • @kitora/pickers

    Kitora's date, time and colour pickers: typed-segment date and time fields, calendars (single, multiple, range), range presets, month, year, week and quarter pickers, datetime, a time-zone picker, an RRULE recurrence editor, a colour picker and an emoji picker, on a framework-free core with Intl locales and RTL.

  • @kitora/primitives

    Kitora's own headless primitives: renderer-neutral state and maths (core), DOM behaviour (dom) and unstyled React parts (react), plus the behaviour stylesheet (state-attribute variants, enter and exit animations) the styled packages rely on. Nothing third-party but React.

  • @kitora/scheduling

    Kitora's scheduling kit: an event calendar (month, week, day, agenda, resource timeline) with drag to move, resize and create, all-day lanes, overlap layout, time zones and RRULE expansion, plus a Gantt chart with dependencies, drag bars, zoom levels and a today line, on a framework-free core.

  • @kitora/search

    Kitora's search and data tools: a framework-free search core (ranking, grouping, facets, highlight, recents), a visual query builder model (AND/OR groups, typed operators, JSON, evaluation), a CSV import pipeline (parse, map, validate), and styled React parts for each.

  • @kitora/shell

    Kitora's application shell: a thin composition of @kitora/sidebar with a header (breadcrumbs, search, notifications, user menu), page header with tabs, a resizable inspector on the dock's SplitView, a status bar, a mobile drawer, and layout presets (sidebar, double sidebar, top nav, settings).

  • @kitora/sidebar

    Kitora's application sidebar: a framework-free nav model (tree, sections, badges, active matching, moves, persisted state) with React bindings, resize on the dock's SplitView, drag reorder on the dnd kit, and styled ClickUp / Slack / Linear / VS Code / Notion-grade presets.

  • @kitora/spreadsheet

    Kitora's spreadsheet grid in layers: a framework-free sheet model (addresses, a pluggable formula engine with dependency-ordered recalculation, selection, clipboard codecs, fill series, sort, undo), headless grid behaviour, unstyled React hooks, and styled compound parts (toolbar, formula bar, virtualised grid, status bar) with a preset built from them.

  • @kitora/tabster

    Kitora's tabbed dock, a preset on @kitora/dock: panels, persistence adapters, group names, outliner, arrange overlay and keyboard handling.

  • @kitora/task-list

    Kitora's headless, adapter-driven task lists: provider, list and kanban boards with drag, filters, saved views, bulk actions and the styled parts.

  • @kitora/terminal

    Kitora's developer views: a terminal emulator view (ANSI colours, cursor, scrollback, input with history, pluggable session adapter), a virtualised log viewer (levels, filter, search, follow tail, JSON expansion), a split and unified diff viewer with word-level highlighting, and a JSON / YAML tree diff, on a framework-free core that stays fast at 100k lines.

  • @kitora/theme

    Kitora's foundations and theming: OKLCH colour scales from one brand colour with contrast-checked foreground pairs, radius / spacing / type / density scales, a ThemeProvider (light, dark, system, per-subtree themes, density), CSS-variable and Tailwind exporters, a live theme designer and a WCAG contrast checker.

  • @kitora/tour

    Kitora's onboarding kit: a framework-free tour machine (steps, progress, resume, route-aware), spotlight maths, checklist and announcement models, with headless React hooks and styled presets (tour popover on the overlay kit, beacons, coach marks, onboarding checklist, what's new); the stepper is re-exported from the feedback kit.

  • @kitora/ui

    Kitora's styled components in the shadcn style, on @kitora/primitives and Tailwind v4, one entry per component, and the cn helper.

  • @kitora/upload

    Kitora's files and media kit: a dropzone with validation, an upload queue on a pluggable (and chunked, resumable) adapter, an image cropper, avatar upload, a media library, and image, PDF, video and audio viewers.

  • @kitora/whiteboard

    Kitora's whiteboard: an SVG infinite canvas (shapes, freehand, select / move / resize / rotate, groups, z-order, undo, SVG / PNG / JSON) on a framework-free pointer engine, plus a mind map and an org chart on the same camera and tree layout.

  • @kitora/windows

    Kitora's floating window manager: a framework-free core (states, snapping, z-order, persistence) with DOM gestures, React bindings and macOS / Windows / neutral chrome presets.
