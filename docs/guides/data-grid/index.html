The data grid

Columns, selection, editing, cell ranges and the clipboard.

This guide builds on a first data table: a DataGrid inside DataGridUIProvider and DataGridProvider, fed by an adapter. Each example here uses the in-memory adapter from @kitora/datagrid; an adapter for your API has the same shape, and editing needs its updateRow.

Columns

defineColumns<Row>() types the column list against your row. Each column has an id, a header and a cell that draws the cell from its row, so a cell can be any element: a bold name, a formatted price. meta adds the rest: sortFieldId turns the header into a sort button for that field, and align: "right" lines numbers up on the right. A column without sortFieldId has a plain header.

Selection

selectable adds a checkbox to every row and a select-all box in the header. Shift-click a second row's checkbox to select every row between it and the last one you clicked. DataGridSelectionIndicator shows how many rows are selected, with a Clear button, and hides while nothing is.

Products

Category

Try it: sort by price, check the first row, then Shift-click the third.

Editing

A column with meta.edit edits in place. Its type picks the editor (text, number or select), and patch turns the editor's value into the change your adapter's updateRow saves. Double-click a cell to open its editor; Enter saves, Escape cancels. A select column opens straight into its list, and picking an option saves it.

Cell ranges and the clipboard

cellSelection makes the table a spreadsheet-style grid whose cells share one tab stop, the focused cell. Shift with the arrow keys selects a rectangle of cells, and Mod+C copies it as tab-separated text, the format spreadsheets copy and paste.

Mod+V goes the other way: it writes the pasted cells from the focused cell into the editable columns, through the same patch and updateRow, and skips cells it may not edit. One value pasted over a selected range fills every cell of it.

Try it: click Alex's Monday, press Shift+Down and Shift+Right, copy, and paste into a spreadsheet; or copy a cell from a spreadsheet and paste it over a range here. The DataGrid reference lists every prop, among them copyHeaders and clipboardCodec for the clipboard.
