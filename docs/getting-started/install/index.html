Getting started

Install

The packages, the install line, the CSS your Tailwind build reads and the design tokens.

Kitora is a set of packages under the @kitora scope; install the ones you use. Each package's page lists its entries, their size budgets and its dependencies.

  • @kitora/ui · 87 entries

    Kitora's styled components in the shadcn style, on @kitora/primitives and Tailwind v4, one entry per component, and the cn helper.

  • @kitora/form · 8 entries

    Kitora's form engine: a framework-free core, React bindings, the field catalog, auto forms, data sources, server validation, Yjs collaboration and devtools.

  • @kitora/datagrid · 1 entry

    Kitora's headless, adapter-driven datagrid: providers, filters, sort, pagination, infinite scroll, layouts (table, cards, kanban, media grid), saved views, row reorder and the styled parts.

  • @kitora/overlay · 1 entry

    Kitora's overlay stack: a headless core, React bindings, styled presets, a router adapter and an imperative API.

  • @kitora/theme · 5 entries

    Kitora's foundations and theming: OKLCH colour scales from one brand colour with contrast-checked foreground pairs, radius / spacing / type / density scales, a ThemeProvider (light, dark, system, per-subtree themes, density), CSS-variable and Tailwind exporters, a live theme designer and a WCAG contrast checker.

Install

Start with the styled components. The line below adds the package, the primitives whose behaviour stylesheet it needs, and its peers:

pnpm add @kitora/ui @kitora/primitives react react-dom tailwindcss

Before the npm release: install from GitHub

Kitora is not on npm yet. Until it is, the packages install from the public repository kitorajs/packages, which holds every package built, as it will be published, one tagged snapshot at a time. Install them with pnpm (npm, Yarn and Bun cannot install a folder of a git repository):

pnpm add "github:kitorajs/packages#path:/ui" "github:kitorajs/packages#path:/primitives" react react-dom tailwindcss

pnpm 11 and later refuse git dependencies inside git dependencies unless the app allows it in its pnpm-workspace.yaml:

Every @kitora/* package of a snapshot depends on the others at that same snapshot, so an app gets one copy of each. pnpm update "@kitora/*" --latest moves them all to the newest snapshot together. The starter is a ready Vite app set up this way.

CSS

The components carry Tailwind v4 class names, so your own Tailwind build generates their CSS, for the packages you use only. Put these imports in the CSS file your build reads:

@import "tailwindcss";
@import "@kitora/primitives/styles.css";
@import "@kitora/ui/tailwind.css";

Each package you add has its own tailwind.css; its page shows the line. For a smaller stylesheet, @kitora/ui also has one file per module (@kitora/ui/tailwind/button.css and so on).

Design tokens

The classes read design tokens (--background, --primary, --radius and the rest) through Tailwind theme variables. Generate them with @kitora/theme: the stylesheet it writes starts with @import "tailwindcss", so it takes that line's place. With no options it is exactly this site's theme: the colours, radius and type, the Geist font stacks (load Geist itself, for example @fontsource-variable/geist), shadows, status colours and the base rules (a bare border or outline takes the theme's colours instead of Tailwind v4's text colour).
