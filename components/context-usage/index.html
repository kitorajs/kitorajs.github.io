ContextUsage

How much of a model's context window a conversation has used: a ring and percent for a composer toolbar, with the used and maximum tokens, a bar, a breakdown and the cost in a popover. Built on the feedback Meter; the ai-chat kit's ContextUsage.

Source: @kitora/ai-chat (the single implementation; no other package ships one)

Full API on the ai-chat kit gallery

Built frompopoverMeter · feedback
  • On this page:
  • In a toolbar
  • Zones
  • Breakdown and cost
  • In a composer
  • API reference
  • Anatomy

01In a toolbar

A ring and the rounded percent; press it (click, Enter or Space) for the details. size="sm" draws a 16px ring with 11px text.

02Zones

Under 70% of max the ring is green, up to 90% amber, above it red: the feedback Meter's zones with optimum 0. low and high move the thresholds, in tokens.

03Breakdown and cost

breakdown lists input, output, reasoning and cached tokens, and cost adds a row through formatCost (US dollars by default).

04In a composer

A Textarea and a send Button with ContextUsage in the toolbar; each send adds the message and a reply to what is used.

Props

ContextUsage

The context window as a compact ring for a composer toolbar, with the details in a popover.

  • usedrequirednumber

    Tokens used so far.

  • maxrequirednumber

    The model's context window, in tokens.

  • breakdownContextUsageBreakdown

    Where the used tokens went; each given row is listed in the details.

  • costnumber

    What the conversation has cost so far, shown in the details through formatCost.

  • formatCost(cost: number) => string

    Default US dollars through `Intl.NumberFormat` (two to four decimals)

    Formats cost.

  • lownumber

    Default 70% of `max`

    From this many tokens the meter reads suboptimal.

  • highnumber

    Default 90% of `max`

    Above this many tokens the meter reads critical.

  • sizekeyof typeof SIZES

    Default "md"

    The trigger's size: a 16px ring with 11px text, or a 20px ring with 12px text.

  • localeIntl.LocalesArgument

    The locale numbers are formatted in; the runtime's default when unset.

  • labelsPartial<ContextUsageLabels>

    Words to replace (merged over {@link DEFAULT_CONTEXT_USAGE_LABELS}).

  • side"top" | "bottom"

    Default "top"

    Which side of the trigger the details open on.

  • openboolean

    Whether the details are open (controlled).

  • defaultOpenboolean

    Default false

    Whether the details start open (uncontrolled).

  • onOpenChange(open: boolean) => void

    Called when the details open or close.

  • classNamestring

    Classes on the trigger.

  • classNamesContextUsageClassNames

    Default {}

    Classes per part.

  • childrenReactNode

    Extra content at the end of the details (a link to usage settings, a "compact" action).

Hooks and functions

  • CONTEXT_USAGE_HIGH

    The default high threshold, as a share of max: above it the meter reads critical.

  • CONTEXT_USAGE_LOW

    The default low threshold, as a share of max: from here the meter reads suboptimal.

  • DEFAULT_CONTEXT_USAGE_LABELS

    The English labels.
