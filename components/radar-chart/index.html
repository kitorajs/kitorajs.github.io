RadarChart

Radar (spider) chart comparing several metrics across series on plain SVG: polygon or circle grid, rings, stripes, fill and dots, highlight by axis with a tooltip, legend toggles, arrow-key reading and a table view. The charts kit's RadarChart; every chart lives on /kits/charts.

Source: @kitora/charts (the single implementation; no other package ships one)

Full API on the charts kit gallery

Built fromChart · chartsChartFrame · chartsPolar · charts

01Default

One row per axis (axis) and one closed shape per series. Hover near a spoke, or focus the plot and use the arrow keys, to read every series on that axis.

02Grid shape, rings and stripes

shape="polygon" (the default) or "circle", rings for the ring count, stripes to shade alternate bands, domain to fix the scale.

03Fill and dots

fill={false} draws outlines only, dots marks every point; colours come from the palette or each series' color.

04Missing values

A null value sits at the centre so the shape stays closed, has no dot, and reads as "missing" in the tooltip, the live region and the table.

05Controlled axis and series

activeIndex / onActiveIndexChange drive the highlighted axis from outside; hidden / onHiddenChange own the legend toggles.

Hidden: cleo

06Download as SVG or PNG

exportFormats adds a download button per format before the Table toggle; the file carries the title and the legend, so it stands alone outside the page.

Props

RadarChart<T>

A radar (spider) chart. Hover or arrow keys pick an axis: its spoke is emphasised, each visible series' point on it is ringed and the tooltip lists every value on it. Legend entries toggle series.

  • datarequiredreadonly T[]

    The rows, one per axis (metric).

  • axisrequired(row: T) => string

    Reads an axis' name (the metric).

  • seriesrequiredreadonly ChartSeries<T>[]

    The series compared; each reads one value per axis. color defaults to the palette slot at its position.

  • titlerequiredstring

    The chart's name; shown in the header and used as the accessible name and table caption.

  • domainreadonly [number, number]

    Fixes the value range from the centre outwards; default a nice 0..max over every series.

  • shapePolarGridShape

    Default "polygon"

    The grid: polygons through the spokes, or circles.

  • ringsnumber

    How many grid rings; default nice ticks for the domain.

  • fillboolean

    Default true

    Whether to fill each shape (translucent) under its outline.

  • dotsboolean

    Default false

    Whether to draw a dot on every point.

  • stripesboolean

    Default false

    Whether to shade alternate bands between the rings.

  • formatValue(value: number) => string

    Formats values in the tooltip, the live region, the table and the radius axis. Default: the formats adapter's number.

  • heightnumber

    Default 280

    Plot height in pixels; the circle fits min(width, height).

  • legendLegendPosition

    Where the legend sits, or none; when unset it is top with several series and none with one.

  • tooltipboolean

    Default true

    Whether to show the tooltip for the active axis.

  • renderTooltip(readout: Readout, index: number) => ReactNode

    Replaces the tooltip's content; given the readout (axis, rows) and the active axis index.

  • onActiveChange(index: number | null) => void

    Called as the reader moves between axes (pointer or keyboard), with the axis index; null when they leave.

  • hideTitleboolean

    Whether to hide the title visually; screen readers still hear it.

  • descriptionReactNode

    One sentence under the title.

  • summarystring

    Screen reader summary; each chart has an automatic one.

  • tableToggleboolean

    Default true

    Whether to show the "Table" toggle in the header. The hidden table for screen readers is always there.

  • animateboolean

    Whether marks animate in; on unless false (the reader's reduced-motion setting still wins).

  • classNamestring

    Classes added to the figure element.

  • classNamesChartClassNames

    Extra classes per frame part.

  • actionsReactNode

    Extra header controls (a range picker, a mode switch), placed left of the Table toggle.

  • exportFormatsreadonly ChartExportFormat[]

    Default []

    Download buttons in the header, one per format, before the Table toggle (Chart.Export); none unless set.

  • showTableboolean

    Show the table instead of the plot (controlled).

  • defaultShowTableboolean

    Default false

    Whether the table shows at first (uncontrolled).

  • onShowTableChange(showTable: boolean) => void

    Called when the reader switches between plot and table, with true for the table.

  • hiddenReadonlySet<string>

    Hidden series keys (controlled).

  • defaultHiddenreadonly string[]

    Hidden at first (uncontrolled).

  • onHiddenChange(hidden: ReadonlySet<string>) => void

    Called when a series is shown or hidden, with the new set of hidden keys.

  • activeIndexnumber | null

    The active row index, null for none (controlled).

  • defaultActiveIndexnumber | null

    The active row at first (uncontrolled); null for none.

  • onActiveIndexChange(index: number | null) => void

    Called when the active row changes, with its index or null when the reader leaves.
