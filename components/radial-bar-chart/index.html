RadialBarChart

Concentric bars against one full sweep (the largest value or a goal) on plain SVG: faint tracks, rounded ends, a 0° to 270° default sweep, input order or sorted, labels at the bar starts or a legend, arrow-key reading and a table view. The charts kit's RadialBarChart.

Source: @kitora/charts (the single implementation; no other package ships one)

Full API on the charts kit gallery

Built fromChart · chartsChartFrame · chartsPolar · charts

01Default

label and value per row, max for the full sweep (default the largest value). Hover a ring, or focus the plot and use the arrow keys.

02Sweep

startAngle and endAngle in degrees clockwise from 12 o'clock; the default 0° to 270° keeps the longest bar from closing into a ring.

03Tracks, labels and the legend

track={false} drops the faint track, labels={false} moves the names into the legend, barSize and gap set the rings.

04Sort and colours

sort puts the largest outermost; each bar keeps the colour of its input position, or the one color returns.

05Download as SVG or PNG

exportFormats adds a download button per format before the Table toggle; the file carries the title and the legend, so it stands alone outside the page.

Props

RadialBarChart<T>

Concentric bars against a common full sweep: goals, quotas, storage per kind. Hover a ring or step with the arrow keys to read a bar ("Storage: 72 of 100, 72%"); the others fade.

  • datarequiredreadonly T[]

    The rows, one per bar; the first is the outermost ring.

  • labelrequired(row: T) => string

    Reads a bar's name, shown at its start, in the tooltip and the table.

  • valuerequired(row: T) => number

    Reads a bar's value; negative values count as zero.

  • color(row: T, index: number) => string

    Per-bar colour; defaults to the categorical slot at the row's input position (kept when sorted).

  • titlerequiredstring

    The chart's name; shown in the header and used as the accessible name and table caption.

  • maxnumber

    The value of a full sweep (a goal such as 100); default the largest value. A value past it stops at the end.

  • startAnglenumber

    Default 0

    Where every bar starts, degrees clockwise from 12 o'clock.

  • endAnglenumber

    Default 270

    Where a full bar ends, degrees clockwise from 12 o'clock.

  • trackboolean

    Default true

    Whether to draw a faint full-sweep track behind each bar.

  • barSizenumber

    Each bar's thickness in pixels; default fitted to the plot (6 to 28).

  • gapnumber

    Default 4

    The space between bars in pixels.

  • sortboolean

    Default false

    Whether to order bars largest first (outermost); false keeps the input order.

  • labelsboolean

    Default true

    Whether to write each bar's name at its start.

  • formatValue(value: number) => string

    Formats values in the tooltip, the live region, the legend and the table. Default: the formats adapter's number.

  • heightnumber

    Default 260

    Plot height in pixels; the circle fits min(width, height).

  • legendLegendPosition

    Where the legend (each bar with its value) sits, or none; when unset it is none with labels and bottom without.

  • tooltipboolean

    Default true

    Whether to show the tooltip for the active bar.

  • renderTooltip(readout: Readout, index: number) => ReactNode

    Replaces the tooltip's content; given the readout and the active bar's index.

  • onActiveChange(index: number | null) => void

    Called as the reader moves between bars (pointer or keyboard), with the bar's index; null when they leave.

  • hideTitleboolean

    Whether to hide the title visually; screen readers still hear it.

  • descriptionReactNode

    One sentence under the title.

  • summarystring

    Screen reader summary; each chart has an automatic one.

  • tableToggleboolean

    Default true

    Whether to show the "Table" toggle in the header. The hidden table for screen readers is always there.

  • animateboolean

    Whether marks animate in; on unless false (the reader's reduced-motion setting still wins).

  • classNamestring

    Classes added to the figure element.

  • classNamesChartClassNames

    Extra classes per frame part.

  • actionsReactNode

    Extra header controls (a range picker, a mode switch), placed left of the Table toggle.

  • exportFormatsreadonly ChartExportFormat[]

    Default []

    Download buttons in the header, one per format, before the Table toggle (Chart.Export); none unless set.

  • showTableboolean

    Show the table instead of the plot (controlled).

  • defaultShowTableboolean

    Default false

    Whether the table shows at first (uncontrolled).

  • onShowTableChange(showTable: boolean) => void

    Called when the reader switches between plot and table, with true for the table.

  • activeIndexnumber | null

    The active row index, null for none (controlled).

  • defaultActiveIndexnumber | null

    The active row at first (uncontrolled); null for none.

  • onActiveIndexChange(index: number | null) => void

    Called when the active row changes, with its index or null when the reader leaves.
