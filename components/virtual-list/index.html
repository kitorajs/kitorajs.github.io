VirtualList

Renders only the visible rows of a huge list, fixed or measured heights, with scrollToIndex. The collections kit's VirtualList.

Source: @kitora/collections (the single implementation; no other package ships one)

Full API on the collections kit gallery

Props

VirtualList

See the file header.

  • renderItemrequired(index: number, item: VirtualItem) => ReactNode

    Draws row index.

  • itemClassNamestring

    Class names for every row.

  • classNamestring

    Class names for the scroll viewport.

  • aria-labelrequiredstring

    Accessible name of the scroll region.

  • heightnumber

    Default 320

    Viewport height in px.

  • rowHeightnumber

    Fixed row height in px (default 28 when estimateSize is absent).

  • handleRefRef<VirtualListHandle>

    scrollToIndex / scrollToOffset for the host.

  • countrequirednumber

    How many rows the list has.

  • estimateSize(index: number) => number

    Variable heights: the guess for a row before it is measured; mounted rows are then measured (measureElement).

  • overscannumber

    Default 6

    Rows mounted above and below the viewport.

  • scrollOffsetnumber

    Controlled scroll offset in px; pair with onScrollOffsetChange.

  • defaultScrollOffsetnumber

    Uncontrolled starting offset in px.

  • onScrollOffsetChange(offset: number) => void

    Called when the scroll offset changes, with the new offset in px.

  • getItemKey(index: number) => string | number

    React key of row index (default the index).

VirtualListContent

The spacer of a VirtualList, sized to every row's total height; calls its child function for each mounted row.

  • classNamestring

    Class names for the spacer.

  • childrenrequired(item: VirtualItem) => ReactNode

    One mounted row; usually a VirtualList.Item.

VirtualListItem

One row of a VirtualList, placed at its offset; measured for its height when the list has estimateSize.

  • itemrequiredVirtualItem

    The mounted row this element draws.

  • classNamestring

    Class names for the row.

  • styleCSSProperties

    Inline style, merged over the row's position.

  • childrenrequiredReactNode

    The row's content.

VirtualListRoot

The scroll viewport of a VirtualList: owns the list state and gives it to the parts inside.

  • aria-labelrequiredstring

    Accessible name of the scroll region.

  • heightnumber

    Default 320

    Viewport height in px.

  • handleRefRef<VirtualListHandle>

    scrollToIndex / scrollToOffset for the host.

  • classNamestring

    Class names for the scroll viewport.

  • childrenrequiredReactNode | ((list: VirtualListState) => ReactNode)

    The parts inside, or a function of the list state that returns them.

  • countrequirednumber

    How many rows the list has.

  • rowHeightnumber

    Fixed row height in px (default 28 when estimateSize is absent).

  • estimateSize(index: number) => number

    Variable heights: the guess for a row before it is measured; mounted rows are then measured (measureElement).

  • overscannumber

    Default 6

    Rows mounted above and below the viewport.

  • scrollOffsetnumber

    Controlled scroll offset in px; pair with onScrollOffsetChange.

  • defaultScrollOffsetnumber

    Uncontrolled starting offset in px.

  • onScrollOffsetChange(offset: number) => void

    Called when the scroll offset changes, with the new offset in px.

  • getItemKey(index: number) => string | number

    React key of row index (default the index).
