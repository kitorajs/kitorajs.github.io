OTPField

One box per character of a one-time code: typing moves on, a paste or an autofill spreads the code, Backspace steps back, digits, letters or your own rule, a mask, completion and auto-submit. The `OTPField` preset (groups, sm / md / lg boxes from the `otp` slot, `name` posting the code) over the styled Base UI OTPFieldPreview parts; the pickers and auth kits' `OtpField` render them.

Source: @kitora/ui (the primitive the kits compose)

01Preset

OTPField renders length boxes (default 6) in groups with a separator between them (groupSize, default half of an even length above 4), each named "<group>, character N of M" from labels, and onComplete fires once the last box is filled.

04Parts

The parts the preset is made of: OTPFieldRoot, OTPFieldInput, OTPFieldSeparator (and OTPFieldGroup). Typing moves on, a paste or an autofill spreads the code, Backspace steps back and onValueComplete fires once the last box is filled.

05Validation types

validationType numeric (default), alpha, alphanumeric or none with your own sanitizeValue; mask hides the characters.

Props

OTPField

The one-time-code preset: length boxes in groups with a separator between them (groupSize), sized by size from the otp slot, charset numeric or upper-cased alphanumeric, onComplete once the last box is filled, invalid, autoFocus (the first empty box), autoComplete="one-time-code" on the first box (an autofilled code spreads), name posting the code, each box named "One-time code, character N of M" (labels). Keyboard and ARIA are the primitives' (typing advances, paste and autofill spread, Backspace steps back, arrows, Home / End, right to left flips the arrows). The pickers kit's OtpField, the auth kit's re-export and the form kit's OTPField render this.

  • groupSizenumber | null

    Insert a separator after this many boxes (3 for "123–456"). Default: half of length when it is even and above 4, none otherwise; null for none.

  • sizeOTPFieldSize

    The box size for every box (unset or md keeps the otp slot's box).

  • labelsPartial<OTPFieldLabels>

    The strings; label (kept from the pickers kit) sets labels.group too.

  • namestring

    Posts the code with a surrounding <form>.

  • formstring

    The form the code posts into.

  • requiredboolean

    A surrounding <form> refuses to submit until every box is filled.

  • idstring

    The id of the first box.

  • classNamestring

    Classes for the root, merged after classNames.root.

  • classNames{ readonly root?: string; readonly group?: string; readonly slot?: string; readonly separator?: string }

    Default {}

    Classes for the root, each group, each box and each separator.

  • lengthnumber

    Slots. Default 6.

  • valuestring
  • defaultValuestring
  • onValueChange(value: string) => void
  • onComplete(value: string) => void

    Fires once when the last slot is filled.

  • charsetOtpCharset
  • disabledboolean
  • invalidboolean
  • autoFocusboolean

    Focus the first empty slot on mount.

  • labelstring

    Group label for screen readers. Default "One-time code".

  • autoCompletestring

    Autofill hint on the FIRST slot (the whole code then spreads). Default "one-time-code".

OTPFieldInput

One box of the code.

  • sizeOTPFieldSize

    Opt-in box size, written as data-size (unset or md keeps the slot's box).

  • indexnumber

    The slot's place when it is known at render time (Kitora): the first render and a server render then show the slot's character; without it the place is read from the DOM order after the slots mount.

OTPFieldRoot

A one-time-code field: one box per character. Typing moves on, a paste or an autofill spreads the whole code, Backspace steps back and the arrow keys move between boxes. length boxes need length OTPFieldInput inside; validationType picks digits, letters or both, mask hides the characters and onValueComplete fires once the last box is filled. Works with Field (the label names the group and the first box). Built from Base UI's OTPFieldPreview parts.

  • idstring

    The id of the first input (the one a <label> points at); the others are <id>-2, <id>-3...

  • autoCompletestring

    Default "one-time-code"

    The autocomplete of the first input: the autofill target of an SMS or mail code.

  • formstring

    Identifies the form that owns the field, for a field rendered outside it.

  • lengthrequirednumber

    The number of slots (and so of OTPFieldPreview.Input parts).

  • autoSubmitboolean

    Default false

    Submit the enclosing form when the last slot is filled.

  • maskboolean

    Default false

    Hide the typed characters (type="password" slots).

  • inputModeReact.HTMLAttributes<HTMLInputElement>["inputMode"]

    The soft keyboard hint; defaults from validationType.

  • validationTypeOTPValidationType

    Default "numeric"

    What a slot accepts: digits, letters, both, or anything sanitizeValue lets through.

  • sanitizeValue(value: string) => string

    Cleans typed or pasted text when validationType is none.

  • requiredboolean

    Whether every slot must be filled before the form submits.

  • disabledboolean

    Whether the field ignores user interaction.

  • readOnlyboolean

    Whether the user cannot change the code; the slots stay focusable.

  • namestring

    Identifies the field when a form is submitted.

  • valuestring

    The code (controlled); pair with onValueChange.

  • defaultValuestring

    The code at first (uncontrolled).

  • invalidboolean

    Marks every slot aria-invalid (a Field.Root does so through its own validity).

  • onValueChange(value: string, details: OTPFieldChangeEventDetails) => void

    Called when the code changes.

  • onValueInvalid(value: string, details: OTPFieldInvalidEventDetails) => void

    Called when typed or pasted text had characters the validationType refused.

  • onValueComplete(value: string, details: OTPFieldCompleteEventDetails) => void

    Called once when the code fills every slot.

Plus render, and className / style as functions of the part's state, and every <div> prop.
