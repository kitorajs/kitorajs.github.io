ColorPicker

Colour panel with area, hue and alpha sliders, typed values and presets, inline or in a popover, plus ColorSwatches on its own. The pickers kit's ColorPicker.

Source: @kitora/pickers (the single implementation; no other package ships one)

Full API on the pickers kit gallery

Props

ColorPicker

The inline colour panel (see file header), plus its parts for composing your own.

  • swatchesreadonly (string | ColorSwatchOption)[]

    Presets under the inputs: hex strings or { value, label }. Default {@link DEFAULT_COLOR_SWATCHES}; [] hides them.

  • swatchColumnsnumber

    Swatches per row. Default 8.

  • formatsreadonly ColorFormat[]

    Formats the inputs offer. Default hex, rgb, hsl.

  • eyeDropperboolean

    Offer the sampler (eyedropper) where supported. Default true.

  • samplerColorSampler

    The sampler behind the eyedropper button; default the browser's EyeDropper.

  • disabledboolean

    Whether every part is disabled (a surrounding Field's disabled also disables it).

  • classNamestring

    Extra classes for the panel (the popover's content box in ColorPickerPopover).

  • classNamesColorPickerClassNames

    One class per part (merged after the part's own classes).

  • valuestring

    Controlled colour (hex, rgb() or hsl()); leave undefined for an uncontrolled picker.

  • defaultValuestring

    Default "#000000"

    Initial colour when uncontrolled.

  • onChange(value: string) => void

    Receives canonical hex on every change.

  • alphaboolean

    Default true

    When false the colour is always opaque.

  • namestring

    Posts the colour with a surrounding <form> as canonical hex (#rrggbb, #rrggbbaa when not opaque); inside a Field the Field's name wins.

  • formstring

    The form the value posts into (a picker outside the <form> element).

  • requiredboolean

    Accepted for parity with the other pickers; a colour picker always holds a colour, so it never refuses a submit.

  • invalidboolean

    Force the invalid look (a Field's error sets it too).

  • idstring

    The control's id (the panel's group, the popover's trigger): a <label htmlFor> or a Field's label points at it.

ColorPickerPopover

A swatch button that opens {@link ColorPicker} in the overlay kit's Popover; changes apply live as you drag.

  • labelstring

    Accessible name of the trigger and the popover, e.g. "Background colour". Default "Colour".

  • showValueboolean

    Default true

    Whether to show the hex next to the trigger's swatch.

  • sidePopoverSide

    Default "bottom"

    The side of the trigger the popover opens on.

  • alignPopoverAlign

    Default "start"

    How the popover lines up with the trigger along that side.

  • triggerClassNamestring

    Extra classes for the trigger button.

  • swatchesreadonly (string | ColorSwatchOption)[]

    Presets under the inputs: hex strings or { value, label }. Default {@link DEFAULT_COLOR_SWATCHES}; [] hides them.

  • swatchColumnsnumber

    Swatches per row. Default 8.

  • formatsreadonly ColorFormat[]

    Formats the inputs offer. Default hex, rgb, hsl.

  • eyeDropperboolean

    Offer the sampler (eyedropper) where supported. Default true.

  • samplerColorSampler

    The sampler behind the eyedropper button; default the browser's EyeDropper.

  • disabledboolean

    Whether every part is disabled (a surrounding Field's disabled also disables it).

  • classNamestring

    Extra classes for the panel (the popover's content box in ColorPickerPopover).

  • classNamesColorPickerClassNames

    One class per part (merged after the part's own classes).

  • valuestring

    Controlled colour (hex, rgb() or hsl()); leave undefined for an uncontrolled picker.

  • defaultValuestring

    Default "#000000"

    Initial colour when uncontrolled.

  • onChange(value: string) => void

    Receives canonical hex on every change.

  • alphaboolean

    Default true

    When false the colour is always opaque.

  • namestring

    Posts the colour with a surrounding <form> as canonical hex (#rrggbb, #rrggbbaa when not opaque); inside a Field the Field's name wins.

  • formstring

    The form the value posts into (a picker outside the <form> element).

  • requiredboolean

    Accepted for parity with the other pickers; a colour picker always holds a colour, so it never refuses a submit.

  • invalidboolean

    Force the invalid look (a Field's error sets it too).

  • idstring

EyeDropperButton

Samples a colour through a ColorSampler; renders nothing where the sampler is unsupported.

  • onPickrequired(hex: string) => void

    Receives the picked colour as canonical hex.

  • samplerColorSampler

    Where the colour comes from; default the browser's EyeDropper (browserEyeDropper).

  • disabledboolean

    Whether the button is disabled.

  • classNamestring

    Extra classes for the button.

  • childrenReactNode

    Button content; default an eyedropper icon.

Hooks and functions

  • useColorPickerContext() => ColorPickerContextValue

    The colour state from the nearest ColorPicker.Root; throws outside one so a misplaced part fails loudly.

Features

  • DP78 Form binding for MonthPicker, YearPicker, DateRangePicker, ColorPicker and ColorPickerPopover: `name` (`startName` / `endName` on a range), `form` and `required` post with a plain `<form>` through the primitives' hidden inputs (nothing while disabled), an empty required picker refuses the submit and takes focus, and inside a ui `Field` the label names the control, its description and error describe it and its `disabled` and `invalid` reach it (pickers, live)
