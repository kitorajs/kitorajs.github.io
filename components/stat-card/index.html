Props

StatCard

A metric card: label, headline value with an optional sparkline, a trend badge and a footnote. Compose your own from StatCard.Root, Label, Value, Trend, Sparkline and Footnote.

  • labelrequiredReactNode

    What the value measures.

  • valuerequiredReactNode

    The formatted headline value.

  • currentnumber

    Numbers for the trend badge: the current and previous raw values.

  • previousnumber

    The previous raw value, compared with current for the trend badge.

  • invertboolean

    Whether down is good (latency, cost, errors), for the trend and the sparkline.

  • trendSuffixReactNode

    Text after the trend ratio (vs last week).

  • seriesreadonly number[]

    Series for the sparkline.

  • iconReactNode

    An icon before the label.

  • footnoteReactNode

    A small line under the value (a breakdown, a source).

  • hrefstring

    Makes the card a link or button-like surface.

  • classNamestring

    Class for the card.

  • classNamesStatCardClassNames

    A class per part: root, label, value, trend, footnote.

Sparkline

A tiny line chart of a series, coloured by its trend, for stat cards and table cells.

  • valuesrequiredreadonly number[]

    The data points, in order.

  • widthnumber

    Default 96

    Width of the drawing in px.

  • heightnumber

    Default 28

    Height of the drawing in px.

  • areaboolean

    Default true

    Fill under the line.

  • dotboolean

    Default true

    A dot on the last point.

  • toneSparkTone

    Default "auto"

    Colour; auto picks positive / negative from first → last (inverted with invert).

  • invertboolean

    Default false

    Whether down is good (latency, cost, errors), so a falling line reads positive under auto.

  • labelstring

    Accessible description; default "Trend from A to B".

  • classNamestring

    Class for the chart.

TrendBadge

The change from previous to current as an arrow and a signed ratio (+12.5%), coloured good or bad.

  • currentrequirednumber

    The value now.

  • previousrequirednumber

    The value to compare against.

  • invertboolean

    Default false

    Down is good (latency, cost, errors).

  • suffixReactNode

    Text after the ratio (vs last week).

  • format(ratio: number | null) => string

    Format the ratio yourself; default the formatter adapter's ratio (+12.5%).

  • classNamestring

    Class for the badge.

KpiTile

A compact tile: label over value with the trend inline, an optional sparkline strip and goal bar. Designed to sit in a row joined by dividers.

  • labelrequiredReactNode

    What the value measures.

  • valuerequiredReactNode

    The formatted headline value.

  • currentnumber

    The current raw value, for the trend badge.

  • previousnumber

    The previous raw value, compared with current for the trend badge.

  • invertboolean

    Whether down is good (latency, cost, errors), for the trend and the sparkline.

  • seriesreadonly number[]

    Series for the sparkline strip.

  • progressnumber

    Progress toward a goal: 0–1. Draws a bar under the value.

  • targetReactNode

    Text for the goal (of $120K target).

  • classNamestring

    Class for the tile.

KpiStrip

A row of KPI tiles joined by dividers in one bordered strip; wraps to 2 columns on narrow screens.

  • childrenrequiredReactNode

    The KpiTiles.

  • classNamestring

    Class for the strip.

StatGrid

Responsive grid for stat cards: 1 → 2 → columns.

  • childrenrequiredReactNode

    The stat cards.

  • columns2 | 3 | 4

    Default 4

    Columns on wide screens.

  • classNamestring

    Class for the grid.

Hooks and functions

  • SPARK_TONES

    The sparkline colours: auto (positive or negative from the trend), neutral, positive, negative and accent.
