Props

PricingTable

The preset: toggle, plan cards, and (when rows are given) the comparison matrix.

  • plansrequiredreadonly Plan[]

    The plans to show, in order.

  • intervalBillingInterval

    The billing interval, controlled; pair it with onIntervalChange.

  • defaultIntervalBillingInterval

    Default "month"

    The billing interval to start with, uncontrolled.

  • onIntervalChange(interval: BillingInterval) => void

    Called when the billing interval changes, with the new interval.

  • comparisonreadonly ComparisonRow[]

    The comparison rows; the table is shown only when given.

  • onSelect(plan: Plan, interval: BillingInterval) => void

    Called when a plan's button is pressed, with the plan and the chosen interval.

  • classNamestring

    Extra classes on the root element.

  • headingReactNode

    Content beside the interval switch, such as a title.

ComparisonCell

Default cell renderer: tick, dash, or the text / number.

  • valuerequiredComparisonValue

    The cell value: a tick for true, a dash for false or null, else the text or number.

Pricing

The pricing parts, for building your own layout.

Hooks and functions

  • usePricingContext() => PricingApi

    The pricing state of the nearest Pricing.Root.

  • INTERVAL_LABELS

    Interval labels; pass your own for other words or locales.

  • PLAN_FEATURE_NOT_INCLUDED

    Screen-reader words after an excluded feature (the strike-through alone is not announced).
