Props

RadioGroup

A group of radios with one value: RadioGroup from

  • orientation"vertical" | "horizontal"

    How the radios are laid out, written as data-orientation and aria-orientation: vertical (a column) or horizontal (a wrapping row). Layout and announcement only: the arrow keys stay the primitives' (both axes, as in Base UI; RTL flips left and right). Without it the group keeps today's grid and writes neither attribute.

  • valueValue

    The checked radio's value (controlled).

  • defaultValueValue

    The checked radio's value at first (uncontrolled).

  • onValueChange(value: Value, eventDetails: ChangeDetails) => void

    Called when the user checks a radio, with its value and the change details (details.cancel() vetoes).

  • disabledboolean

    Whether every radio in the group ignores user interaction.

  • readOnlyboolean

    Default false

    Whether the user cannot change the checked radio; the radios stay focusable.

  • requiredboolean

    Default false

    Whether a choice is needed before the form submits.

  • namestring

    The form field name the radios submit under.

  • inputRefReact.Ref<HTMLInputElement>

    A ref to the hidden input of the checked radio (the first enabled one while none is): the field's native constraint.

  • formstring

    The form the radios belong to.

  • idstring

    The group element's id, which an enclosing Field registers as its control.

  • enableHomeAndEndKeysboolean

    Default false

    Home and End move to the first and last enabled radio and check it (an extension; APG leaves them out of a radio group).

Plus render, and className / style as functions of the part's state, and every <div> prop.

RadioGroupItem

One radio in a RadioGroup: the themed circle and dot, with an optional label and description beside it.

  • valuerequiredValue

    The value this radio stands for; the group's value equals it while this radio is checked.

  • disabledboolean

    Default false

    Whether this radio ignores user interaction (the group's disabled also applies).

  • readOnlyboolean

    Default false

    Whether the user cannot check this radio; it stays focusable (the group's readOnly also applies).

  • requiredboolean

    Default false

    Whether a choice is needed before the form submits (the group's required also applies).

  • idstring

    The id of the hidden input, which is what a <label for> targets.

  • inputRefReact.Ref<HTMLInputElement>

    A ref to the hidden input.

  • nativeButtonboolean

    Default false

    Whether the rendered element is a native <button> (set it true when render gives one).

  • labelReact.ReactNode

    Visible label text rendered in a <label htmlFor> next to the control.

  • descriptionReact.ReactNode

    More about the choice, rendered under the label and announced with the control (aria-describedby).

  • wrapperClassNamestring

    Classes for the wrapper <span> that holds the control, label and description (only with label or description).

  • labelClassNamestring

    Classes for the rendered <label> (only with label).

  • descriptionClassNamestring

    Classes for the description <span> (only with description).

Plus render, and className / style as functions of the part's state, and every <span> prop.

Keyboard

RadioGroup

  • ArrowDownArrowRightRadio.RootMoves focus to the next radio and checks it, wrapping from the last to the first (ArrowRight moves to the previous one right to left).
  • ArrowUpArrowLeftRadio.RootMoves focus to the previous radio and checks it, wrapping from the first to the last (ArrowLeft moves to the next one right to left).

Radio

  • SpaceRadio.RootChecks the focused radio (Enter does nothing, so it never submits a form).

Accessibility

  • RadioGroup follows the WAI-ARIA Radio Group pattern: roles radiogroup, radio.
  • Radio follows the WAI-ARIA Radio Group pattern: roles radiogroup, radio.

Design-language slot

slots.radio Radio button (@kitora/ui/radio-group, one RadioGroupItem). A circle with a dot when selected.

  • size PxDiameter of the circle.
  • surface PerScheme<Fill>The empty circle's own fill per scheme; none shows the surface behind it.
  • edge PerScheme<Fill>The circle's 1px edge per scheme while empty (a selected circle's edge is primary); non-text UI wants 3:1 against the page.
  • fill ButtonFillFlat primary when selected, or a soft top-lit sheen over it (macOS).
  • elevation ElevationHow much the circle lifts off the page.
  • dotSize PxDiameter of the dot inside a selected circle.
  • focusRing FocusRingThe keyboard-focus indicator.
