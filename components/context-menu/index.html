Anatomy

Which part renders inside which in the examples above, from @kitora/ui/context-menu: each part's data-slot, the @kitora/primitives part it renders, its role, the state attributes it writes and the CSS variables it sets (style them with data-open:, data-checked: and the rest). Build your own builds the same thing from the parts alone.

Props

ContextMenu

A menu that opens at the pointer on right-click or long press over its trigger; ContextMenu.Root from

  • openboolean

    Whether the menu is open (controlled).

  • defaultOpenboolean

    Default false

    Whether it starts open (uncontrolled).

  • onOpenChange(open: boolean, details: MenuChangeEventDetails) => void

    Called when the open state is about to change; details.cancel() refuses it.

  • childrenReact.ReactNode | PayloadChildRenderFunction<Payload>

    The content: nodes, or a function of the payload of the trigger the menu is attached to.

  • disabledboolean

    Default false

    Disables the whole menu: the trigger does not open it.

  • orientationRovingOrientation

    Default "vertical"

    The direction the items run in (arrow keys follow it).

  • modalboolean

    true (default): the page scroll is locked and an invisible backdrop blocks the page while open. Ignored on a submenu.

  • loopFocusboolean

    Default true

    Arrow keys wrap from the last item to the first.

  • onOpenChangeComplete(open: boolean) => void

    Called after the open or close animation finished.

  • highlightItemOnHoverboolean

    Default true

    The pointer highlights (and focuses) the item it moves over.

  • closeParentOnEscboolean

    Default false

    Escape in a submenu closes the parent menus too.

ContextMenuFilterProvider

Makes the menu inside it searchable (value / defaultValue / onValueChange, autoHighlight, filter, locale). Renders nothing.

  • valuestring

    The filter text (controlled).

  • defaultValuestring

    Default ""

    The starting text (uncontrolled).

  • onValueChange(value: string, details: MenuFilterChangeEventDetails) => void

    Called before the text changes; details.reason says why and details.cancel() keeps the old text.

  • autoHighlightboolean | "always"

    Default false

    Highlight the first match as the text changes (true), also with no text ("always"), or not (false).

  • filter(itemText: string, query: string) => boolean) | null

    Whether an item's text matches the query; null shows every item (the host filters them). Default: useFilter().contains.

  • localeIntl.LocalesArgument

    The locale of the default matcher. Default: the page's.

  • childrenReact.ReactNode

    The Menu.Root (or Menu.SubmenuRoot) to make searchable.

ContextMenuInput

The filter's text box, above the items. Give it an aria-label (and a placeholder) that says what it searches.

Plus render, and className / style as functions of the part's state, and every <input> prop.

ContextMenuClear

Clears the text (shown only while there is text). label names it for assistive tech.

  • labelstring

    Default "Clear search"

    The clear button's accessible name and tooltip.

Plus render, and className / style as functions of the part's state, and every <button> prop.

ContextMenuEmpty

Plus render, and className / style as functions of the part's state, and every <div> prop.

ContextMenuTrigger

The area that opens the context menu on right-click or long press; takes asChild as well as render.

  • asChildboolean

    Whether the single child element renders in place of the part's own element, with the part's props merged onto it (the Radix-style spelling of render).

Plus render, and className / style as functions of the part's state, and every <div> prop.

ContextMenuContent

The context menu's popup, portalled and positioned at the point it opened at, with an optional backdrop and arrow.

  • finalFocusFinalFocusProp

    Where focus goes on close: true (default: the trigger), false, an element ref, or a function.

  • sideAnchoredSideRequest

    Default "inline-end"

    Which side of the anchor the popup sits on; inline-start / inline-end follow the text direction.

  • alignAnchoredAlign

    Default "start"

    Alignment along that side.

  • sideOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 0

    Gap between anchor and popup, px or a function of the placement.

  • alignOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 4

    Shift along the anchor's edge.

  • stickyboolean

    Default false

    Keep the popup against its anchor's edge while the anchor scrolls away.

  • positionMethodPositionStrategy

    absolute (default) follows the page while it scrolls; fixed places in the viewport.

  • collisionBoundaryCollisionBoundary

    Default "clipping-ancestors"

    What the popup must stay inside.

  • collisionPaddingnumber | Partial<PlacementPadding>

    Default 5

    Space kept from the boundary's edges.

  • arrowPaddingnumber

    Default 5

    Space kept between the arrow and the popup's corners.

  • disableAnchorTrackingboolean

    Default false

    Do not follow the anchor after the first placement.

  • collisionAvoidanceCollisionAvoidance

    Flip, shift or neither, per axis.

  • containerPortalContainerOption

    Render the popup into this element instead of document.body.

  • backdropboolean

    Default false

    Draw an overlay behind the menu.

  • arrowboolean

    Default false

    Draw an arrow pointing at the point the menu opened at.

Plus render, and className / style as functions of the part's state, and every <div> prop.
