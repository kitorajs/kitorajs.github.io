SortableList

Reorder a list by pointer or keyboard, vertical or horizontal, with handles, pinned rows and announced moves. The dnd kit's SortableList.

Source: @kitora/dnd (the single implementation; no other package ships one)

Props

SortableList<T>

A styled sortable list, vertical or horizontal; see the file header.

  • orientationSortableOrientation

    Default "vertical"

    vertical stacks items (D33); horizontal lays them in a row (D34).

  • dirDirection

    Writing direction of a horizontal list (D48); default inherited, read from dir on the list.

  • idstring

    Container id (the MoveOp's container); default a generated one. Unique per page.

  • itemsreadonly T[]

    Controlled: the app owns the order and applies onItemsChange.

  • defaultItemsreadonly T[]

    Uncontrolled: the starting order.

  • getIdrequired(item: T) => string

    The item's stable id.

  • onItemsChange(items: readonly T[], op: MoveOp) => void

    Every drop's new list and the MoveOp that made it.

  • renderItemrequired(item: T, state: SortableItemState) => ReactNode

    Renders one item, with its index, drag state and drop position.

  • labelrequiredstring

    Accessible name of the list.

  • handleboolean

    Drag only from a grip button (D16); default false = the whole item.

  • isDisabled(item: T) => boolean

    Items that cannot be dragged (D29); drops can still land around them.

  • indicatorSortableIndicator

    Default gap.

  • strategySortStrategy

    swap exchanges the dragged item and the one it is dropped on (D36); default shift.

  • classNamestring

    Extra classes for the list.

  • itemClassNamestring

    Extra classes for every item.

  • keyboardA11yPolicy

    The keyboard / screen-reader model (D108–D110): grab-arrow (default: Space, arrows, Space), clipboard (Space or Ctrl X, Tab between targets, Space or Ctrl V) or menu (a "Move…" menu on every item).

  • itemLabel(item: T) => string

    The spoken name of an item, for announcements and its Move menu; default its id.

  • providerPropsPartial<Omit<DndProviderProps<unknown>, "children" | "onMove">>

    The escape hatch: any DndProvider option the props above do not name. onMove belongs to the preset.

Hooks and functions

  • DEFAULT_CELL_WIDTH

    Default grid cell width, px (cellWidth).

  • GAP_COLLISION(input: CollisionInput) => readonly Collision[]

    Collision for the presets: pointer-within, with a slack that bridges the gap between items (see pointerNear).

  • SORTABLE_INDICATORS

    How the drop slot shows: siblings make room (gap, the kit's default) or a line on the hovered item (line).

  • SORTABLE_ORIENTATIONS

    List orientations; horizontal is a tab strip or a toolbar.
