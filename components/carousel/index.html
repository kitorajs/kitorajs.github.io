Props

Carousel

A scroll-snap carousel of slides (one child per slide) with arrows, page dots and optional autoplay. Compose your own from Carousel.Root, Viewport, Track, Prev, Next, Dots and PlayToggle.

  • arrowsCarouselArrows

    Default "overlay"

    Arrow buttons; overlay floats them on the slides, header puts them top-right, none hides them.

  • dotsboolean

    Default true

    Whether page dots show under the track; they never show with a single page.

  • titleReactNode

    Content for the header row (left of the header arrows).

  • classNamesCarouselClassNames

    A class per part: root, header, track, slide, arrow, dots.

  • classNamestring

    Class for the root section.

  • childrenrequiredReactNode

    The carousel parts: Carousel.Viewport, Carousel.Track, the arrows, dots and play toggle.

  • labelrequiredstring

    Accessible name of the carousel.

  • gapnumber

    Default 12

    Gap between slides in px.

  • pagenumber

    Controlled page (0-based).

  • perViewnumber

    Default 1

    Slides visible at once (1–6).

  • loopboolean

    Default false

    Whether stepping wraps from the last page to the first.

  • autoplaynumber

    Advance every N ms while playing.

  • defaultPagenumber

    Default 0

    The first page when uncontrolled (0-based).

  • onPageChange(page: number) => void

    Called when the page changes, with the new page (0-based).

  • playingboolean

    Controlled autoplay on/off (the play / pause button).

  • defaultPlayingboolean

    Whether autoplay starts on when uncontrolled; by default it is on when autoplay is set.

  • onPlayingChange(playing: boolean) => void

    Called when autoplay is turned on or off, with whether it now plays.

Hooks and functions

  • useCarouselContext() => CarouselContextValue

    The state of the nearest Carousel.Root; throws outside one.

  • CAROUSEL_ARROWS

    Where the Carousel preset puts its arrow buttons: overlay, header or none.
