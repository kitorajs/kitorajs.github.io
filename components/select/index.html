Select

Kitora's select: a button that opens a list of options, laid over the trigger with the chosen item on its value. Single or multiple, groups, scroll arrows, typeahead, a search box (`searchable`), Field and Form. The kits use it, and the collections kit's Select (items as data) is an adapter over it. Use NativeSelect instead where the platform's own control is wanted: a form that must work without JavaScript, or the native picker on a phone.

Source: @kitora/ui (the primitive the kits compose)

Used inpaginationDataGridBulkEditPopover · datagridEditableCell · datagridLocaleSelect · i18nModelSelector · ai-chatPager · uploadRecurrenceEditor · pickersSelectOptions · collections

01Default

The popup opens over the trigger so the chosen item sits on the value it replaces. ↓ or ↑ opens it, typing a letter jumps to a match, Enter or Space chooses.

02Multiple

multiple keeps the popup open and toggles items; the value is an array and the trigger shows the labels joined.

2 chosen

03Groups

SelectGroup, SelectLabel and SelectSeparator group the options; the group is named by its label.

04Over or under the trigger

alignItemWithTrigger (on by default) lays the popup over the trigger; false opens it under the trigger, as a menu does. Near the edge of the screen it gives up and opens under.

Over the trigger (default)
Under the trigger

05Searchable

searchable puts a search box at the top of the popup that filters the items as you type (every time zone here). ↓ and ↑ move through the matches, Enter chooses, Escape closes; on the closed trigger a typed letter still jumps to a match.

06Long list with scroll arrows

A list taller than the room scrolls: hold the pointer on the arrows at its ends, or use PageUp, PageDown, Home and End.

07In a Field

A Field names and describes the select and shows its error; required blocks a submit until something is chosen and the hidden input submits the value. Its label is not a native <label>.

Props

Select<Value, Multiple extends boolean | undefined = false>

A select root: the value, the open state, the form name. Renders no element.

  • childrenReact.ReactNode

    The select's parts: Select.Trigger, Select.Portal and the rest.

  • inputRefReact.Ref<HTMLInputElement>

    A ref to the hidden input element.

  • namestring

    Identifies the field when a form is submitted.

  • formstring

    Identifies the form that owns the hidden input; useful when the select is rendered outside the form.

  • autoCompletestring

    A hint to the browser for autofill (the autocomplete attribute).

  • idstring

    The id of the select (its trigger).

  • requiredboolean

    Default false

    Whether the user must choose a value before submitting a form.

  • readOnlyboolean

    Default false

    Whether the user should be unable to choose a different option from the popup.

  • disabledboolean

    Default false

    Whether the component should ignore user interaction.

  • multipleMultiple

    Default false

    Whether multiple items can be selected.

  • highlightItemOnHoverboolean

    Default true

    Whether moving the pointer over items highlights them. Off, CSS :hover and the keyboard highlight (data-highlighted) can differ.

  • virtualizedboolean

    Default false

    Kitora extension (the Combobox's pattern, which Base UI's Select lacks): the items are virtualized by you, so only a window of them is mounted. Give items (every item, in list order) and each Select.Item its index into them; the keys, typeahead and the highlight then work over all of items, and onItemHighlighted says which index to scroll into view (the item takes focus once it mounts). Keep the highlighted item mounted while it is scrolled away, or its focus is lost. The popup cannot be laid over the trigger then (alignItemWithTrigger needs the chosen item measured).

  • onItemHighlighted(itemValue: Value | undefined, eventDetails: SelectHighlightEventDetails) => void

    Called when an item is highlighted or unhighlighted (undefined for none) with why and its index: a virtualized list scrolls to it here.

  • defaultOpenboolean

    Default false

    Whether the popup is initially open (uncontrolled).

  • onOpenChange(open: boolean, eventDetails: SelectRootChangeEventDetails) => void

    Called when the popup opens or closes, with why.

  • onOpenChangeComplete(open: boolean) => void

    Called after any animations complete when the popup opens or closes.

  • openboolean

    Whether the popup is open (controlled).

  • modalboolean

    Default true

    true: the page is blocked and its scroll locked while the popup is open.

  • actionsRefReact.RefObject<SelectRootActions | null>

    Imperative actions: unmount() (the select then stays mounted after closing until it is called) and close().

  • itemsListboxItems<any, React.ReactNode>

    The data the options are rendered from, so Select.Value shows the label of the selected item instead of its raw value: a record from value to label, an array of { label, value }, or an array of groups of those.

  • itemToStringLabel(itemValue: Value) => string

    For object values: the text the trigger shows. A { value, label } object needs none.

  • itemToStringValue(itemValue: Value) => string

    For object values: the text a form submits. A { value, label } object needs none.

  • isItemEqualToValue(itemValue: Value, value: Value) => boolean

    Default `defaultItemEquality`

    For object values that are not the same reference: whether an item's value is the selected one. The default compares with Object.is.

  • defaultValueSelectValueType<Value, Multiple> | null

    Default null

    The value at first (uncontrolled).

  • valueSelectValueType<Value, Multiple> | null

    The value (controlled).

  • onValueChange(value: SelectValueType<Value, Multiple> | (Multiple extends true ? never : null), eventDetails: SelectRootChangeEventDetails) => void

    Called when the value changes, with why; details.cancel() refuses the change.

  • searchableboolean

    Default false

    A search box at the top of the popup filters the items as you type. Needs items.

  • filter((itemValue: Value, query: string, itemToString?: (itemValue: Value) => string) => boolean) | null

    With searchable: whether an item matches the query, given its label. Default: contains, under Intl.Collator.

SelectContent

A select's popup: portal, positioner and the list in an animated menu-look panel, with scroll arrows, an optional backdrop, a bottom sheet on small screens (sheet) and, for a searchable select, the search box and empty text.

  • finalFocusFinalFocusProp

    Where focus goes on close: true (default: the trigger), false, an element ref, or a function.

  • alignItemWithTriggerboolean

    Default true

    Lay the popup over the trigger so the selected item sits on the value it replaces (not for a touch open, and given up when it does not fit).

  • sideAnchoredSideRequest

    Default "bottom"

    Which side of the trigger the popup sits on when it is not laid over the trigger; inline-start / inline-end follow the text direction.

  • alignAnchoredAlign

    Default "center"

    Alignment along that side.

  • sideOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 4

    Gap between anchor and popup, px or a function of the placement.

  • alignOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 0

    Shift along the anchor's edge.

  • containerPortalContainerOption

    Render the popup into this element instead of document.body.

  • backdropboolean

    Default false

    Draw an overlay behind the popup.

  • searchPlaceholderstring

    Default "Search…"

    A searchable select's search box placeholder.

  • searchLabelstring

    Default "Search"

    A searchable select's search box name for screen readers.

  • emptyTextReact.ReactNode

    Default "No results"

    What a searchable select shows while no item matches the query.

  • positionerPropsPick<SelectPrimitive.Positioner.Props, "className" | "style"> & { readonly [data: `data-${string}`]: string | undefined }

    Extra props for the positioner (a class, a style with a host's z-index, a data-* marker), for a kit that wraps this part.

  • listPropsSelectPartProps

    Extra props for the list (a class such as a taller max-h-…, a style, a data-* marker).

  • scrollArrowsboolean

    Default true

    The scroll arrows at the top and bottom of a list that overflows (hold the pointer on one to scroll). false drops them.

  • sheet"mobile" | number

    Default undefined (never)

    Draw the popup as a bottom sheet on small screens: "mobile" below 640px, or below a width in px. Above it nothing changes. Not for a searchable select (its popup stays anchored).

SelectSearch

The search box of a searchable select, as a part: put it as a direct child of SelectContent to replace the built-in one (always placed at the top of the popup, above the list) with your own class, placeholder or input props. className is the box's; inputClassName the <input>'s. Its placeholder and name default to SelectContent's searchPlaceholder / searchLabel. In a select without searchable it renders nothing.

SelectTrigger

The button that opens the popup: shows the chosen value and a chevron. size="sm" is the compact height, size="lg" the tall one. loading swaps the chevron for a spinner and sets aria-busy while the options are on their way; the trigger still opens (it can show what is already there).

  • nativeButtonboolean

    Default true

    Whether the rendered element is a native <button>.

  • disabledboolean

    Default false

    Whether the trigger ignores user interaction; the root's and the field's disabled disable it too.

  • sizeSelectTriggerSize

    Default "default"

    The trigger height: sm compact, default, or lg tall.

  • loadingboolean

    Default false

    Options are loading: a spinner in place of the chevron and aria-busy="true".

  • asChildboolean

    Whether to render the child element as the trigger, with the trigger's props merged onto it.

Plus render, and className / style as functions of the part's state, and every <button> prop.

SelectValue

  • placeholderReact.ReactNode

Keyboard

Select

  • ArrowDownSelect.TriggerOpens the list on the selected item, or on the first item when none is selected.
  • ArrowUpSelect.TriggerOpens the list on the selected item, or on the last item when none is selected.
  • EnterSpaceSelect.TriggerOpens the list.
  • ArrowDownSelect.ItemMoves focus to the next item, stopping at the last.
  • ArrowUpSelect.ItemMoves focus to the previous item, stopping at the first.
  • HomeSelect.ItemMoves focus to the first item.
  • EndSelect.ItemMoves focus to the last item.
  • EnterSpaceSelect.ItemChooses the focused item and closes the list (a multiple select keeps it open and flips the item).
  • EscapeSelect.ItemCloses the list without choosing and returns focus to the trigger.

Combobox

  • ArrowDownCombobox.InputGroupOpens the list and highlights the chosen item, else the first (Alt+ArrowDown only opens); in an open list it moves the highlight down, past the last item back to the input.
  • ArrowUpCombobox.InputGroupOpens the list and highlights the last item; in an open list it moves the highlight up, past the first item back to the input.
  • EscapeCombobox.InputGroupCloses the list; a second Escape clears the text and the chosen value.
  • ArrowDownArrowUpCombobox.TriggerOpens the list and moves focus to its input (ArrowUp highlights the last item).
  • EnterSpaceCombobox.TriggerOpens or closes the list.
  • ArrowRightCombobox.ChipMoves focus to the next chip, past the last one to the input (the previous chip right to left).
  • ArrowLeftCombobox.ChipMoves focus to the previous chip, before the first one to the input (the next chip right to left).
  • ArrowDownArrowUpCombobox.ChipOpens the list and returns focus to the input.

Accessibility

  • Select follows the WAI-ARIA Combobox (select-only) pattern: roles combobox, listbox, option.
  • Combobox follows the WAI-ARIA Combobox pattern: roles combobox, listbox, option.

Design-language slot

slots.menu Dropdown, context and select menus (@kitora/ui/dropdown-menu, context-menu, and the popup of select).

  • corner CornerThe menu panel's corner.
  • itemCorner CornerA menu item's corner.
  • surface SurfaceThe panel's surface: opaque or translucent.
  • blur PxBlur radius behind a translucent surface; ignored when surface is solid.
  • highlight HighlightThe colour a highlighted item takes.
  • checkmark CheckmarkSideWhich side a checkmark sits on.
  • elevation ElevationHow much the panel lifts off the page.

slots.select The closed field of a select (@kitora/ui/select's SelectTrigger, and @kitora/ui/native-select, which is the sm size). Its popup is a menu and reads the menu slot. The invalid state keeps Kitora's tints in every language.

  • heights PerSelectSize<Px>Height per size.
  • corner CornerThe default trigger's corner.
  • smallCorner CornerThe sm trigger's and the native select's corner (the sm trigger caps it at 10px, as Kitora's always has).
  • surface PerScheme<Fill>The field's own fill per scheme; none shows the surface behind it (a native select, which the platform draws, shows the page colour instead).
  • darkHover FillThe fill under the pointer in the dark scheme (in light the field keeps its fill, as Kitora's does); a little more opaque than the dark surface.
  • elevation ElevationHow much the closed field lifts off the page (raised is a pop-up button).
  • focusRing FocusRingThe keyboard-focus indicator.
