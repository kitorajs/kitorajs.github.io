Props

Sidebar

The panel, rail or sheet for the current mode; see the file header.

  • headerReactNode

    The top area (workspace switcher, search, primary action); centred in the rail.

  • pinnedReactNode

    A sticky area under the header that never scrolls away (S32): pinned items, usually a SidebarNav of the pinned sections.

  • footerReactNode

    The bottom area under a rule (user menu, customise menu).

  • childrenReactNode

    The scrolling body, usually a SidebarNav.

  • classNamestring

    Extra classes for the panel's nav element.

  • sheetTitleReactNode

    Title of the phone sheet; default the provider's label.

NavRailList<T>

The nav as an icon rail (S2, S78–S81): each section's top-level items, sections divided by a rule.

  • navrequiredreadonly NavSection<T>[]

    The nav whose top-level items the rail shows.

  • onNavigate(item: NavItem<T>, event: MouseEvent<HTMLElement>) => void

    Called when a rail item is clicked, with the item and the click event; call event.preventDefault() to route yourself.

  • activeIdstring | null

    The active item; matched from the provider's location when omitted. A nested active item marks its top-level ancestor.

NavSkeleton

A whole-nav loading skeleton (S71) for before the nav itself has loaded; a section that is reloading uses status: "loading" instead.

  • rowsnumber

    Default 8

    Skeleton rows in all, spread over the sections.

  • sectionsnumber

    Default 2

    Section groups, each with a header bar in the panel.

  • classNamestring

    Extra classes for the skeleton block.

SidebarNav<T>

The nav for the current mode: tree rows in the panel and sheet, the icon rail when collapsed.

  • classNamestring

    Extra classes for the tree element.

  • labelstring

    Accessible name of the tree; default the provider's label.

  • navrequiredreadonly NavSection<T>[]

    The sections and items to show, as the host's data.

  • rowHeight(row: NavRow<T>, base: number) => number

    Row heights for the virtualiser, px; default --sb-row-h per row and {@link SECTION_GAP_PX} more for a section header.

  • onRename(item: NavItem<T>, label: string) => void

    Inline rename (S49); without it F2 and the rename action are off.

  • rulesMoveRules<T>

    Which moves a drag or Alt+Arrow may make (locked items, allowed parents); without it every move is allowed.

  • indentnumber

    Px per depth level: the row inset and the drag offset that changes depth by one; {@link NAV_INDENT_PX} unless given.

  • renderLink(props: NavLinkProps) => ReactNode

    Turns link props into the host router's link; default a plain <a>.

  • onNavChange(next: readonly NavSection<T>[], move: NavMove) => void

    Accepting moves turns drag reorder and Alt+Arrow on (S35–S38, S98); the new nav plus the move that made it.

  • onNavigate(item: NavItem<T>, event: MouseEvent<HTMLElement> | globalThis.KeyboardEvent) => void

    Called on activation (click or Enter); call event.preventDefault() to handle navigation yourself (a client router, a demo).

  • onRetry(section: NavSection<T>) => void

    A failed section's Retry (S73): reload it and pass the new nav.

  • onEmptyAction(section: NavSection<T>) => void

    An empty section's call to action (S72, the section's emptyAction).

  • virtualizeboolean | number

    Virtualise (S74): true always, false never, a number = past that many rows; default {@link VIRTUALIZE_THRESHOLD}.

  • onLoadChildren(item: NavItem<T>) => void

    A lazy item was opened (S28): load its children and pass the new nav.

  • itemActions(item: NavItem<T>) => readonly NavAction[]

    Called for each item to build its menu (hover "…" and right-click), with the item.

  • sectionActions(section: NavSection<T>) => readonly NavAction[]

    Called for each section header to build its menu, with the section.

  • predicate(item: NavItem<T>) => boolean

    Extra filter, e.g. unreads only (S68).

  • activeIdstring | null

    The active item; default matched from the provider's location (S121).

  • rowOptionsNavRowOptions

    The create button on section headers and parent items, passed to each NavRowView.

SidebarSearch

The filter field (S65, S66): filters the nav as you type; Escape clears. In the rail it is an icon that opens the panel.

  • placeholderstring

    The field's placeholder and accessible name; the provider's messages.search when omitted.

  • shortcutstring

    Default "⌘K"

    A shortcut hint drawn at the end of the empty field; an empty string hides it.

  • classNamestring

    Extra classes for the field.

SidebarTrigger

The toggle button (S21, S105): collapses the panel on desktops, opens the sheet on phones and tablets.

  • classNamestring

    Extra classes for the button.

  • labelstring

    The button's accessible name; the provider's messages.toggle when omitted.
