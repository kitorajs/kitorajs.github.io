SegmentedControl

One value of a few as segments in a track, never empty. Toggle or radio semantics, three sizes, an optional sliding indicator.

Source: @kitora/ui (the primitive the kits compose)

Built fromtoggletoggle-groupUsed inDatePicker · pickersSegmented · commerceSegmented · schedulingSegmentedControl · themeSegmentedField · formSlotPicker · pickers

01Basic

Controlled with value and onValueChange, or uncontrolled starting on the first segment; pressing the chosen segment again keeps it, and indicator slides one raised face between segments.

View: week (pressing it again keeps it)

02Radio semantics

semantics="radio" makes a radiogroup whose arrow keys move and select, with segments written as SegmentedControlItem parts (a hint chip, a disabled option).

Arrow keys move and select: month

03Sizes and icons

xs, sm and default sizes; an icon segment takes its accessible name from the option's title, and disabled on the root disables every segment.

04Issue filter

A SegmentedControl above a list of issue Cards with Badges, filtering it to all, open or closed.

Props

SegmentedControl<V extends string = string>

One choice of a few as segments in a muted track, the chosen one raised; there is always exactly one value. Built on ui's ToggleGroup (semantics="toggle") or the primitives' RadioGroup (semantics="radio"), drawn the same either way.

  • valueV

    The chosen value (controlled).

  • defaultValueV

    The value chosen at first (uncontrolled); falls back to the first segment.

  • onValueChange(value: V) => void

    Called with the newly chosen value; never with "nothing".

  • semanticsSegmentedControlSemantics

    Default "toggle"

    How the segments are announced and driven: toggle buttons (focus moves, Space / Enter picks) or a radio group (selection follows focus).

  • sizeSegmentedControlSize

    Default "default"

    The segment height and text size.

  • disabledboolean

    Default false

    Whether every segment is disabled.

  • indicatorboolean

    Default false

    Draw the raised face as one element that slides to the chosen segment.

  • optionsreadonly SegmentedControlOption<V>[]

    Shorthand for children: one segment per option.

  • classNames{ readonly root?: string; readonly item?: string; readonly indicator?: string }

    Extra classes per part.

  • childrenReact.ReactNode

    SegmentedControlItems, instead of options.

  • refReact.Ref<HTMLDivElement>

    A ref to the track element.

Plus every HTML prop.

SegmentedControlItem<V extends string = string>

One segment of a SegmentedControl: a toggle button or a radio, by the control's semantics.

  • valuerequiredV

    The value this segment picks.

  • disabledboolean

    Whether this segment is disabled.

  • refReact.Ref<HTMLButtonElement>

    A ref to the segment's button.

Plus every HTML prop.

Keyboard

RadioGroup

  • ArrowDownArrowRightRadio.RootMoves focus to the next radio and checks it, wrapping from the last to the first (ArrowRight moves to the previous one right to left).
  • ArrowUpArrowLeftRadio.RootMoves focus to the previous radio and checks it, wrapping from the first to the last (ArrowLeft moves to the next one right to left).

Radio

  • SpaceRadio.RootChecks the focused radio (Enter does nothing, so it never submits a form).

Accessibility

  • RadioGroup follows the WAI-ARIA Radio Group pattern: roles radiogroup, radio.
  • Radio follows the WAI-ARIA Radio Group pattern: roles radiogroup, radio.
