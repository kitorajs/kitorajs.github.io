Props

Slider

A slider: track, filled range and one thumb per value (a number for one thumb, an array for a range, a 0–100 range when no value is given), with optional tick marks and value bubbles. The preset composed from SliderRoot, SliderControl, SliderTrack, SliderRange and SliderThumb; name it with aria-label, aria-labelledby or getAriaLabel, which reach every thumb.

  • valueValue

    The controlled value: a number for one thumb, an array for a range.

  • defaultValueValue

    Default min

    The value to start with.

  • disabledboolean

    Default false

    Whether the slider ignores user interaction.

  • formatIntl.NumberFormatOptions

    Intl.NumberFormat options for the value text and Slider.Value.

  • localeIntl.LocalesArgument

    The locale Intl.NumberFormat formats the value with; the runtime's when omitted.

  • maxnumber

    Default 100

    The largest value.

  • minnumber

    Default 0

    The smallest value.

  • minStepsBetweenValuesnumber

    Default 0

    Fewest steps a range keeps between thumbs.

  • namestring

    The form field name the thumbs' inputs submit under (a Field's name wins).

  • formstring

    The id of the <form> the thumbs' inputs belong to, when the slider sits outside it.

  • orientationOrientation

    Default "horizontal"

    Which way the slider runs; vertical puts min at the bottom.

  • stepnumber

    Default 1

    The amount an arrow key moves the value, and the grid a drag snaps to.

  • largeStepnumber

    Default 10

    What PageUp, PageDown and Shift+arrow move by.

  • thumbAlignment"center" | "edge" | "edge-client-only"

    Default "center"

    edge keeps each thumb inside the control at both ends; center lets its centre reach the end.

  • thumbCollisionBehaviorThumbCollisionBehavior

    Default "push"

    What a dragged thumb does when it meets its neighbour.

  • onValueChange(value: Value extends number ? number : Value, details: SliderChangeDetails) => void

    Called while the value changes (a drag, a track press, a key, an input), with the new value and the change details (details.cancel() vetoes).

  • onValueCommitted(value: Value extends number ? number : Value, details: SliderCommitDetails) => void

    Called when a drag ends, a key is pressed or an input changes, with the value that was last set.

  • getAriaLabelSliderPrimitive.Thumb.Props["getAriaLabel"]

    Names each thumb by its index (wins over aria-label), e.g. "Minimum price" and "Maximum price" for a range.

  • getAriaValueTextSliderPrimitive.Thumb.Props["getAriaValueText"]

    The text a screen reader reads for a thumb's value, from its formatted value, value and index.

  • marks"step" | readonly (number | SliderMark)[]

    Tick marks: "step" for one at every step, or a list of values / { value, label }. Labels get room under the track.

  • showValueSliderShowValue

    A value bubble on every thumb: "active" on hover, keyboard focus and drag; "always" all the time.

Plus render, and className / style as functions of the part's state, and every <div> prop.

SliderControl

The area that takes pointer presses; holds the track, the marks and the thumbs.

Plus render, and className / style as functions of the part's state, and every <div> prop.

SliderLabel

A visible name for the slider: names the thumbs' inputs and focuses the thumb when pressed (one thumb).

Plus render, and className / style as functions of the part's state, and every <div> prop.

SliderMarks

Tick marks along the track, with optional labels under a horizontal track and beside a vertical one. Put it in SliderControl before the thumbs (so a thumb paints over a tick). Each mark has data-value and, when it lies in the filled range (start to the value, or between a range's ends), data-in-range. Positions come from the primitives' valuesToPercents; with edge-aligned thumbs (the default) a mark sits where a thumb's centre would be at that value. Horizontal marks are placed with inset-inline-start, so they mirror in right-to-left text the way the thumbs do; vertical marks grow upward from the bottom. Pressing a mark or its label is a press on the track. The marks are aria-hidden; if a label means more than its number, say it in getAriaValueText.

  • marksreadonly (number | SliderMark)[]

    The marks to draw (numbers or { value, label }); omitted, a tick is drawn at every step.

  • stepnumber

    The interval of the generated ticks when marks is omitted; defaults to the slider's step.

  • classNamestring

    Classes for the box that holds the marks.

  • tickClassNamestring

    Classes for each mark's tick (the dot on the track).

  • labelClassNamestring

    Classes for each mark's label.

SliderRange

The filled part of the track: from the start to the value, or between a range's two ends.

Plus render, and className / style as functions of the part's state, and every <div> prop.

SliderThumb

One handle. Pass index for every thumb of a range (the preset does): a SliderThumbValue inside reads it to show this thumb's value. Children render inside the thumb, before its hidden range input.

  • disabledboolean

    Default false

    Whether this thumb ignores user interaction (the root's disabled also applies).

  • getAriaLabel(index: number) => string) | null

    The accessible name of thumb index; wins over aria-label.

  • getAriaValueText(formattedValue: string, value: number, index: number) => string) | null

    The aria-valuetext of a thumb, from the formatted value, the value and the index.

  • indexnumber

    The thumb's index for a range; derived from document order when omitted.

  • inputRefReact.Ref<HTMLInputElement>

    A ref to the thumb's native range input.

  • onBlurReact.FocusEventHandler<HTMLInputElement>

    Called when the thumb's input loses focus.

  • onFocusReact.FocusEventHandler<HTMLInputElement>

    Called when the thumb's input takes focus.

  • tabIndexnumber

    The tabIndex of the thumb's input.

Plus render, and className / style as functions of the part's state, and every <div> prop.

SliderThumbValue

A bubble with the thumb's formatted value (the root's format and locale), placed above a horizontal thumb and beside a vertical one. Put it inside a SliderThumb. It is aria-hidden: the thumb's input already announces the value through aria-valuetext. While dragging only the dragged thumb's bubble shows (data-dragging on the bubble), so a range does not light up both ends.

  • showSliderShowValue

    Default "active"

    When the bubble shows: while the thumb is active (hovered, focused from the keyboard or dragged) or always.

  • classNamestring

    Classes for the bubble.

  • children(formattedValue: string, value: number) => React.ReactNode

    Render the text yourself from this thumb's formatted value and value; the default is the formatted value.

SliderTrack

The rounded track the thumbs move along; goes in SliderControl around SliderRange.

Plus render, and className / style as functions of the part's state, and every <div> prop.

SliderValue

The current value as text ("a – b" for a range, or children(formattedValues, values)), in an <output>.

  • childrennull | ((formattedValues: readonly string[], values: readonly number[]) => React.ReactNode

    Render the formatted values yourself; the default is "a – b".

Plus render, and className / style as functions of the part's state, and every <output> prop.

SliderIndicator

The filled part of the track: from the start to the value, or between a range's two ends.

Plus render, and className / style as functions of the part's state, and every <div> prop.

Accessibility

  • Slider follows the WAI-ARIA Slider pattern: roles slider.

Design-language slot

slots.slider Slider (@kitora/ui/slider). The thumb is a white knob unless the language gives it a fill.

  • trackSize PxThickness of the track.
  • track PerScheme<Fill>The unfilled track per scheme.
  • range FillThe filled part of the track.
  • thumbSize PxDiameter of the thumb.
  • thumb PerScheme<Fill>The thumb's fill per scheme. Here none means the white knob every language drew before this field existed (a transparent knob would show the track through it, which no language wants): no colour token is white in both schemes, and the contract never carries a raw colour, so white is the adapter's to draw. Kitora keeps it.
  • thumbEdge PerScheme<Fill>The thumb's 1px edge per scheme; it needs 3:1 against the page, since the thumb's fill (white by default) may not.
  • thumbElevation ElevationHow much the thumb lifts off the track.
  • focusRing FocusRingThe keyboard-focus indicator.

Hooks and functions

  • stepMarks(min: number, max: number, step: number) => SliderMark[]

    Ticks from min to max every step, rounded to the step's precision so 0.1 steps stay 0.3, not 0.30000000000000004.

  • useSliderThumbAlignment() => SliderStyleContextValue["thumbAlignment"]

    Inside a ui SliderRoot: how the thumbs sit on the track (edge or center), which marks of your own need to line up with them.

  • useSliderThumbIndex() => number

    Inside a ui SliderThumb: which thumb it is (0 for a single slider, 0 or 1 for a range), for a value label or a part of your own.
