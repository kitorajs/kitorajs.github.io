Props

APIKeyCard

The preset: header, then the value and the stock buttons in one row.

  • namerequiredstring

    The key's name, in the header.

  • createdAtstring

    When the key was created, already formatted ("14 days ago"); shown through labels.created.

  • lastUsedstring

    When the key was last used, already formatted ("2 hours ago"); shown through labels.used.

  • valuerequiredstring

    The full plain key.

  • showCharsnumber

    Default 4

    Number of characters to show on each side when masked.

  • maskLengthnumber

    Draw exactly this many dots in the mask, whatever the key's length (the default mask has one dot per hidden character).

  • revealedboolean

    Controlled: whether the key is shown in full.

  • defaultRevealedboolean

    Default false

    Uncontrolled: whether the key starts shown.

  • onRevealedChange(revealed: boolean) => void

    Called with the next reveal state when the reveal button is pressed (in both modes).

  • canRevealboolean

    Default true

    false for a key that must never be shown again (a write-once secret): no reveal button, always masked.

  • copyableboolean

    Default true

    false hides the copy button.

  • onCopy(value: string) => void

    Called with the key after it was written to the clipboard.

  • onRotate() => void

    Called when the rotate button is pressed; without it there is no rotate button.

  • rotatingboolean

    Default false

    A rotation is in flight: the rotate button is busy (blocked, spinner, focus kept) and the live region says so.

  • labelsPartial<ApiKeyCardLabels>

    Override any of the card's strings (see ApiKeyCardLabels).

Plus every <div> prop.

ApiKeyCardActions

The buttons. With no children it draws reveal, copy and rotate as the root allows (canReveal, copyable, onRotate); with children it draws those instead, so a caller lists the stock buttons it wants next to its own (a revoke button, a status badge).

Plus every <div> prop.

ApiKeyCardRevealButton

Toggles the reveal state; its name says what a press does next ("Reveal key" / "Hide key"), so it carries no aria-pressed.

  • variant"link" | "default" | "secondary" | "outline" | "ghost" | "soft" | "destructive" | "destructive-soft" | null

    Default "default"

    The colour scheme and emphasis.

  • size"default" | "xs" | "sm" | "lg" | "xl" | "icon" | "icon-xs" | "icon-sm" | "icon-lg" | null

    Default "default"

    The height and padding; the icon-* sizes make a square button for a lone icon.

  • loadingboolean

    Default false

    Busy: aria-busy="true" and data-loading, activation blocked but focus kept (focusable-disabled semantics, so focus is not dropped mid-submit), full opacity. The children stay in place, invisible, so the width does not jump, with a spinner centred over them. Controlled by this prop only.

  • renderUseRenderRenderProp

    The primitives' render prop, an alias of asChild with the element given here instead of as the child: an element (cloned with the button's props) or a function (props) => element. asChild wins when both are given.

  • asChildboolean

    Default false

    Render the single child element instead of a <button>, merging the button's props onto it (classes joined, handlers chained, the child's other props win). Built on useRender from

  • focusableWhenDisabledboolean

    Default false

    Keep a disabled button in the tab order: aria-disabled="true" instead of disabled, clicks and every key but Tab blocked (the primitive useButton), hover kept so a Tooltip can explain why.

  • nativeButtonboolean

    Whether the rendered element is a native <button>. Only read with focusableWhenDisabled or loading (it decides aria-disabled vs role="button" handling). Defaults to true unless render/asChild gives an element other than <button>.

  • loadingTextReact.ReactNode

    While loading, show the spinner beside this text instead of over the hidden children.

Plus every <button> prop.

Hooks and functions

  • maskApiKey(value: string, showChars: number, maskLength?: number) => string

    The masked form of a key: showChars characters kept on each side and dots between. A key too short to keep both ends is all dots. With maskLength the dots are always that many (a short key becomes exactly maskLength dots), so the mask says nothing about the length.

  • useApiKeyCard() => ApiKeyCardContextValue

    The state of the enclosing ApiKeyCardRoot, for a caller's own part (a custom copy button, a "copied" toast).

  • API_KEY_CARD_LABELS

    The card's English strings, the defaults labels overrides.
