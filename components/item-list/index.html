ItemList

A selectable list of Item rows that can hold buttons and links: single or multiple selection, checkboxes, row actions with Left and Right, Enter or double click to act, typeahead, and a virtual window for 10,000 rows. The collections kit's ItemList, the grid pattern of React Aria's GridList.

Source: @kitora/collections (the single implementation; no other package ships one)

Full API on the collections kit gallery

Props

ItemList

<ItemList …/> is the preset; ItemList.Root / .Row / .Checkbox / .Empty are the parts it is built from.

  • idstring

    Id of the role="grid" element.

  • heightnumber

    Max height in px before a plain list scrolls; the viewport height of a virtual list (default 320). Unset: a plain list grows.

  • classNamestring

    Class names for the role="grid" element.

  • styleCSSProperties

    Inline style for the role="grid" element, merged over its height.

  • itemsrequiredreadonly T[]

    The items, one per row.

  • getKey(item: T) => string

    The unique key of an item, the selection value. Default item.id; an item without a string id needs this.

  • getTextValue(item: T) => string

    The row's text for typeahead. Default: the item when it is a string, else its label, else its key.

  • selectionModeSelectionMode

    Default "none"

    How rows select: not at all, one, or many.

  • selectionBehaviorItemListSelectionBehavior

    Default "toggle"

    Whether a click toggles the row or makes it the only selection.

  • selectedKeysreadonly string[]

    Controlled selection (keys); leave undefined to let the hook keep its own, seeded by defaultSelectedKeys.

  • defaultSelectedKeysreadonly string[]

    Starting selection (keys) when uncontrolled.

  • onSelectionChange(keys: string[]) => void

    Called when the selection changes, with the selected keys.

  • disabledKeysIterable<string>

    Keys that cannot be focused by arrow keys, selected or acted on (an item's own disabled: true counts too).

  • disallowEmptySelectionboolean

    Whether to keep at least one row selected: the last selected row cannot be deselected, and Escape does not clear.

  • onAction(item: T, key: string) => void

    Enter, or a double click, on a row. Without it Enter selects the row like a click.

  • virtualboolean

    Whether to mount only the rows in view (aria-rowcount / aria-rowindex then describe the whole list).

  • rowHeightnumber

    Default 56

    Fixed row height in px for the virtual window.

  • estimateSize(index: number) => number

    Measured rows: the guess in px for a row before it is measured. Implies virtual.

  • overscannumber

    Default 6

    Rows mounted above and below the viewport when virtual.

  • pageSizenumber

    Default 10

    PageUp / PageDown jump in rows.

  • dirTextDirection

    Text direction for Left/Right; default the nearest dir attribute or the computed direction.

  • aria-labelstring

    Accessible name of the list. Not allowed with aria-labelledby.

  • aria-labelledbynever

    Not allowed with aria-label. Id of the element that names the list.

  • variant"default" | "outline" | "muted" | null

    Default "default"

    The row's surface: plain, an edge (outline) or a fill (muted).

  • size"default" | "xs" | "sm" | null

    Default "default"

    The row's padding and gaps.

  • renderItem(item: T, state: ItemListRowState) => ReactNode

    The content of one row (what goes inside the Item). Default: the row's text as an ItemTitle.

  • checkboxesboolean

    Draw the selection checkbox in multiple mode (default true).

  • renderEmptyState() => ReactNode

    What an empty list shows (default "No items").

  • rowClassNamestring

    Class of every row.

ItemListCheckbox

The selection checkbox of the enclosing row (multiple mode). It is a control of its own: it toggles this row and does not also run the row's click, it is reached with Left/Right from the row, and its name is "Select {row text}".

  • classNamestring

    Class names for the checkbox.

ItemListEmpty

Shown only when the list has no rows: a row with one cell, so the grid keeps a valid structure.

  • classNamestring

    Class names for the cell that holds the message.

  • childrenrequiredReactNode

    The message shown when there are no rows.

ItemListRow<T>

One role="row" with one role="gridcell" holding an Item; the row is the focus stop and carries the roving and data-* attributes.
