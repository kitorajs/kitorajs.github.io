Anatomy

Which part renders inside which in the examples above, from @kitora/ui/scroll-area: each part's data-slot, the @kitora/primitives part it renders, its role, the state attributes it writes and the CSS variables it sets (style them with data-open:, data-checked: and the rest). Build your own builds the same thing from the parts alone.

Props

ScrollArea

A scrolling box with thin themed scrollbars over the content in place of the platform's: ScrollArea from

  • overflowEdgeThresholdOverflowEdgeThreshold

    Default 0

    Px of remaining scroll below which an edge counts as reached for data-overflow-* (one number, or per edge).

  • scrollbarsScrollAreaAxes

    Default "y"

    Which scrollbars to render.

  • fadeboolean | ScrollAreaAxes

    Default false

    Fade the edges with content past them. true follows scrollbars.

  • typeScrollAreaType

    Default "auto"

    When the bars show.

  • viewportClassNamestring

    Classes for the viewport (the scrolling element).

  • contentClassNamestring

    Wrap the children in the primitives' Content part with these classes ("" for none).

Plus render, and className / style as functions of the part's state, and every <div> prop.

ScrollBar

One scrollbar with its thumb, vertical or horizontal; ScrollArea draws these, so render one yourself only when composing the parts.

  • orientation"horizontal" | "vertical"

    Default "vertical"

    Which axis this scrollbar scrolls.

  • keepMountedboolean

    Default false

    Keep the scrollbar mounted while its axis does not overflow.

  • typeScrollAreaType

    Default "auto"

    When the bar shows (see ScrollArea).

Plus render, and className / style as functions of the part's state, and every <div> prop.

Design-language slot

slots.scrollbar ScrollArea (@kitora/ui/scroll-area): its scrollbars.

  • size PxThe scrollbar's thickness (the thumb is 1px in from each side).
  • ends BarEndsRound or square ends of the thumb.
  • thumb PerScheme<Fill>The thumb per scheme.
  • track PerScheme<Fill>The track behind it per scheme. none overlays the content (Kitora); a painted track is a classic scroller, and the content is kept clear of it.
  • thumbElevation ElevationHow much the thumb lifts off the track.
