GaugeChart

One value on a dial between a minimum and a maximum: a 240° sweep by default, coloured bands with a legend, the formatted value in the centre and a WAI-ARIA meter root. Its arc is the same drawing as the feedback kit's Meter.Ring and CircularProgress. The charts kit's GaugeChart.

Source: @kitora/charts (the single implementation; no other package ships one)

Full API on the charts kit gallery

Built fromChart · chartsChartFrame · charts

01Default

value between min (0) and max (100) on a 240° dial; the root is a meter with aria-valuenow, aria-valuemin, aria-valuemax and aria-valuetext, named by the title.

02Segments

segments colour bands on the track; the arc takes the colour of the band it ends in (unless color is set) and a legend lists the bands.

03Sweep and size

startAngle / endAngle in degrees, size and thickness; a full sweep is the same arc as Meter.Ring.

04Format and centre

format reaches the centre and aria-valuetext; centerLabel adds a caption, children replaces the centre. A value past max stops the dial but keeps its text.

05Download as SVG or PNG

exportFormats adds a download button per format before the Table toggle; the file carries the title and the legend, so it stands alone outside the page.

06KPI row

Three GaugeCharts in ui Cards with a Badge for the band each one is in.

Props

GaugeChart

A single value on a dial: value between min and max, optional coloured segments, the formatted value in the centre. A change of value animates the arc (none under reduced motion).

  • valuerequirednumber

    The value shown. Outside min..max the dial stops at the end, while the text and aria-valuetext keep the real value.

  • minnumber

    Default 0

    The value at the start of the dial.

  • maxnumber

    Default 100

    The value at the end of the dial.

  • titlerequiredstring

    The accessible name; shown by the frame unless hideTitle.

  • startAnglenumber

    Default -120

    Where the dial starts, degrees clockwise from 12 o'clock.

  • endAnglenumber

    Default 120

    Where the dial ends, degrees clockwise from 12 o'clock.

  • thicknessnumber

    The arc's thickness in pixels; default a tenth of the size.

  • colorstring

    The value arc's colour; default the band the value ends in, else the first palette slot.

  • segmentsreadonly GaugeSegment[]

    Coloured bands on the track (green to 60, amber to 85, red above); a legend lists them.

  • format(value: number) => string

    Formats the centre text and aria-valuetext; default the formats adapter's number.

  • centerLabelstring

    A caption under the value ("of 100", "CPU").

  • childrenReactNode

    Replaces the centre content (value and caption).

  • sizenumber

    Default 160

    The dial's diameter in pixels; it shrinks to the plot's width.

  • legendLegendPosition

    Where the band legend sits, or none; when unset it is bottom with segments and none without.

  • hideTitleboolean

    Whether to hide the title visually; screen readers still hear it.

  • descriptionReactNode

    One sentence under the title.

  • summarystring

    Screen reader summary; each chart has an automatic one.

  • tableToggleboolean

    Default true

    Whether to show the "Table" toggle in the header. The hidden table for screen readers is always there.

  • animateboolean

    Whether marks animate in; on unless false (the reader's reduced-motion setting still wins).

  • classNamestring

    Classes added to the figure element.

  • classNamesChartClassNames

    Extra classes per frame part.

  • actionsReactNode

    Extra header controls (a range picker, a mode switch), placed left of the Table toggle.

  • exportFormatsreadonly ChartExportFormat[]

    Default []

    Download buttons in the header, one per format, before the Table toggle (Chart.Export); none unless set.

  • showTableboolean

    Show the table instead of the plot (controlled).

  • defaultShowTableboolean

    Default false

    Whether the table shows at first (uncontrolled).

  • onShowTableChange(showTable: boolean) => void

    Called when the reader switches between plot and table, with true for the table.

Hooks and functions

  • GAUGE_SIZE

    The default dial size, px.
