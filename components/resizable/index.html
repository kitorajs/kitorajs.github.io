Props

SplitView

A resizable row or column of panes with keyboard-operable sashes, min / max and collapse; the dock lays out its splits with it, and it works on its own.

  • orientationrequiredOrientation

    horizontal lays the panes out as a row, vertical as a column.

  • childrenrequiredReactNode

    One pane per child, in order.

  • sizesreadonly number[]

    Controlled fractions, one per pane (DK5); pair with onSizesChange.

  • defaultSizesreadonly number[]

    Uncontrolled starting fractions; default equal shares.

  • collapsedreadonly boolean[]

    Controlled collapsed flags (DK6).

  • defaultCollapsedreadonly boolean[]

    Uncontrolled starting collapsed flags, one per pane.

  • panesreadonly (PaneConstraints | undefined)[]

    Default []

    Per-pane px min / max, priority, collapsible, collapsed size (DK4, DK7, DK9).

  • basisPxnumber

    The container px the sizes were committed at; default the first measured size (DK9).

  • onSizesChange(change: SplitChange) => void

    Called once per finished drag, key press or double-click, never per pointer move.

  • paneLabelsreadonly string[]

    Default []

    Accessible name of each pane, for the separators' labels ("Resize Explorer").

  • paneIdsreadonly string[]

    DOM ids of the panes' content, for each separator's aria-controls (DK101); default generated.

  • onlynumber

    Show only pane only at full size (DK44: the dock's maximise). The other panes stay mounted but display: none, and no sash renders, so maximising and restoring never remount anything (a drag that starts while maximised keeps its source element, DK136).

  • classNamestring

    Extra class names for the split's root element.

  • styleCSSProperties

    Inline styles for the split's root element.

Hooks and functions

  • SASH_KEY_STEP_PX

    Keyboard step for arrow keys, px.

  • SASH_PAGE_STEP_PX

    Keyboard step for Shift+arrow, px.

  • SASH_PX

    Width of the visible divider between panes, px; the hit area is wider (see SASH_HIT_PX in the stylesheet).
