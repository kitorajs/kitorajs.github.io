Button

Eight intents, five sizes, icon-only variants. Compact-first — 32px default. Slot-based via asChild.

Source: @kitora/ui (the primitive the kits compose)

01Variants

Eight intents. default is the headline action; soft is the workhorse for secondary CTAs in dense UI.

02Sizes

Five heights: 24 / 28 / 32 (default) / 36 / 40px. Compact-first — match supabase / linear density.

03With icons

Leading icon = primary action, trailing = navigation. Lucide auto-sized + spaced.

04Icon-only

Square buttons. Provide an aria-label for screen readers.

05Loading + disabled

Pair disabled with a spinner for async actions. Width stays stable.

06Width

Set width on the button itself, not a wrapper — keeps focus rings + transitions intact.

07Headless Button (primitives)

Button from @kitora/primitives/react is the behaviour without the look: a disabled one can stay focusable (focusableWhenDisabled, aria-disabled) and nativeButton={false} makes any element act as a button.

A span that acts as a button

08Loading

A busy button keeps its width and focus, with a spinner over its label or beside loading text.

09Disabled with a reason

A disabled button that stays focusable and hoverable, so a tooltip can explain why it is off.

Props

Button

A button with Kitora's variants and sizes, plus asChild / render, loading and focusableWhenDisabled; built on the primitives' useButton.

  • asChildboolean

    Default false

    Render the single child element instead of a <button>, merging the button's props onto it (classes joined, handlers chained, the child's other props win). Built on useRender from

  • renderUseRenderRenderProp

    The primitives' render prop, an alias of asChild with the element given here instead of as the child: an element (cloned with the button's props) or a function (props) => element. asChild wins when both are given.

  • focusableWhenDisabledboolean

    Default false

    Keep a disabled button in the tab order: aria-disabled="true" instead of disabled, clicks and every key but Tab blocked (the primitive useButton), hover kept so a Tooltip can explain why.

  • nativeButtonboolean

    Whether the rendered element is a native <button>. Only read with focusableWhenDisabled or loading (it decides aria-disabled vs role="button" handling). Defaults to true unless render/asChild gives an element other than <button>.

  • loadingboolean

    Default false

    Busy: aria-busy="true" and data-loading, activation blocked but focus kept (focusable-disabled semantics, so focus is not dropped mid-submit), full opacity. The children stay in place, invisible, so the width does not jump, with a spinner centred over them. Controlled by this prop only.

  • loadingTextReact.ReactNode

    While loading, show the spinner beside this text instead of over the hidden children.

  • variant"link" | "default" | "secondary" | "outline" | "ghost" | "soft" | "destructive" | "destructive-soft" | null

    Default "default"

    The colour scheme and emphasis.

  • size"default" | "xs" | "sm" | "lg" | "xl" | "icon" | "icon-xs" | "icon-sm" | "icon-lg" | null

    Default "default"

    The height and padding; the icon-* sizes make a square button for a lone icon.

Plus every <button> prop.

Hooks and functions

  • buttonVariants(props?: ({ variant?: "link" | "default" | "secondary" | "outline" | "ghost" | "soft" | "destructive" | "destructive-soft" | null | undefined; size?: "default" | "xs" | "sm" | "lg" | "xl" | "icon" | "icon-xs" | "icon-sm" | "icon-lg" | null | undefined; } & ClassProp) | undefined) => string

    The button's class names for a variant and size, for an element that should look like a button.

  • BUTTON_HIT_AREA_CLASS

    Coarse-pointer hit area: an invisible ::after grows the target to at least 44×44 under a touch pointer (WCAG 2.5.5 / Apple HIG) without changing the drawn size. min(0px, (100% - 44px) / 2) is a negative inset for a box under 44px and 0 for a larger one, so big buttons are untouched; nothing at all applies under a fine pointer. Every button carries it (in buttonVariants); exported for a caller's own small control. A pointer-only class, so the default look is unchanged.
