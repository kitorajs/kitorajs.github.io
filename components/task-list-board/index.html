Props

TaskListBoard

A board of task lists: drag tasks within and across lists, reorder, collapse, rename and delete lists, add tasks inline, select and paginate.

  • groupsrequiredTaskListGroup[]

    The lists to show, in order.

  • onGroupsChange(next: TaskListGroup[]) => void

    Called with the whole new arrangement after a drag, collapse, reorder or delete that no granular callback handled.

  • onTaskMove( taskId: string, sourceGroupId: string, targetGroupId: string, beforeTaskId: string | null, /** Other selected task ids dragged together (excludes the primary). */ additionalTaskIds?: string[], ) => void

    Granular drag callbacks. When supplied, take precedence over onGroupsChange for that kind of change — letting headless adapters dispatch a single moveTask / reorderGroups call instead of diffing.

  • onListReorder(orderedIds: string[]) => void

    Called when the user reorders lists, with every list id in the new order.

  • onListDelete(groupId: string) => void

    Called when the user deletes a list, with its id.

  • onListCollapse(groupId: string, collapsed: boolean) => void

    Called when the user collapses or expands a list, with its id and the new state.

  • onTaskToggle(groupId: string, task: Task, next: boolean) => void

    Called when the user checks or unchecks a task, with its list id, the task and the new done state.

  • onTaskStatusChange(groupId: string, task: Task, status: TaskStatus) => void

    Called when the user picks a status for a task, with its list id, the task and the status.

  • onTaskOpen(groupId: string, task: Task) => void

    Called when the user opens a task, with its list id and the task.

  • onAddList() => void

    Called when the user presses the add-list button; the button shows only when this is set.

  • onAddTask( groupId: string, title: string, position: 'top' | 'bottom', ) => void

    Called when the user adds a task from a list's composer, with the list id, the title and whether it goes at the top or bottom; the composers show only when this is set.

  • onRenameTask(groupId: string, task: Task, newTitle: string) => void

    Called when the user renames a task inline, with its list id, the task and the new title.

  • onDuplicateTask(groupId: string, task: Task) => void

    Called when the user duplicates a task, with its list id and the task; the menu item shows only when this is set.

  • onDeleteTask(groupId: string, task: Task) => void

    Called when the user deletes a task, with its list id and the task; the menu item shows only when this is set.

  • onAddSubtask(groupId: string, parent: Task) => void

    Called when the user adds a subtask, with the list id and the parent task; the menu item shows only when this is set.

  • onRenameList(groupId: string, newTitle: string) => void

    Called when the user renames a list, with its id and the trimmed new title; renaming is offered only when this is set.

  • onDuplicateList(groupId: string) => void

    Called when the user duplicates a list, with its id; the menu item shows only when this is set.

  • onLoadMoreTasks(groupId: string) => void

    Per-list pagination — when supplied, "Load more" footer renders beneath each list whose pageInfo.hasNextPage is true.

  • pagerSlot(group: TaskListGroup) => React.ReactNode

    Custom per-list pagination footer. When supplied, this slot wins over the default "Load more" button — render any pager UI you like (Prev/Next buttons, page-jumper, infinite-scroll hint, etc). Receives the live group so pageInfo / totalCount / loadingMore are available.

  • taskListVirt{ containerHeight: number estimateRowHeight?: number overscan?: number }

    Virtualize each list's row stack via <TaskList>'s virt prop. When set, every list gets its own internal virt scroller — same <TaskList> rendering with all features (subtasks, multi-select, drag-drop, status pickers, inline-add).

  • selectedIdsstring[]

    The selected task ids.

  • onSelectionChange(ids: string[]) => void

    Called when the selection changes, with every selected task id.

  • expandedIdsSet<string>

    The ids of tasks whose subtasks are shown.

  • onToggleExpand(taskId: string) => void

    Called when the user expands or collapses a task's subtasks, with its id.

  • classNamestring

    Class on the board.
