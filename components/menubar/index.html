Menubar

A bar of menus (File, Edit, View) with arrow-key movement between them and hover switching while one is open.

Source: @kitora/ui (the primitive the kits compose)

Built fromdropdown-menu
  • On this page:
  • Application menu
  • Vertical, non-modal and disabled
  • Document window
  • Build your own
  • API reference
  • Anatomy

01Application menu

↓ opens a menu on its first item and ← / → walk to the neighbouring menu with it open; once a menu is open, resting the pointer on another title opens that one. Items, checkboxes, radios and submenus are the dropdown menu's.

02Vertical, non-modal and disabled

A vertical bar moves with ↑ / ↓ and opens a menu with →. modal={false} keeps the page live behind an open menu, and a disabled trigger is skipped.

03Document window

A Menubar next to a Badge in a Card; choosing an item reports it below.

The same menubar from the primitives' Menubar and Menu parts only (one tab stop, ← / → along the bar, ↓ opens a menu); a rebuild test compares it with ui's.

Props

Menubar

A bar of menus (APG Menubar): one tab stop, ←/→ along the bar (↑/↓ when orientation="vertical"), ↓ opens a menu on its first item and ←/→ walk to the neighbouring menu while one is open; resting the pointer on another title opens its menu once any is open. Each menu is a MenubarMenu with a MenubarTrigger and a MenubarContent; the items, groups, separators and submenus are the dropdown menu's, under the same names with a Menubar prefix.

  • modalboolean

    Default true

    Whether the page is blocked behind an open menu (the bar itself stays usable).

  • disabledboolean

    Default false

    Disables the whole menubar.

  • orientation"horizontal" | "vertical"

    Default "horizontal"

    The direction the arrow keys move along the bar.

  • loopFocusboolean

    Default true

    Whether the arrow keys wrap from the last trigger to the first and back.

Plus render, and className / style as functions of the part's state, and every <div> prop.

MenubarMenu<Payload = unknown>

One menu of the bar: its trigger and its content.

  • openboolean

    Whether the menu is open (controlled).

  • defaultOpenboolean

    Default false

    Whether it starts open (uncontrolled).

  • onOpenChange(open: boolean, details: MenuChangeEventDetails) => void

    Called when the open state is about to change; details.cancel() refuses it.

  • onOpenChangeComplete(open: boolean) => void

    Called after the open or close animation finished.

  • disabledboolean

    Default false

    Disables the whole menu: the trigger does not open it.

  • modalboolean

    true (default): the page scroll is locked and an invisible backdrop blocks the page while open. Ignored on a submenu.

  • loopFocusboolean

    Default true

    Arrow keys wrap from the last item to the first.

  • orientationRovingOrientation

    Default "vertical"

    The direction the items run in (arrow keys follow it).

  • highlightItemOnHoverboolean

    Default true

    The pointer highlights (and focuses) the item it moves over.

  • closeParentOnEscboolean

    Default false

    Escape in a submenu closes the parent menus too.

  • triggerIdstring | null

    ID of the trigger the menu is attached to: with a controlled open, which of several triggers it opens from.

  • defaultTriggerIdstring | null

    ID of the trigger the menu is attached to when it starts open (defaultOpen).

  • actionsRefReact.RefObject<MenuRootActions | null>

    A ref to imperative actions: close(), and unmount() for a popup kept mounted with details.preventUnmountOnClose().

  • handleMenuHandle<Payload>

    A handle that lets Menu.Triggers outside this Root open it (Menu.createHandle()).

  • childrenReact.ReactNode | PayloadChildRenderFunction<Payload>

    The content: nodes, or a function of the payload of the trigger the menu is attached to.

MenubarTrigger

The title of a menu in the bar. asChild renders the child element as the title (like every other ui trigger), merged onto.

  • handleMenuHandle<Payload>

    A handle that associates this trigger with a Menu.Root elsewhere in the tree (Menu.createHandle()).

  • payloadPayload

    What the menu's content receives (children of the Root as a function) while it is attached to this trigger.

  • disabledboolean

    Default false

    Disables the trigger.

  • nativeButtonboolean

    Default true

    Whether the rendered element is a native <button>; false adds role="button" and keyboard activation.

  • openOnHoverboolean

    Default false

    Open the menu when the pointer rests on the trigger, as well as on press. In a Menubar: while a menu of the bar is open.

  • delaynumber

    Default 100

    How long the pointer must rest on the trigger before the menu opens, in ms. Needs openOnHover.

  • closeDelaynumber

    Default 0

    How long after the pointer leaves before a hover-opened menu closes, in ms. Needs openOnHover.

  • asChildboolean

    Whether the single child element renders in place of the part's own element, with the part's props merged onto it (the Radix-style spelling of render).

Plus render, and className / style as functions of the part's state, and every <button> prop.

MenubarContent

A menu's popup, under its title.

  • finalFocusFinalFocusProp

    Where focus goes on close: true (default: the trigger), false, an element ref, or a function.

  • sideAnchoredSideRequest

    Which side of the anchor the popup sits on; inline-start / inline-end follow the text direction.

  • alignAnchoredAlign

    Default "start"

    Alignment along that side.

  • sideOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 8

    Gap between anchor and popup, px or a function of the placement.

  • alignOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default -4

    Shift along the anchor's edge.

  • stickyboolean

    Default false

    Keep the popup against its anchor's edge while the anchor scrolls away.

  • positionMethodPositionStrategy

    absolute (default) follows the page while it scrolls; fixed places in the viewport.

  • collisionBoundaryCollisionBoundary

    Default "clipping-ancestors"

    What the popup must stay inside.

  • collisionPaddingnumber | Partial<PlacementPadding>

    Default 5

    Space kept from the boundary's edges.

  • arrowPaddingnumber

    Default 5

    Space kept between the arrow and the popup's corners.

  • disableAnchorTrackingboolean

    Default false

    Do not follow the anchor after the first placement.

  • collisionAvoidanceCollisionAvoidance

    Flip, shift or neither, per axis.

  • containerPortalContainerOption

    Render the popup into this element instead of document.body.

  • backdropboolean

    Default false

    Draw an overlay behind the menu.

  • arrowboolean

    Default false

    Draw an arrow pointing at the trigger.

  • morphboolean

    Default false

    One menu opened by several triggers (handle and payload): animate the move and the content change between them.

Plus render, and className / style as functions of the part's state, and every <div> prop.

Keyboard

Menubar

  • ArrowRightMenu.TriggerMoves focus to the next trigger of a horizontal bar, wrapping (the previous one right to left); while a menu is open, that trigger's menu opens.
  • ArrowLeftMenu.TriggerMoves focus to the previous trigger of a horizontal bar, wrapping (the next one right to left); while a menu is open, that trigger's menu opens.
  • HomeMenu.TriggerMoves focus to the first trigger.
  • EndMenu.TriggerMoves focus to the last trigger.
  • ArrowDownMenu.TriggerOpens the trigger's menu with its first item focused (ArrowRight in a vertical bar, ArrowLeft right to left).
  • ArrowUpMenu.TriggerOpens the trigger's menu with its last item focused (in a horizontal bar).
  • EnterSpaceMenu.TriggerOpens the trigger's menu with its first item focused.
  • EscapeMenu.TriggerCloses the open menu; focus stays on its trigger.

Menu

  • EnterSpaceMenu.TriggerOpens the menu and moves focus into it.
  • ArrowDownMenu.TriggerOpens the menu with its first item focused.
  • ArrowUpMenu.TriggerOpens the menu with its last item focused.
  • ArrowDownMenu.ItemMoves focus to the next item, wrapping from the last to the first.
  • ArrowUpMenu.ItemMoves focus to the previous item, wrapping from the first to the last.
  • HomeMenu.ItemMoves focus to the first item.
  • EndMenu.ItemMoves focus to the last item.
  • EnterSpaceMenu.ItemActivates the focused item (Enter on press, Space on release) and closes the menu.
  • EscapeMenu.ItemCloses the menu (a submenu first) and returns focus to the trigger.
  • ArrowRightMenu.SubmenuTriggerOpens the submenu with its first item focused (ArrowLeft right to left).
  • EnterSpaceMenu.SubmenuTriggerOpens the submenu.

Accessibility

  • Menubar follows the WAI-ARIA Menu and Menubar pattern: roles menubar, menuitem, menu.
  • Menu follows the WAI-ARIA Menu Button pattern: roles button, menu, menuitem.

Design-language slot

slots.menubar Menubar (@kitora/ui/menubar): the bar and its titles; its menus read the menu slot.

  • corner CornerThe bar's corner.
  • itemCorner CornerA title's corner.
  • surface PerScheme<Fill>The bar's fill per scheme.
  • edge PerScheme<Fill>The bar's 1px edge per scheme (none for no visible edge).
  • highlight BarHighlightA title under the pointer, focused, or with its menu open.
  • fontWeight numberThe titles' CSS-style weight, 100–900.
