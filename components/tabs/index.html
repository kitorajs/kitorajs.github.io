Props

Tabs

The root of a set of tabs: holds the selected value and lays out the list and panels in a column (a row when vertical); Tabs.Root from

  • valueany

    The value of the selected tab (controlled). null selects none.

  • defaultValueany

    Default 0

    The value to start with (uncontrolled). null selects none.

  • orientationTabsOrientation

    Default "horizontal"

    The layout flow of the tabs, which sets the arrow keys.

  • onValueChange(value: any, eventDetails: TabsRootChangeEventDetails) => void

    Called when a new value is being set. eventDetails.activationDirection says which way the selection moved; cancel() vetoes it.

Plus render, and className / style as functions of the part's state, and every <div> prop.

TabsList

The row of tabs: Tabs.List from

  • activateOnFocusboolean

    Default false

    Select a tab as it receives focus from the arrow keys (automatic activation). Otherwise Enter or Space selects it (manual activation).

  • loopFocusboolean

    Default true

    Wrap keyboard focus from the last tab to the first and back with the arrow keys.

  • variant"line" | "default" | null

    Default "default"

    The look: default raised tabs in a muted track (the tabs slot), line an underline under the selected tab.

  • size"default" | "sm" | "lg" | null

    Default "default"

    The list height and tab text: sm, default or lg. Opt-in; the default adds no class. The tabs follow the list's height.

  • fillboolean | null

    Default false

    Whether the list stretches to the full width (the tabs share it).

  • scrollableboolean

    Default false

    Put the list in a horizontal scroll container (no visible bar, fades at the edges with hidden tabs), for more tabs than fit. Arrow keys still move between tabs and the selected one scrolls into view. Horizontal tabs only.

  • scrollClassNamestring

    Classes for the scroll container (scrollable).

Plus render, and className / style as functions of the part's state, and every <div> prop.

TabsTrigger

One tab in TabsList: raised (or underlined in line) while selected.

  • valuerequiredTabsTabValue

    The value that selects this tab and its panel (the root's value).

  • disabledboolean

    Default false

    Whether the tab ignores the user. It stays focusable (announced as disabled) but cannot be selected.

  • nativeButtonboolean

    Default true

    Whether the part renders a native <button>; set false when render gives another element.

Plus render, and className / style as functions of the part's state, and every <button> prop.

TabsContent

The panel a tab shows; Tabs.Panel from

  • valuerequiredany

    The value of the tab this panel belongs to.

  • keepMountedboolean

    Default false

    Keep the panel in the DOM, hidden, while its tab is not selected.

Plus render, and className / style as functions of the part's state, and every <div> prop.

TabsIndicator

Opt-in sliding selection: put it inside TabsList and it follows the selected tab with a short transition (none under reduced motion), from the --active-tab-* variables the primitives' Tabs.Indicator writes. In the default variant it is the raised pill (the same --dk-tabs-selected* slot values a selected tab reads); in line it is the 2px underline (an inline-end bar in a vertical list). The tabs stop drawing their own selection while it is there. Its left is physical on purpose: the primitive measures the tab from the list's physical left edge.

  • renderBeforeHydrationboolean

    Default false

    Render a script that places the indicator before React hydrates server-rendered markup, so it does not jump.

Plus render, and className / style as functions of the part's state, and every <span> prop.

Keyboard

  • ArrowRightTabs.TabMoves focus to the next tab in a horizontal list (the previous one right to left).
  • ArrowLeftTabs.TabMoves focus to the previous tab in a horizontal list (the next one right to left).
  • HomeTabs.TabMoves focus to the first tab.
  • EndTabs.TabMoves focus to the last tab.
  • EnterSpaceTabs.TabSelects the focused tab and shows its panel.

Accessibility

  • Tabs follows the WAI-ARIA Tabs pattern: roles tablist, tab, tabpanel.

Design-language slot

slots.tabs Tabs (@kitora/ui/tabs, the default TabsList variant; the explicit line variant keeps its look).

  • style TabsStyleWhether the selected tab is a raised segment in a track or a line under it.
  • height PxHeight of the tab list.
  • trackCorner CornerThe track's corner (segmented only).
  • tabCorner CornerEach tab's corner.
  • track PerScheme<Fill>The track behind the tabs (segmented only; underline draws none).
  • selected PerScheme<Fill>The selected tab's fill (segmented only).
  • selectedEdge PerScheme<Fill>The selected tab's edge, drawn as a 1px border (none = no visible edge). It is the tab's pressed edge: every segmented language but Kitora gives one that reaches 3:1 against the track, since the selected fill alone barely differs from it (an underline style shows the state with its indicator instead).
  • selectedElevation ElevationHow much the selected tab lifts off the track.

Hooks and functions

  • tabsListVariants(props?: ({ variant?: "line" | "default" | null | undefined; size?: "default" | "sm" | "lg" | null | undefined; fill?: boolean | null | undefined; } & ClassProp) | undefined) => string

    The tab list's classes by variant, size and fill, for a host that draws its own list.
