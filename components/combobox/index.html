Combobox

An input you search a list with: type to filter, arrows to highlight (focus stays in the input), Enter to choose. Single or multiple with chips, groups, async lists, a search box inside the popup, Field and Form. The collections kit's Combobox (items as data, free text, async loading built in) builds on the same core.

Source: @kitora/ui (the primitive the kits compose)

01Default

Type to filter, ↑ and ↓ to highlight (focus stays in the input, the highlight is aria-activedescendant), Enter to choose, Escape to close and again to clear. The chevron and the clear button are the group's.

02Multiple with chips

multiple keeps the popup open and toggles items; the chosen values are chips in front of the input. Backspace on an empty input removes the last chip, ← walks onto the chips, and useComboboxAnchor anchors the popup to the whole box.

Astro
Remix

03Async search

Items fetched as you type: filter={null} turns the root's own filter off, ComboboxStatus says "Searching…" while the request is out and ComboboxEmpty shows only once it came back empty. The fake fetch is a timer that gives up when the text changes.

Chosen: nothing

04Groups

items as groups, each rendered by a ComboboxGroup with a ComboboxLabel and a ComboboxCollection; a group with no match leaves the list, and the group is named by its label.

05In a Field

A Field names the input (a press on the label focuses it), describes it and shows the error; required blocks a submit until something is chosen, and the chosen value is what the form submits.

Used for digests and due dates.

06Search box in the popup

ComboboxTrigger is the combobox (a button showing the value) and the ComboboxInput sits inside the popup, which takes focus when it opens and gives it back to the trigger.

07Chip labels and read-only

Each chip's remove button is named after the chip, the input's buttons take translated names, and read-only mutes the field and hides its buttons.

Français

08Grid rows

An emoji picker in rows of cells, moved through with the arrow keys across and down.

09Assign an owner

A Label, a Combobox with a Badge on each person, and a Button in a Card; the object items are the value, the Button assigns the chosen one.

Props

Combobox<Value, Multiple extends boolean | undefined = false>

A combobox root: the value, the typed text, the open state, the items. Renders no element.

  • multipleMultiple

    Default false

    Whether multiple items can be chosen (shown as chips).

  • valueValueOf<Value, Multiple> | null

    The chosen value (controlled); an array when multiple.

  • defaultValueValueOf<Value, Multiple> | null

    The chosen value at first (uncontrolled).

  • onValueChange(value: ValueOf<Value, Multiple> | (Multiple extends true ? never : null), eventDetails: ComboboxChangeEventDetails) => void

    Called when the chosen value changes, with why; details.cancel() refuses the change.

  • autoCompletestring

    A hint to the browser for autofill (the autocomplete attribute of the hidden input).

  • openboolean

    Whether the popup is open (controlled).

  • defaultOpenboolean

    Default false

    Whether the popup is initially open (uncontrolled).

  • onOpenChange(open: boolean, eventDetails: ComboboxChangeEventDetails) => void

    Called when the popup opens or closes, with why.

  • childrenReact.ReactNode

    The combobox's parts: Combobox.Input, Combobox.Portal and the rest.

  • idstring

    The id of the component (its input, or its trigger when the input is inside the popup).

  • formstring

    Identifies the form that owns the hidden input; useful when the combobox is rendered outside the form.

  • filternull | ListboxItemFilter<Value>

    Matches an item against the query; null lists every item. Default: contains under Intl.Collator.

  • disabledboolean

    Default false

    Whether the component should ignore user interaction.

  • namestring

    Identifies the field when a form is submitted.

  • readOnlyboolean

    Default false

    Whether the user should be unable to choose a different option from the popup.

  • requiredboolean

    Default false

    Whether the user must choose a value before submitting a form.

  • gridboolean

    Default false

    Whether the items are laid out as a grid (Combobox.Row rows).

  • itemsreadonly any[] | readonly ListboxGroup[]

    The items: a flat array or an array of groups ({ value, items }). With them the root filters, limits and labels the values itself.

  • virtualizedboolean

    Default false

    The items are virtualized by you: give each Combobox.Item its index.

  • inlineboolean

    Default false

    The list is rendered where you put it, with no popup.

  • limitnumber

    Default -1

    The most items listed (-1: no limit).

  • modalboolean

    Default false

    true: the page is blocked and its scroll locked while the popup is open.

  • localeIntl.LocalesArgument

    The locale of the string comparison. Default: the runtime's.

  • loopFocusboolean

    Default true

    Whether the arrow keys loop through the list and back to the input (APG: the input is part of the loop).

  • inputRefReact.Ref<HTMLInputElement>

    A ref to the hidden input element.

  • onOpenChangeComplete(open: boolean) => void

    Called after any animations complete when the popup opens or closes.

  • highlightItemOnHoverboolean

    Default true

    Whether moving the pointer over items highlights them. Off, CSS :hover and the keyboard highlight (data-highlighted) can differ.

  • actionsRefReact.RefObject<ComboboxRootActions | null>

    Imperative actions: unmount() (the popup then stays mounted after closing until it is called) and close().

  • openOnInputClickboolean

    Default true

    Whether the popup opens when the input is pressed.

  • autoHighlightboolean | "always"

    Default false

    Whether the first matching item is highlighted: true after the user types (kept while the query changes), "always" as soon as the list opens.

  • keepHighlightboolean

    Default false

    Whether the highlight stays when the pointer leaves the list.

  • homeEndKeysboolean

    Default false

    Whether Home and End on the input move the highlight to the first and the last item instead of the caret (a command menu, where the list is the point and the text is a filter). Only while the list is showing.

  • highlightedValueValue | null

    The value of the item to highlight (controlled from outside; onItemHighlighted reports every change the user makes). The highlight moves to the item whose value equals it whenever this prop or the listed items change; undefined leaves the highlight to the user. A value no listed item has is ignored.

  • inputValuestring

    The input value (controlled).

  • onInputValueChange(value: string, eventDetails: ComboboxChangeEventDetails) => void

    Called when the input value changes, with why.

  • defaultInputValuestring

    The input value at first (uncontrolled).

  • onItemHighlighted(itemValue: Value | undefined, eventDetails: ComboboxHighlightEventDetails) => void

    Called when an item is highlighted or unhighlighted (undefined for none) with why (keyboard, pointer, none for code) and its index.

  • filteredItemsreadonly any[] | readonly ListboxGroup[]

    The items to list, filtered by you (see useFilter); the root then does not filter items.

  • itemToStringLabel(itemValue: Value) => string

    For object values: the text the input shows. A { value, label } object needs none.

  • itemToStringValue(itemValue: Value) => string

    For object values: the text a form submits. A { value, label } object needs none.

  • isItemEqualToValue(itemValue: Value, value: Value) => boolean

    Default Object.is

    For object values that are not the same reference: whether an item's value is the selected one.

  • submitOnItemClickboolean

    Default false

    Whether choosing an item submits the owning form.

ComboboxChip

A chosen value in the chips box, with a remove button (showRemove, on by default). Backspace and Delete on it remove it. The remove button is named after the chip ("Remove Astro"), so a screen reader tells the buttons apart; removeLabel replaces the wording (a string, or a function of the chip's text).

  • showRemoveboolean

    Default true

    A button that removes the chip.

  • removeLabelstring | ((chipText: string) => string)

    Default (text) => `Remove ${text}`

    The remove button's name: a string, or a function of the chip's text.

  • removePropsOmit<ComboboxPrimitive.ChipRemove.Props, "children">

    Props for the remove button (a class, a data-* marker, a title); its aria-label wins over removeLabel.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ComboboxChips

The box of a multiple combobox: the chips and the input inside it, drawn like the input. A press on it focuses the input, and ← at the start of the input walks to the chips. Anchor the popup to it with useComboboxAnchor and ComboboxContent's anchor.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ComboboxChipsInput

The input inside the chips box: it takes the room the chips leave. Give it an aria-label, or a Field.Label.

  • disabledboolean

    Default false

    Whether the input should ignore user interaction.

Plus render, and className / style as functions of the part's state, and every <input> prop.

ComboboxClear

Empties the text and the value and keeps focus in the input; it is there only while there is something to clear.

  • nativeButtonboolean

    Default true

    Whether the rendered element is a native <button>.

  • disabledboolean

    Default false

    Whether the clear button ignores user interaction; the combobox's and the field's disabled disable it too.

  • keepMountedboolean

    Default false

    Whether to keep the button mounted while there is nothing to clear.

Plus render, and className / style as functions of the part's state, and every <button> prop.

ComboboxCollection

Renders the filtered items of a group (or of the list): give it a function of an item. Renders no element.

  • childrenrequired(item: any, index: number) => React.ReactNode

    Renders one item: a function of the item and its index.

ComboboxContent

The popup: portal, positioner and popup, as wide as what it is anchored to (the input group, the chips box with anchor, or the trigger when the search box is in the popup). Put a ComboboxList in it (and, for a search box in the popup, a ComboboxInput before the list).

  • initialFocusInitialFocusProp

    Where focus goes on open when the input is in the popup: true (default: the input), false, an element ref, or a function. Ignored while the input is beside the popup (it keeps focus).

  • finalFocusFinalFocusProp

    Where focus goes on close when the input is in the popup: true (default: the trigger), false, an element ref, or a function.

  • anchorPositionerAnchor

    What to place against instead of the trigger: an element, a virtual anchor (a point), a ref, or a function returning one.

  • sideAnchoredSideRequest

    Default "bottom"

    Which side of the anchor the popup sits on; inline-start / inline-end follow the text direction.

  • alignAnchoredAlign

    Default "start"

    Alignment along that side.

  • sideOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 4

    Gap between anchor and popup, px or a function of the placement.

  • alignOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 0

    Shift along the anchor's edge.

  • containerPortalContainerOption

    Render the popup into this element instead of document.body.

  • backdropboolean

    Default false

    Draw an overlay behind the popup.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ComboboxEmpty

ComboboxInput

The input, in a group the popup is anchored to. showTrigger (default) puts a chevron button at the end, showClear a clear button (which replaces the chevron while there is something to clear); children go in the group after them. className is the group's. Give the input its own aria-label, or a Field.Label.

  • disabledboolean

    Default false

    Whether the input should ignore user interaction.

  • classNamestring

    The group's class (the input inside it is styled by the group).

  • inputClassNamestring

    The <input>'s own class, merged after the group's control classes.

  • showTriggerboolean

    Default true

    A chevron button that opens the popup.

  • showClearboolean

    Default false

    A clear button, shown while there is something to clear.

  • triggerLabelstring

    Default "Show suggestions"

    The chevron button's name for screen readers.

  • clearLabelstring

    Default "Clear"

    The clear button's name for screen readers.

Plus render, and className / style as functions of the part's state, and every <input> prop.

ComboboxItem

One option in the combobox's list, with a check mark at the end while it is selected.

  • valueany

    Default null

    A unique value that identifies this item (what the root's items hold).

  • indexnumber

    The item's place in the list: required when the list is virtualized (only some items are mounted), optional otherwise.

  • labelstring

    The text typeahead and the input match; default: the item's text content.

  • disabledboolean

    Default false

    Whether the item cannot be chosen (it can still be highlighted).

  • nativeButtonboolean

    Default false

    Whether the rendered element is a native <button>. A <div> is better: a focusable item would take focus from the input.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ComboboxItemText

The text of an item with the typed query marked (@kitora/ui/highlight): <ComboboxItem value={x}><ComboboxItemText>{x}</ComboboxItemText></ComboboxItem>. The query is the input's current text, read from the root; pass query to mark something else (a server's match, the query before an inline completion). The marks are presentational: the option's accessible name stays its full text.

  • classNamestring

    Classes on the wrapping <span>.

  • variantHighlightVariant

    Default "underline"

    Base look of each <mark>: an underline, a tint, or none (style it with markClassName).

  • markClassNamestring

    Classes for each <mark>, merged after the variant's classes.

  • matchOptionsHighlightMatchOptions

    How query matches (case-sensitive, whole words). Ignored for ranges and indices.

  • renderMatch(text: string, index: number, term: number) => React.ReactNode

    Draws a matched run yourself (a link, a coloured span); the default is a <mark>. index counts the marks; term is the index of the query term that hit it (the first one, where hits of several terms merged), so each term can take its own colour, or -1 for ranges / indices.

  • childrenrequiredstring

    The item's full text, the string the marks are drawn in.

  • querystring

    The text to mark instead of the input's current text (a server's match, the query before an inline completion).

ComboboxLabel

ComboboxList

The list the input controls (role="listbox"); give it a function of an item to render the filtered items. It scrolls when it is taller than the room.

ComboboxRow

A row of a grid list (a grid root, the primitives' Combobox.Row, role="row"): its items are cells, ←/→ move along the row and ↑/↓ between rows. The cells share the row's width, centred, with no check mark (a picked cell shows by its fill); for an emoji or a colour swatch picker.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ComboboxSeparator

ComboboxStatus

A message a screen reader announces politely: "Searching…", a count.

ComboboxTrigger

The button that opens the popup: a chevron by default. Inside ComboboxInput (showTrigger) it is an icon button of the group.

  • nativeButtonboolean

ComboboxValue

The chosen value as text, for a combobox that shows it outside the input (a trigger button). Renders no element.

  • childrenReact.ReactNode | ((selectedValue: any) => React.ReactNode)

    What to show: a node, or a function of the chosen value. Default: the chosen item's label (read from items).

  • placeholderReact.ReactNode

    What to show while nothing is chosen.

Keyboard

  • ArrowDownCombobox.InputGroupOpens the list and highlights the chosen item, else the first (Alt+ArrowDown only opens); in an open list it moves the highlight down, past the last item back to the input.
  • ArrowUpCombobox.InputGroupOpens the list and highlights the last item; in an open list it moves the highlight up, past the first item back to the input.
  • EscapeCombobox.InputGroupCloses the list; a second Escape clears the text and the chosen value.
  • ArrowDownArrowUpCombobox.TriggerOpens the list and moves focus to its input (ArrowUp highlights the last item).
  • EnterSpaceCombobox.TriggerOpens or closes the list.
  • ArrowRightCombobox.ChipMoves focus to the next chip, past the last one to the input (the previous chip right to left).
  • ArrowLeftCombobox.ChipMoves focus to the previous chip, before the first one to the input (the next chip right to left).
  • ArrowDownArrowUpCombobox.ChipOpens the list and returns focus to the input.

Accessibility

  • Combobox follows the WAI-ARIA Combobox pattern: roles combobox, listbox, option.

Hooks and functions

    The ref that anchors the popup to the chips box: <ComboboxChips ref={anchor}> and <ComboboxContent anchor={anchor}>.

  • useComboboxFilter(options?: UseComboboxFilterOptions) => ListboxFilter

    The matchers of one collator (contains, startsWith, endsWith, exact), for a list that filters items itself and hands them to the root's filteredItems.

  • useComboboxFilteredItems<Item = any>() => readonly Item[]

    The items the root listed after filtering (groups when items are groups); call it inside the root.
