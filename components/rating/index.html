Props

Rating

A star rating. Every Rating.Root prop passes through (value / defaultValue / onValueChange, max default 5, allowHalf, clearable, readOnly, disabled, name, getItemLabel); size is sm, md (default) or lg; icon swaps the star. Give it an accessible name (aria-label or aria-labelledby).

  • valuenumber

    The chosen value (controlled); 0 means not rated. Snapped to the step and kept inside [0, max].

  • defaultValuenumber

    Default 0

    The value at first (uncontrolled).

  • onValueChange(value: number, eventDetails: RatingChangeEventDetails) => void

    Called when the user changes the value, with the new value and the change details (details.cancel() vetoes).

  • maxnumber

    Default 5

    The number of items, and the largest value.

  • allowHalfboolean

    Default false

    Whether half values (2.5) can be chosen.

  • clearableboolean

    Default false

    Whether a press on the chosen value clears the rating to 0.

  • readOnlyboolean

    Default false

    Whether the value is shown, focusable and named, but cannot be changed.

  • disabledboolean

    Default false

    Whether the rating ignores the user and leaves the tab order.

  • namestring

    The form field name: a hidden input submits the value under it.

  • formstring

    The form the hidden input belongs to.

  • getItemLabel(value: number) => string

    Default `defaultRatingItemLabel` ("3 stars")

    The accessible name of the item standing for a value.

  • size"sm" | "lg" | "md" | null

    Default "md"

    The icon size: sm 14px, md 20px, lg 28px.

  • iconReact.ReactNode

    Default a star

    The icon each item draws (outlined when empty, filled when chosen).

  • itemClassNamestring

    Classes for each item.

Plus render, and className / style as functions of the part's state, and every <div> prop.

Accessibility

  • Rating follows the WAI-ARIA Radio Group pattern: roles radiogroup, radio.

Hooks and functions

  • ratingItemVariants(props?: ({ size?: "sm" | "lg" | "md" | null | undefined; } & ClassProp) | undefined) => string

    The classes of one rating item (focus ring, hover growth, icon size by size), for a host that draws its own items.
