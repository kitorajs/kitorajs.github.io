DropdownMenu

Context menu / action menu with sub-menus, separators, destructive items.

Source: @kitora/ui (the primitive the kits compose)

02One menu, many row triggers

A row's button opens the same DropdownMenu with that row's payload; no menu per row.

03Open on hover, with link items

openOnHover (with delay and closeDelay) opens the menu when the pointer rests on the trigger; DropdownMenuLinkItem is an <a> item and arrow points the menu at its trigger.

Rest the pointer on the button: the menu opens, the items are links, and a press commits to it. The keyboard works as it does on any menu button.

04Backdrop and arrow

backdrop dims the page behind the menu and arrow draws a pointer at the trigger; a press on the dim closes the menu.

05One menu morphing between triggers

DropdownMenuContent morph animates one menu between triggers that open it on hover: the menu moves and resizes and the items slide toward the new trigger.

One menu, three triggers: moving from one to the next slides the items and resizes the menu.

06Item descriptions

Sharing choices with a muted second line that each item names in aria-describedby.

07Searchable: move to one of 40 folders

DropdownMenuFilterProvider around the menu makes it searchable: DropdownMenuInput filters the items as you type (accent and case insensitive), groups with no match and their separators hide, ↑ / ↓ move the highlight while focus stays in the input, Enter moves. autoHighlight puts it on the first match; DropdownMenuClear and DropdownMenuEmpty clear the text and say when nothing matches. The Archive submenu has a filter of its own.

Not moved yet

08Account menu

An Avatar trigger opens a DropdownMenu with the user's name and email, profile, settings and sign out.

09Build your own

The same menu from the primitives' Menu parts only: items, a label, a checkbox item, a radio group and a submenu; a rebuild test compares it with ui's.

Props

DropdownMenu<Payload = unknown>

A menu of actions that opens from a trigger button; Menu.Root from

  • openboolean

    Whether the menu is open (controlled).

  • defaultOpenboolean

    Default false

    Whether it starts open (uncontrolled).

  • onOpenChange(open: boolean, details: MenuChangeEventDetails) => void

    Called when the open state is about to change; details.cancel() refuses it.

  • onOpenChangeComplete(open: boolean) => void

    Called after the open or close animation finished.

  • disabledboolean

    Default false

    Disables the whole menu: the trigger does not open it.

  • modalboolean

    true (default): the page scroll is locked and an invisible backdrop blocks the page while open. Ignored on a submenu.

  • loopFocusboolean

    Default true

    Arrow keys wrap from the last item to the first.

  • orientationRovingOrientation

    Default "vertical"

    The direction the items run in (arrow keys follow it).

  • highlightItemOnHoverboolean

    Default true

    The pointer highlights (and focuses) the item it moves over.

  • closeParentOnEscboolean

    Default false

    Escape in a submenu closes the parent menus too.

  • triggerIdstring | null

    ID of the trigger the menu is attached to: with a controlled open, which of several triggers it opens from.

  • defaultTriggerIdstring | null

    ID of the trigger the menu is attached to when it starts open (defaultOpen).

  • actionsRefReact.RefObject<MenuRootActions | null>

    A ref to imperative actions: close(), and unmount() for a popup kept mounted with details.preventUnmountOnClose().

  • handleMenuHandle<Payload>

    A handle that lets Menu.Triggers outside this Root open it (Menu.createHandle()).

  • childrenReact.ReactNode | PayloadChildRenderFunction<Payload>

    The content: nodes, or a function of the payload of the trigger the menu is attached to.

DropdownMenuFilterProvider

Makes the menu inside it searchable (value / defaultValue / onValueChange, autoHighlight, filter, locale). Renders nothing.

  • valuestring

    The filter text (controlled).

  • defaultValuestring

    Default ""

    The starting text (uncontrolled).

  • onValueChange(value: string, details: MenuFilterChangeEventDetails) => void

    Called before the text changes; details.reason says why and details.cancel() keeps the old text.

  • autoHighlightboolean | "always"

    Default false

    Highlight the first match as the text changes (true), also with no text ("always"), or not (false).

  • filter(itemText: string, query: string) => boolean) | null

    Whether an item's text matches the query; null shows every item (the host filters them). Default: useFilter().contains.

  • localeIntl.LocalesArgument

    The locale of the default matcher. Default: the page's.

  • childrenReact.ReactNode

    The Menu.Root (or Menu.SubmenuRoot) to make searchable.

DropdownMenuInput

The filter's text box, above the items. Give it an aria-label (and a placeholder) that says what it searches.

Plus render, and className / style as functions of the part's state, and every <input> prop.

DropdownMenuClear

Clears the text (shown only while there is text). label names it for assistive tech.

  • labelstring

    Default "Clear search"

    The clear button's accessible name and tooltip.

Plus render, and className / style as functions of the part's state, and every <button> prop.

DropdownMenuEmpty

The message while nothing matches, below the items.

Plus render, and className / style as functions of the part's state, and every <div> prop.

DropdownMenuPortal

Moves the menu's popup to the end of the document (or into container).

  • childrenReact.ReactNode

    The positioner and popup to move.

  • containerPortalContainerOption

    Render the popup into this element instead of document.body.

  • keepMountedboolean

    Default false

    Keep the popup mounted (hidden) while closed.

  • classNamestring

    A class for the node the portal creates.

  • preserveTabOrderboolean

    Keep the tab order natural across the portal.

Plus every HTML prop.

DropdownMenuTrigger<Payload = unknown>

The button that opens the menu; takes asChild as well as render.

  • handleMenuHandle<Payload>

    A handle that associates this trigger with a Menu.Root elsewhere in the tree (Menu.createHandle()).

  • payloadPayload

    What the menu's content receives (children of the Root as a function) while it is attached to this trigger.

  • disabledboolean

    Default false

    Disables the trigger.

  • nativeButtonboolean

    Default true

    Whether the rendered element is a native <button>; false adds role="button" and keyboard activation.

  • openOnHoverboolean

    Default false

    Open the menu when the pointer rests on the trigger, as well as on press. In a Menubar: while a menu of the bar is open.

  • delaynumber

    Default 100

    How long the pointer must rest on the trigger before the menu opens, in ms. Needs openOnHover.

  • closeDelaynumber

    Default 0

    How long after the pointer leaves before a hover-opened menu closes, in ms. Needs openOnHover.

  • asChildboolean

    Whether the single child element renders in place of the part's own element, with the part's props merged onto it (the Radix-style spelling of render).

Plus render, and className / style as functions of the part's state, and every <button> prop.

DropdownMenuContent

The menu's popup, portalled and placed against its trigger, with an optional backdrop, arrow and morph between triggers.

  • finalFocusFinalFocusProp

    Where focus goes on close: true (default: the trigger), false, an element ref, or a function.

  • sideAnchoredSideRequest

    Default "bottom"

    Which side of the anchor the popup sits on; inline-start / inline-end follow the text direction.

  • alignAnchoredAlign

    Default "start"

    Alignment along that side.

  • sideOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 4

    Gap between anchor and popup, px or a function of the placement.

  • alignOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 0

    Shift along the anchor's edge.

  • stickyboolean

    Default false

    Keep the popup against its anchor's edge while the anchor scrolls away.

  • positionMethodPositionStrategy

    absolute (default) follows the page while it scrolls; fixed places in the viewport.

  • collisionBoundaryCollisionBoundary

    Default "clipping-ancestors"

    What the popup must stay inside.

  • collisionPaddingnumber | Partial<PlacementPadding>

    Default 5

    Space kept from the boundary's edges.

  • arrowPaddingnumber

    Default 5

    Space kept between the arrow and the popup's corners.

  • disableAnchorTrackingboolean

    Default false

    Do not follow the anchor after the first placement.

  • collisionAvoidanceCollisionAvoidance

    Flip, shift or neither, per axis.

  • containerPortalContainerOption

    Render the popup into this element instead of document.body.

  • backdropboolean

    Default false

    Draw an overlay behind the menu.

  • arrowboolean

    Default false

    Draw an arrow pointing at the trigger.

  • morphboolean

    Default false

    One menu opened by several triggers (handle and payload): animate the move and the content change between them.

Plus render, and className / style as functions of the part's state, and every <div> prop.

DropdownMenuItemDescriptionContext

How an item learns about a DropdownMenuItemDescription inside it: the description reports its id, and the item names it in aria-describedby, so a screen reader reads the item's label as its name and the second line as its description. Only while a description is mounted: an item without one renders exactly what it rendered before.

Plus every HTML prop.

Keyboard

  • EnterSpaceMenu.TriggerOpens the menu and moves focus into it.
  • ArrowDownMenu.TriggerOpens the menu with its first item focused.
  • ArrowUpMenu.TriggerOpens the menu with its last item focused.
  • ArrowDownMenu.ItemMoves focus to the next item, wrapping from the last to the first.
  • ArrowUpMenu.ItemMoves focus to the previous item, wrapping from the first to the last.
  • HomeMenu.ItemMoves focus to the first item.
  • EndMenu.ItemMoves focus to the last item.
  • EnterSpaceMenu.ItemActivates the focused item (Enter on press, Space on release) and closes the menu.
  • EscapeMenu.ItemCloses the menu (a submenu first) and returns focus to the trigger.
  • ArrowRightMenu.SubmenuTriggerOpens the submenu with its first item focused (ArrowLeft right to left).
  • EnterSpaceMenu.SubmenuTriggerOpens the submenu.

Accessibility

  • Menu follows the WAI-ARIA Menu Button pattern: roles button, menu, menuitem.

Hooks and functions

  • createDropdownMenuHandle<Payload = unknown>() => MenuPrimitive.Handle<Payload>

    Connects a DropdownMenu with triggers that sit elsewhere in the tree (handle on the root and on each trigger), and opens it from code.

  • useDropdownMenuItemDescription(own: string | undefined) => { describedBy: string | undefined; register: (id: string | undefined) => void; }

    The id of the description inside an item (if any), joined with the caller's own aria-describedby.
