QrCode

QR code drawn as one SVG path with selectable error correction, used for authenticator setup links. The auth kit's QrCode.

Source: @kitora/auth (the single implementation; no other package ships one)

Full API on the auth kit gallery

Used inTwoFactorSetup · auth
  • On this page:
  • Default
  • Authenticator setup
  • Error correction
  • API reference
  • Anatomy

01Default

A QR code for a link, named by label.

https://example.com/invite/7f3a91

02Authenticator setup

totpUri builds the link an authenticator app scans, redrawn as the account changes.

JBSW Y3DP EHPK 3PXP JBSW Y3DP EHPK 3PXP

03Error correction

ecc from L to H trades density for damage tolerance.

Props

QrCode

A QR code drawn as one SVG path in currentColor on a white plate, so scanners read it in dark mode too.

  • valuerequiredstring

    The text to encode, such as an otpauth:// URI.

  • sizenumber

    Default 168

    Rendered size in px.

  • eccQrEcc

    Default "M"

    Error correction level: higher levels survive more damage but need more modules.

  • marginnumber

    Default 4

    Light border around the code, in modules (QR_QUIET_ZONE).

  • labelstring

    Default "QR code"

    Accessible name.

  • classNamestring

    Classes for the <svg>.

Hooks and functions

  • QR_QUIET_ZONE

    Quiet zone, in modules (the standard asks for 4).
