FormatNumber

Locale-aware numbers, currency, bytes, dates and relative times as components; a DisplayProvider sets the locale. The display kit's FormatNumber, FormatBytes, FormatDate and RelativeTime.

Source: @kitora/display (the single implementation; no other package ships one)

Full API on the display kit gallery

Props

FormatNumber

A number in the locale: decimal, currency, percent, unit or compact. Tabular figures.

  • valuerequirednumber

    The number to format.

  • optionsIntl.NumberFormatOptions

    Intl.NumberFormat options: { style: "currency", currency: "EUR" }, { style: "percent" }, { style: "unit", unit: "kilometer-per-hour" }, { notation: "compact" }.

  • localestring

    A per-component locale; default the adapter's (the provider's locale, else the runtime's).

  • classNamestring

    Class for the element that holds the text.

  • children(text: string) => ReactNode

    Render the formatted text yourself.

FormatBytes

A file or transfer size: 1.5 MiB, 1.5 MB.

  • valuerequirednumber

    A byte count; negative for a shrink.

  • unitsByteUnitSystem

    Default "binary"

    binary (1024, KiB) or decimal (1000, kB).

  • maximumFractionDigitsnumber

    Default 1

    Most fraction digits a scaled size shows; whole bytes never show a fraction.

  • unitDisplay"short" | "narrow" | "long"

    Default "short"

    How decimal units are spelled: short (kB), narrow or long (kilobytes); binary symbols do not change.

  • localestring

    A per-component locale; default the adapter's (the provider's locale, else the runtime's).

  • classNamestring

    Class for the element that holds the text.

  • children(text: string) => ReactNode

    Render the formatted text yourself.

FormatDate

A date and/or time as <time dateTime>; an invalid date renders — with no dateTime.

  • valuerequiredDate | number

    The date as a Date or epoch milliseconds.

  • dateStyleIntl.DateTimeFormatOptions["dateStyle"]

    Intl date style (full, long, medium, short); medium when neither style nor options is given.

  • timeStyleIntl.DateTimeFormatOptions["timeStyle"]

    Intl time style (full, long, medium, short); no time when omitted.

  • optionsIntl.DateTimeFormatOptions

    Field-by-field options; win over dateStyle / timeStyle.

  • timeZonestring

    An IANA zone (UTC, Asia/Kolkata); set it when the text must match between server and browser.

  • localestring

    A per-component locale; default the adapter's (the provider's locale, else the runtime's).

  • classNamestring

    Class for the element that holds the text.

  • children(text: string) => ReactNode

    Render the formatted text yourself.

RelativeTime

3 min. ago, in 2 days, as <time dateTime title={absolute}>. Without now the server and the first browser render show the absolute date, so hydration matches; the relative text replaces it once mounted and stays current while live.

  • valuerequiredDate | number

    The instant, as a Date or epoch milliseconds.

  • nowDate | number

    A fixed "now": the first render already reads relative (and matches on server and browser).

  • liveboolean

    Re-render from the real clock after mount (every second under a minute, every minute under an hour, else hourly). Default: true without now, false with it.

  • absoluteOptionsIntl.DateTimeFormatOptions

    Default ABSOLUTE_OPTIONS

    Options of the absolute form (the tooltip, and the text until mounted when there is no now); by default { dateStyle: "medium", timeStyle: "short" }.

  • localestring

    A per-component locale; default the adapter's (the provider's locale, else the runtime's).

  • classNamestring

    Class for the element that holds the text.

  • children(text: string) => ReactNode

    Render the formatted text yourself.
