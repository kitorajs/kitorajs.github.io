IconButton

Icon-only button with a required label, a pressed state for toggles and a native or styled tooltip. The one every kit toolbar uses.

Source: @kitora/ui (the primitive the kits compose)

01Sizes and states

24 / 28 (default) / 32 / 36px. pressed sets aria-pressed and the primary tint; label is the accessible name and the native title.

02Tooltips

tooltip shows a styled tooltip: true for the label, or any node, such as the label plus a key cap. false drops the title.

03Loading and toggle

A loading icon button, and pressed toggles in uncontrolled and controlled form.

04Formatting toolbar

Toggle IconButtons for bold / italic / underline and plain actions for undo / redo, split by a Separator, inside a toolbar.

Props

IconButton

An icon-only Button (ghost by default) with a required accessible name, an optional pressed state that makes it a toggle, and a native title or a styled tooltip.

  • labelrequiredstring

    Accessible name. Also the tooltip text unless tooltip says otherwise. Required: an icon has no text.

  • pressedboolean

    Pressed state (controlled). Any of pressed, defaultPressed, onPressedChange makes this a real toggle: aria-pressed, data-pressed and the pressed fill. Leave all three undefined for a plain action.

  • defaultPressedboolean

    Initial pressed state of an uncontrolled toggle.

  • onPressedChange(pressed: boolean) => void

    Called with the next pressed state when the toggle is pressed on or off.

  • sizeIconButtonSize

    Default "sm"

    24 / 28 / 32 / 36px square; the default sm (28px) is the compact toolbar size.

  • tooltipReact.ReactNode

    undefined (default): the native title shows label. true: a styled tooltip showing label. A node: a styled tooltip showing that node (for example the label plus a key cap). false: no tooltip and no title.

  • tooltipSide'top' | 'bottom' | 'left' | 'right'

    Default "top"

    Tooltip side when a styled tooltip is drawn.

  • variant"link" | "default" | "secondary" | "outline" | "ghost" | "soft" | "destructive" | "destructive-soft" | null

    Default "ghost"

    The colour scheme and emphasis.

  • loadingboolean

    Default false

    Busy: aria-busy="true" and data-loading, activation blocked but focus kept (focusable-disabled semantics, so focus is not dropped mid-submit), full opacity. The children stay in place, invisible, so the width does not jump, with a spinner centred over them. Controlled by this prop only.

  • renderUseRenderRenderProp

    The primitives' render prop, an alias of asChild with the element given here instead of as the child: an element (cloned with the button's props) or a function (props) => element. asChild wins when both are given.

  • focusableWhenDisabledboolean

    Default false

    Keep a disabled button in the tab order: aria-disabled="true" instead of disabled, clicks and every key but Tab blocked (the primitive useButton), hover kept so a Tooltip can explain why.

  • nativeButtonboolean

    Whether the rendered element is a native <button>. Only read with focusableWhenDisabled or loading (it decides aria-disabled vs role="button" handling). Defaults to true unless render/asChild gives an element other than <button>.

Plus every <button> prop.
