Marker

A line in a conversation that is not a message: a named day separator (optionally sticky), a "New messages" row or a boxed status line.

Source: @kitora/ui (the primitive the kits compose)

Props

Marker

A non-message line: a day separator, "New messages", "Conversation compacted".

  • variantMarkerVariant

    Default "default"

    default (an inline row), border (a boxed row) or separator (a centred label between rules).

  • labelstring

    A separator's accessible name; defaults to its children when they are a plain string.

  • stickyboolean

    Default false

    A separator only: pin the label to the top of the scroller while its section is on screen.

Plus render, and className / style as functions of the part's state, and every <div> prop.

MarkerContent

The marker's text; in a separator, the label pill between the rules.

Plus every <span> prop.

MarkerIcon

The marker's icon; decorative (aria-hidden), so the text must say it all.

Plus every <span> prop.
