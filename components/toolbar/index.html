Props

Toolbar

A row (or column) of controls with ONE tab stop: Tab enters it once, the arrow keys along its orientation (mirrored in right to left) move between its buttons, links, inputs, toggles and menu triggers, Home and End jump to the ends. A disabled button stays focusable (aria-disabled) unless it sets focusableWhenDisabled={false}. The parts are the primitives' Toolbar.*; ToolbarButton takes Button's variant and size, so a toggle, a menu trigger or a split button can render through it with render.

  • disabledboolean

    Default false

    Disables every button and input in the toolbar.

  • orientationOrientation

    Default "horizontal"

    The direction the arrow keys move in.

  • loopFocusboolean

    Default true

    Whether the arrow keys wrap from the last item to the first and back.

  • densityToolbarDensity

    Default "default"

    compact tightens the bar and turns its buttons and toggles into 28px tool buttons (see ToolbarDensity).

Plus render, and className / style as functions of the part's state, and every <div> prop.

ToolbarOverflow

Items of a Toolbar that collapse into a trailing "More" menu when the bar is too narrow (opt-in; a bar without it is unchanged). It fills the rest of the bar (flex-1), so give the Toolbar a width (w-full, a max-w-*) for there to be something to fit; a vertical bar fits heights the same way. The fitted items keep their order and the overflowed ones continue it in the menu: the bar stays one tab stop, arrows walk the fitted items then the More trigger, and if the focused item overflows, focus moves to the trigger. Toggles keep their state while they move between bar and menu. The More menu's open state is controlled (open + onOpenChange) or not (defaultOpen).

  • openboolean

    Whether the menu is open (controlled).

  • defaultOpenboolean

    Default false

    Whether it starts open (uncontrolled).

  • onOpenChange(open: boolean, details: MenuChangeEventDetails) => void

    Called when the open state is about to change; details.cancel() refuses it.

  • itemsrequiredreadonly ToolbarOverflowEntry[]

    The items in order, drawn on the bar while they fit and in the More menu once they do not.

  • moreLabelstring

    Default "More"

    The More trigger's accessible name.

  • moreIconReact.ReactNode

    Default a horizontal ellipsis

    The More trigger's icon.

  • onOverflowChange(hiddenIds: string[]) => void

    Called with the ids of the items in the menu whenever that set changes (separators left out).

Plus every <div> prop.

ToolbarGroup

A set of related items: they share a gap, and disabled disables all of them.

  • disabledboolean

    Default false

    Disables every button and input in the group.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ToolbarButton

A button. Pressed toggles read as such (aria-pressed or data-pressed), and a disabled one stays in the tab order but looks and acts disabled. In a density="compact" bar it is a 28px tool button and variant / size do not apply.

  • disabledboolean

    Default false

    Disables the button.

  • focusableWhenDisabledboolean

    Default true

    Whether the button stays focusable (and a stop of the toolbar) while disabled.

  • nativeButtonboolean

    Default true

    Whether the part renders a native <button>; set false when render gives another element.

  • variant"link" | "default" | "secondary" | "outline" | "ghost" | "soft" | "destructive" | "destructive-soft" | null

    Default "ghost"

    The colour scheme and emphasis.

  • size"default" | "xs" | "sm" | "lg" | "xl" | "icon" | "icon-xs" | "icon-sm" | "icon-lg" | null

    Default "sm"

    The height and padding; the icon-* sizes make a square button for a lone icon.

  • densityToolbarDensity

    This item's density; defaults to its Toolbar's. A kit that always draws compact items sets it so a bar of another density does not restyle them.

Plus render, and className / style as functions of the part's state, and every <button> prop.

ToolbarToggle<Value extends string = string>

A two-state button (aria-pressed) that is one stop of the bar: Bold, Italic, Wrap. Base UI's composition, Toolbar.Button rendering a Toggle, so the toolbar owns the focus and the toggle owns the state; it draws as ToolbarButton with the toolbar slot's pressed fill. Pressed is controlled (pressed + onPressedChange) or not (defaultPressed). Inside a ToolbarToggleGroup, value names it and the group holds the state.

  • variant"link" | "default" | "secondary" | "outline" | "ghost" | "soft" | "destructive" | "destructive-soft" | null

    Default "default"

    The colour scheme and emphasis.

  • size"default" | "xs" | "sm" | "lg" | "xl" | "icon" | "icon-xs" | "icon-sm" | "icon-lg" | null

    Default "default"

    The height and padding; the icon-* sizes make a square button for a lone icon.

  • disabledboolean

    Default false

    Disables the button.

  • focusableWhenDisabledboolean

    Default true

    Whether the button stays focusable (and a stop of the toolbar) while disabled.

  • nativeButtonboolean

    Default true

    Whether the part renders a native <button>; set false when render gives another element.

  • densityToolbarDensity

    This item's density; defaults to its Toolbar's. A kit that always draws compact items sets it so a bar of another density does not restyle them.

  • valueValue

    The value identifying this toggle in its ToggleGroup.

  • pressedboolean

    Whether the toggle is currently pressed (controlled).

  • defaultPressedboolean

    Default false

    Whether the toggle is initially pressed (uncontrolled).

  • onPressedChange(pressed: boolean, eventDetails: ChangeDetails) => void

    Called when the toggle is pressed on or off, with the new state and the change details (details.cancel() vetoes).

Plus render, and className / style as functions of the part's state, and every <button> prop.

ToolbarToggleGroup<Value extends string = string>

A set of toggles sharing one value (multiple or a single choice; value + onValueChange controlled, defaultValue not). It is the primitives' ToggleGroup inside the toolbar, which hands its toggles to the toolbar's roving focus: each ToolbarToggle in it is a stop of the bar, not a nested tab stop. It follows the toolbar's orientation unless given its own.

  • valuereadonly Value[]

    The values of the pressed toggles (controlled).

  • defaultValuereadonly Value[]

    Default []

    The values of the toggles pressed at first (uncontrolled).

  • onValueChange(groupValue: Value[], eventDetails: ChangeDetails) => void

    Called when a toggle is pressed on or off, with the group's new value (details.cancel() vetoes).

  • disabledboolean

    Default false

    Whether the group ignores user interaction.

  • multipleboolean

    Default false

    Whether more than one toggle may be pressed at once.

  • loopFocusboolean

    Default true

    Whether focus wraps from the last toggle to the first and back.

  • orientation"horizontal" | "vertical"

    Default "horizontal"

    The direction of the arrow keys.

  • disallowEmptySelectionboolean

    Default false

    Whether a press that would leave no toggle pressed is cancelled (the last pressed toggle stays pressed and onValueChange is not called). Not part of Base UI, whose groups can always be emptied.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ToolbarLink

A link styled like a ghost button.

Plus render, and className / style as functions of the part's state, and every <a> prop.

ToolbarInput

A text field. Its arrow keys move its caret; they hand over to the toolbar once the caret is at the edge of the text.

  • defaultValueReact.ComponentPropsWithRef<"input">["defaultValue"]

    The starting value when uncontrolled.

  • disabledboolean

    Default false

    Disables the input.

  • focusableWhenDisabledboolean

    Default true

    Whether the input stays focusable (and a stop of the toolbar) while disabled.

Plus render, and className / style as functions of the part's state, and every <input> prop.

ToolbarSeparator

A divider between items, across the toolbar.

  • orientationOrientation

    Default "horizontal"

    The orientation of the separator.

  • densityToolbarDensity

    The separator's size, shorter in a compact bar; defaults to the bar's density.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ToolbarSpacer

Free space that pushes the items after it to the far end of the bar (give the Toolbar a width, e.g. w-full, for it to have room). Hidden from assistive technology.

Plus every <div> prop.

Keyboard

Toolbar

  • ArrowRightToolbar.ButtonMoves focus to the next item of a horizontal toolbar (the previous one right to left), wrapping unless `loopFocus` is false.
  • ArrowLeftToolbar.ButtonMoves focus to the previous item of a horizontal toolbar (the next one right to left), wrapping unless `loopFocus` is false.
  • EndToolbar.ButtonMoves focus to the last item.

ToggleGroup

  • ArrowRightToggleMoves focus to the next toggle in a horizontal group (the previous one right to left), wrapping unless `loopFocus` is false.
  • ArrowLeftToggleMoves focus to the previous toggle in a horizontal group (the next one right to left), wrapping unless `loopFocus` is false.
  • SpaceEnterTogglePresses or releases the focused toggle (a single group releases the one pressed before).

Toggle

  • SpaceEnterTogglePresses or releases the toggle.

Accessibility

  • Toolbar follows the WAI-ARIA Toolbar pattern: roles toolbar.
  • Toggle follows the WAI-ARIA Button pattern: roles button.

Design-language slot

slots.toolbar Toolbar (@kitora/ui/toolbar): the bar around the buttons (which read the button slot) and a pressed toggle in it.

  • corner CornerThe bar's corner.
  • surface PerScheme<Fill>The bar's fill per scheme.
  • edge PerScheme<Fill>The bar's 1px edge per scheme (none for no visible edge).
  • pressed ToolbarPressedStyleHow a pressed toggle button in the bar is drawn.

Hooks and functions

  • TOOLBAR_DENSITIES

    How dense the bar is. default: Button-sized items (the button slot's sizes, variant and size per item). compact: a tighter bar (2px inset and gap) whose items are square 28px tool buttons with 13px text and no Button chrome (no border, press nudge or weight): the look the collections kit's item-array Toolbar has always had, kept here so both toolbars draw from one place.

  • toolbarCompactItemClass

    The compact item look (density="compact"). Exported so a kit that also renders these items outside a toolbar (as a plain button another row roves) draws the same pixels there. The pressed fill, text and inner shade read the toolbar slot like ToolbarButton's.
