FileTree

A tree of folders and files on TreeView: from items or a list of paths, sorted folders first in natural order, with folder and file-kind icons, the size and date as the hint, Enter or a double-click opening a file (onOpenFile), and foldersOnly for a folder picker. Every TreeView prop (selection, expanded, checkboxes, loadChildren, filter, virtual, …) works unchanged. Give it an aria-label.

  • pathsrequiredreadonly PathEntry[]

    The paths ("src/ui/button.tsx"; a trailing separator is an empty folder), or entries with a size, type and date.

  • itemsundefined

    Not with paths: give one or the other.

  • valuereadonly string[]

    Controlled selection (ids); leave undefined to let the hook keep its own, seeded by defaultValue.

  • defaultValuereadonly string[]

    Starting selection (ids) when uncontrolled.

  • classNamestring

    Class names for the tree, after classNames.root.

  • classNamesTreeViewClassNames

    Default {}

    Class names for the parts, by name.

  • defaultCheckedreadonly string[]

    Leaves checked at the start when uncontrolled.

  • draggableboolean | ((item: T) => boolean)

    Which rows can be dragged: all, or a predicate; default off (no drag at all).

  • styleCSSProperties

    Inline style for the tree, merged over its max height.

  • aria-labelstring

    Accessible name of the tree when there is no visible label.

  • aria-labelledbystring

    Id of the element that names the tree.

  • onChange(ids: string[]) => void

    Called when the selection changes, with the selected ids.

  • filterstring

    Show only items matching this query (and their ancestors).

  • checkedreadonly string[]

    Controlled checked leaves (ids); leave undefined to let the hook keep its own, seeded by defaultChecked.

  • heightnumber

    Max height in px before it scrolls (default: none).

  • rowHeightnumber

    Default 28

    Row height in px the virtual window counts in (the kit's compact row).

  • selectionModeSelectionMode

    Default "single"

    How items select; ignored when checkboxes is on.

  • virtualboolean

    Whether to mount only the visible rows.

  • matchItemMatcher<T>

    How an item matches filter; default the label and keywords.

  • expandedreadonly string[]

    Controlled open branches (ids); leave undefined to let the hook keep its own, seeded by defaultExpanded.

  • defaultExpandedreadonly string[]

    Branches open at the start when uncontrolled.

  • onExpandedChange(ids: string[]) => void

    Called when a branch opens or closes, with the open branch ids.

  • checkboxesboolean

    Whether to draw tri-state checkboxes; the checked value lists leaf ids only.

  • onCheckedChange(leafIds: string[]) => void

    Called when a check changes, with the checked leaf ids.

  • loadChildren(item: T) => Promise<readonly T[]>

    Children of a branch marked hasChildren, fetched when it first opens.

  • loadedLoadedChildren<T>

    The children loadChildren has fetched, by branch id. Leave it out and the tree keeps them itself (lost when it unmounts); pass it with onLoadedChange when a host must keep them across remounts or read the loaded nodes too (TreeSelect does both: its popup tree remounts on every open, and its chips label loaded children).

  • onLoadedChange(loaded: LoadedChildren<T>) => void

    Called when loadChildren has fetched a branch, with every loaded branch so far.

  • onEscape() => void

    Escape on a row (a tree in a popup closes it).

  • canDrop(drop: TreeDropCandidate) => boolean

    The host's rule for a drop (only folders take children, a locked branch takes nothing, …); default every drop the tree rules allow.

  • onMove(items: T[], op: MoveOp) => void

    Every drop: the new tree (the items with the move applied, lazily loaded children included) and the dnd MoveOp. The host owns items and stores it.

  • canHaveChildren(item: T) => boolean

    Which items may hold children; default any item may by dragging right under it, and a branch also takes a drop on its middle.

  • maxDepthnumber

    Deepest level a drop may create (0 = the top level only); default unlimited.

  • springLoadnumber | false

    Default 600

    Dwell in ms before a collapsed branch held under a drag opens, or false for never.

  • activationActivationConstraint

    Default { kind: "distance", distance: 3 }

    The pointer (mouse and pen) activation; touch keeps the dnd kit's long-press so a swipe still scrolls.

  • renamableboolean | ((item: T) => boolean)

    Which rows can be renamed: all, or a predicate; default none.

  • onRename(item: T, label: string) => void | string | Promise<void | string>

    Saves a new name. Return (or resolve to) a string to refuse it with that message; throw or reject for a failure (its message is shown).

  • validateName(item: T, label: string) => string | null

    Refuses a name before onRename runs: return the message, or null when the name is fine.

  • menuItems(item: T) => readonly CollectionNode<MenuItem>[]

    More entries for a row's context menu (Rename, Delete, …), after the tree's own; the menu mounts only while dragging (or renaming) is on, or when this is given.

  • apiRefRef<TreeViewHandle>

    Receives the tree's commands (startRename, focusItem), for a toolbar button or a menu of the host's own.

  • dndProviderPropsPartial<Omit<DndProviderProps<unknown>, "children" | "onMove" | "project" | "selection">>

    The escape hatch for a dragging tree: any other dnd DndProvider option (sensors, auto-scroll, presentation, more plugins, monitor callbacks); the drop rules, onMove, project and selection stay the tree's.

  • separatorstring

    Default "/"

    The path separator paths are split on and paths are joined with.

  • sortFileTreeSort<T>

    Default "folders-first"

    How siblings are ordered: folders first then natural order (Intl.Collator, numeric), as given, or a comparator.

  • onOpenFile(node: T) => void

    Enter or a double-click on a file (TreeView's onAction, for files only).

  • foldersOnlyboolean

    Show the folders only, for a "choose a folder" picker.

  • renderIcon(node: T, state: FileTreeIconState) => ReactNode

    Draws a row's icon instead of the folder or file-kind icon.

  • formatHintnode: T) => string

    The row's hint; default the node's own hint, else its size and date (formatBytes, a medium date). Return undefined for none.

  • caseSensitiveNamesboolean

    Default false

    Whether "Report.pdf" and "report.pdf" are different names when renaming (true on Linux file systems, false on macOS and Windows).

FileNodeIcon

The folder icon (open or closed) or the upload kit's file-kind icon, at row size.

  • noderequiredFileNodeFields & { readonly label: string }

    The node to draw the icon of.

  • expandedrequiredboolean

    Whether the folder is open (ignored for a file).
