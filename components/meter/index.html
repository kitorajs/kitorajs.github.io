Props

Meter

A meter: a scalar inside a known range (disk used, a strength, a battery), role="meter". A bare number reads as a percentage; format and locale (Intl.NumberFormat) make it a unit, a currency or a compact number, and the same text is the aria-valuetext. For progress toward a goal (an upload, a task) use Progress. Meter draws the track and the indicator after the children; compose MeterTrack and MeterIndicator yourself for a different bar.

  • formatIntl.NumberFormatOptions

    Options to format the value (Intl.NumberFormat). Without it the value reads as a percentage of 100.

  • getAriaValueText(formattedValue: string, value: number) => string

    Returns the human-readable text alternative for the current value (aria-valuetext).

  • localeIntl.LocalesArgument

    The locale Intl.NumberFormat formats with. Defaults to the runtime's locale.

Accessibility

  • Meter follows the WAI-ARIA Meter pattern: roles meter.

Design-language slot

slots.progress Progress and Meter (@kitora/ui/progress, @kitora/ui/meter): a track with a filled part.

  • trackSize PxThickness of the track.
  • ends BarEndsRounded or square ends of the track (the bar is clipped to them).
  • track PerScheme<Fill>The unfilled track per scheme.
  • indicator FillThe filled part; it needs 3:1 against the page, since it carries the value.
  • fill ButtonFillThe filled part flat, or with a soft top-lit sheen (macOS).
  • bevel BevelThe track's edge: flat, a faint recess (macOS), or the classic sunken bevel (Retro).
