Props

Table

A styled HTML <table> in a sideways-scrolling wrapper, with an optional compact size and a sticky header.

  • sizekeyof typeof TABLE_SIZE_CLASS

    Default "default"

    Row density.

  • stickyHeaderboolean

    Default false

    Keep the header visible while the rows scroll (the container must scroll vertically).

  • containerClassNamestring

    Classes for the scrolling wrapper around the table.

Plus every <table> prop.

TableHeader

The table's <thead>, its rows ruled underneath.

Plus every <tbody> prop.

TableBody

The table's <tbody>; its last row has no rule.

Plus every <tbody> prop.

TableFooter

The table's <tfoot>, ruled above on a muted fill in medium weight (totals).

Plus every <tbody> prop.

TableHead

A header cell (<th>); a TableSortButton inside sets its aria-sort.

Plus every <th> prop.

TableRow

A <tr>, ruled underneath, filled on hover and while data-state="selected", striped where a design language sets a stripe.

Plus every <tr> prop.

TableCell

A body cell (<td>), padded and on one line.

Plus every <td> prop.

TableCaption

The table's <caption>, under the table in muted text; it names the table.

Plus every HTML prop.

TableSortButton

The header of a sortable column: a button with the column name and an arrow (up ascending, down descending, a muted up-down pair when unsorted). It writes aria-sort on its header cell, the WAI-ARIA sortable-table pattern, so the state is announced with the column and not repeated in the button's name. Sorting the rows stays yours (or the datagrid's); this is the control and its state.

  • directionTableSortDirection

    The column's sort state when the parent owns it (a datagrid, a URL).

  • defaultDirectionTableSortDirection

    Default "none"

    The starting state when the button owns it.

  • onDirectionChange(direction: TableSortDirection) => void

    Called with the next state on press (none → ascending → descending → none).

Plus every <button> prop.

Design-language slot

slots.table Table (@kitora/ui/table): its header row and the rows' rules and fills (the text stays the foreground).

  • headHeight PxThe header row's height.
  • headWeight numberThe header labels' CSS-style weight, 100–900.
  • divider PerScheme<Fill>The rule under each row per scheme (none for no visible rule).
  • hover PerScheme<Fill>A row under the pointer (or with a row inside it expanded) per scheme; none is transparent, so a row's own colour clears under the pointer.
  • selected PerScheme<Fill>A selected row (data-state="selected") per scheme.
  • stripe PerScheme<Fill>Every other body row per scheme (none for no stripes); laid over the row's own fill as an image layer, so a row a caller colours keeps it, and skipped on a selected row.
  • kits KitFollowWhether the kits' own tables (the data grid) take this slot's header height and weight, rules, hover, selection and stripes (slot) or keep their own (kit).
