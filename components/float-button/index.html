FloatButton

A floating action button pinned to a logical viewport corner above the safe area: an Affix holding a Button, in three sizes, round or square, extended with text, as a link, with a count or dot badge and a tooltip. BackToTop is its preset.

Source: @kitora/ui (the primitive the kits compose)

03A link and a badge

href draws a link with the same look; badge a count or a dot with a badgeLabel for screen readers; position any logical corner.

33 unread

04Speed dial

SpeedDial opens actions upward from a FloatButton on a press: Enter, Space or ↑ opens it on the first action, ↑ and ↓ walk them, Escape and Tab close it and focus returns to the trigger. It is a ui DropdownMenu: aria-haspopup="menu", menuitem actions.

Last action: none

05Toward the inline start

direction="start" runs the actions to the left (to the right in right-to-left text) and the inline-start arrow walks them; openIcon replaces the icon while open.

06Labels shown

showLabel draws each action's label beside it; unset, labels show on touch screens and are read everywhere.

07Above a bottom nav

On a phone with the shell's ShellBottomNav, the dial's offset (the bar's 57px plus the usual gap) keeps it above the bar.

Props

FloatButton

A floating action button in a viewport corner: an Affix holding a Button. icon and label (required, the accessible name and tooltip); description makes it extended; variant, shape, size; href makes it a link; badge adds a count or a dot. Takes the Affix placement props and every Button prop.

  • loadingboolean

    Default false

    Busy: aria-busy="true" and data-loading, activation blocked but focus kept (focusable-disabled semantics, so focus is not dropped mid-submit), full opacity. The children stay in place, invisible, so the width does not jump, with a spinner centred over them. Controlled by this prop only.

  • renderUseRenderRenderProp

    The primitives' render prop, an alias of asChild with the element given here instead of as the child: an element (cloned with the button's props) or a function (props) => element. asChild wins when both are given.

  • focusableWhenDisabledboolean

    Default false

    Keep a disabled button in the tab order: aria-disabled="true" instead of disabled, clicks and every key but Tab blocked (the primitive useButton), hover kept so a Tooltip can explain why.

  • nativeButtonboolean

    Whether the rendered element is a native <button>. Only read with focusableWhenDisabled or loading (it decides aria-disabled vs role="button" handling). Defaults to true unless render/asChild gives an element other than <button>.

  • loadingTextReact.ReactNode

    While loading, show the spinner beside this text instead of over the hidden children.

  • offsetnumber

    Default 20

    The distance from the edges in px, before the safe-area insets.

  • positionAffixPosition

    Default "bottom-end"

    The corner, in logical terms (end is the right in left-to-right text).

  • withinPortalboolean

    Default true

    Render at the end of the body (or the portal container) instead of in place.

  • zIndexnumber

    Default 50

    The stacking order.

  • iconReact.ReactNode

    The icon.

  • labelrequiredstring

    The accessible name, and the tooltip unless tooltip={false}. Required: an icon has no text.

  • descriptionReact.ReactNode

    Text beside the icon: an extended floating button, named by this text.

  • tooltipReact.ReactNode

    A styled tooltip showing label (true, the default without description), a node to show instead, or false for none.

  • tooltipSide"top" | "bottom" | "inline-start" | "inline-end"

    Default toward the page: `inline-start` in an end corner, `inline-end` in a start corner (mirrored in right-to-left text)

    The tooltip's side.

  • variant"default" | "outline"

    Default "default"

    default: the brand fill; outline: the surface with a border.

  • shape"circle" | "square"

    Default "circle"

    The outline: a circle, or a square with the button slot's own corner.

  • sizeFloatButtonSize

    Default "default"

    sm 40px, default 48px, lg 56px (xs 32px, BackToTop's).

  • hrefstring

    Draw it as a link to this URL.

  • badgenumber | boolean

    A count, or true for a dot, on the button's top-end corner.

  • badgeLabelstring

    What a screen reader hears for the badge ("3 unread"); without it a count is read as its number and a dot says nothing.

  • affixClassNamestring

    Classes for the Affix around the button (className styles the button).

Plus every <button> prop.

SpeedDial

The dial's root: its open state, controlled (open + onOpenChange) or not (defaultOpen). Holds a SpeedDialTrigger and a SpeedDialContent of SpeedDialActions. Not modal by default: the page stays usable around an open dial.

  • openboolean

    Whether the menu is open (controlled).

  • defaultOpenboolean

    Default false

    Whether it starts open (uncontrolled).

  • onOpenChange(open: boolean, details: MenuChangeEventDetails) => void

    Called when the open state is about to change; details.cancel() refuses it.

  • childrenReact.ReactNode | PayloadChildRenderFunction<Payload>

    The content: nodes, or a function of the payload of the trigger the menu is attached to.

  • modalboolean

    Default false

    true (default): the page scroll is locked and an invisible backdrop blocks the page while open. Ignored on a submenu.

SpeedDialAction

One action: a round 40px menu item with an icon, named by label. onClick runs it; the dial then closes.

  • labelrequiredstring | undefined

    The text typeahead matches. Default: the item's text content. Its name, read always; drawn beside it per showLabel.

  • disabledboolean

    Default false

    Whether the item ignores user interaction.

  • focusableWhenDisabledboolean

    Default true

    Whether a disabled item stays a stop of the menu's keys, typeahead and pointer highlight (Base UI's behaviour); false steps over it.

  • nativeButtonboolean

    Default false

    Whether the rendered element is a native <button>.

  • closeOnClickboolean

    Default true

    Close the menu when the item is activated.

  • iconrequiredReact.ReactNode

    The action's icon.

  • showLabelboolean

    Default only on coarse pointers

    Draw the label beside the action (MUI's tooltipOpen).

Plus render, and className / style as functions of the part's state, and every <div> prop.

SpeedDialContent

The actions: a column or row with no surface, direction up (default), down, start or end from the trigger.

  • containerPortalContainerOption

    Render the popup into this element instead of document.body.

  • stickyboolean

    Default false

    Keep the popup against its anchor's edge while the anchor scrolls away.

  • sideOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 8

    Gap between anchor and popup, px or a function of the placement.

  • positionMethodPositionStrategy

    absolute (default) follows the page while it scrolls; fixed places in the viewport.

  • alignOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 0

    Shift along the anchor's edge.

  • collisionBoundaryCollisionBoundary

    Default "clipping-ancestors"

    What the popup must stay inside.

  • collisionPaddingnumber | Partial<PlacementPadding>

    Default 5

    Space kept from the boundary's edges.

  • arrowPaddingnumber

    Default 5

    Space kept between the arrow and the popup's corners.

  • disableAnchorTrackingboolean

    Default false

    Do not follow the anchor after the first placement.

  • collisionAvoidanceCollisionAvoidance

    Flip, shift or neither, per axis.

  • finalFocusFinalFocusProp

    Where focus goes on close: true (default: the trigger), false, an element ref, or a function.

  • directionSpeedDialDirection

    Default "up"

    The way the actions run from the trigger, logical.

Plus render, and className / style as functions of the part's state, and every <div> prop.
