Drawer

Bottom-sheet style drawer (the primitives Drawer: swipe to dismiss, snap points). Mobile-first.

Source: @kitora/ui (the primitive the kits compose)

01Bottom sheet (mobile-first)

02Indent and background

DrawerProvider, DrawerIndent and DrawerIndentBackground: the page steps back behind any open drawer and follows a swipe (--drawer-swipe-progress).

Your app

Open the drawer: this page steps back behind it and comes forward again as you swipe it away.

03Nested drawers

A drawer opened inside another steps the first one back (--nested-drawers); Escape, a swipe and the Android back gesture close only the top one.

04Swipe area

Drawer.SwipeArea: an edge strip that opens the drawer by a drag, following the finger and opening past half or on a flick.

Drag from the left edge to open the menu.

05Snap points

A bottom sheet that rests at a 160px peek, half the screen or full height, also moved by buttons.

06Handle part and logical sides

Start and end drawers that follow the reading direction, and a bottom drawer that places its own DrawerHandle.

07Feedback sheet

A bottom Drawer holding a Label and Textarea feedback form, with Button submit and cancel.

08Build your own

The same bottom drawer from the primitives' Drawer parts only (the popup follows the finger through --drawer-swipe-movement-y); a rebuild test compares it with ui's.

Props

Drawer

A panel that slides in from an edge and is swiped away, with snap points and nested drawers; Drawer.Root from

  • swipeDirectionSwipeDirection

    Default "down"

    The direction the drawer is dismissed toward: down a bottom sheet, up, left, right.

  • snapToSequentialPointsboolean

    Default false

    With snap points, a swipe moves at most to the adjacent point instead of projecting the fling.

  • snapPointsreadonly SnapPointValue[]

    The heights the drawer settles on (down and up drawers only).

  • snapPointSnapPointValue | null

    The active snap point (controlled). null while closed.

  • defaultSnapPointSnapPointValue | null

    The snap point it opens at (uncontrolled). Default: the first of snapPoints.

  • indentboolean

    Default true

    Kitora extension: whether this drawer, while open, counts for the nearest Drawer.Provider (it indents the page behind). Base UI's drawer always does; a host that draws some drawers as centred dialogs turns it off for them.

  • closeWatcherboolean

    Default true

    Kitora extension: whether this drawer takes the platform's close request (the Android back gesture, window.CloseWatcher; reason close-watcher). Base UI's drawer always does; a host that routes Back itself turns it off, and back then does what it did without a drawer.

  • onSnapPointChange(snapPoint: SnapPointValue | null, details: SnapPointChangeDetails) => void

    Called when a swipe (or the drawer closing) changes the snap point. Call details.cancel() to refuse.

  • openboolean

    Whether the dialog is open (controlled).

  • defaultOpenboolean

    Default false

    Whether the dialog starts open (uncontrolled).

  • modalModalMode

    true (default): focus is trapped, the page scroll is locked, everything outside is inert. false: the page stays usable and moving focus out dismisses. "trap-focus": focus is trapped but the page stays scrollable and clickable.

  • onOpenChange(open: boolean, details: DialogRootChangeEventDetails) => void

    Called when the dialog asks to open or close. Call details.cancel() to refuse.

  • onOpenChangeComplete(open: boolean) => void

    Called after the enter animation finished (true) or the exit animation finished and the popup unmounted (false).

  • disablePointerDismissalboolean

    Default false

    An outside press (and focus leaving a non-modal dialog) does not dismiss. Escape still does.

  • layerIdstring

    Kitora extension: adopt this layer of the dismiss-layer model instead of registering a new one. An overlay entry's id, so the entry and its surface are ONE layer and the stack stays the owner of which gesture goes where. A layer the model does not hold yet is added as usual.

  • keepInteractivestring

    Kitora extension: a CSS selector for regions that stay interactive while a modal is open, on top of live regions ([aria-live]): a persistent toast region, a host's chat widget. Everything else outside is inert.

  • triggerIdstring | null

    ID of the trigger the dialog is attached to: with a controlled open, which of several triggers it opens from.

  • defaultTriggerIdstring | null

    ID of the trigger the dialog is attached to when it starts open (defaultOpen).

  • actionsRefReact.RefObject<DialogRootActions | null>

    A ref to imperative actions: close(), and unmount() for a popup kept mounted with details.preventUnmountOnClose().

  • handleDialogHandle<Payload>

    A handle that lets triggers outside this Root open it (Dialog.createHandle()).

  • childrenReact.ReactNode | PayloadChildRenderFunction<Payload>

    The content: nodes, or a function of the payload of the trigger the dialog is attached to.

  • side"start" | "end"

    A side drawer on the reading direction's start or end edge; an explicit swipeDirection wins over it.

DrawerPortal

Moves the drawer's backdrop and panel to the end of the document (or into container).

  • keepMountedboolean

    Default false

    Render the popup even while the dialog is closed (hidden).

  • containerPortalContainerOption

    Where to render: an element, a shadow root, or a function that returns one. Default document.body.

  • childrenReact.ReactNode

    The popup, viewport and backdrop to move.

  • idstring

    An id for the portal node.

  • classNamestring

    A class for the portal node.

DrawerOverlay

The dimmed backdrop behind the drawer, fading in and out.

  • forceRenderboolean

    Default false

    Render the backdrop of a nested drawer too.

Plus render, and className / style as functions of the part's state, and every <div> prop.

DrawerTrigger

The control that opens the drawer.

  • disabledboolean

    Default false

    Whether the trigger does nothing.

  • nativeButtonboolean

    Default true

    Set to false when render is not a native <button>: the part then supplies role, tab stop and Enter / Space.

  • handleDialogHandle<Payload>

    A handle that associates this trigger with a dialog Root elsewhere in the tree (Dialog.createHandle()).

  • payloadPayload

    What the dialog's content receives (children of the Root as a function) while it is attached to this trigger.

  • asChildboolean

    Render the child element as the trigger instead of a button (the other triggers take it too).

Plus render, and className / style as functions of the part's state, and every <button> prop.

DrawerClose

A control that closes the drawer.

  • disabledboolean

    Default false

    Whether the button does nothing.

  • nativeButtonboolean

    Default true

    Set to false when render is not a native <button>.

  • asChildboolean

    Render the child element as the close control instead of a button.

Plus render, and className / style as functions of the part's state, and every <button> prop.

DrawerContent

The drawer's panel, portalled over a backdrop, placed and animated by its swipe direction, with a grab bar on a bottom drawer.

  • initialFocusInitialFocusProp

    What to focus when the dialog opens: false nothing; true the first tab stop; an element (a ref); or a function of how it was opened that returns an element, true for the default, or false for nothing. Default: the popup itself when opened by touch (no on-screen keyboard), else the first tab stop.

  • finalFocusFinalFocusProp

    Where focus goes when the dialog closes: false nowhere; an element (a ref); or a function of how it closed that returns an element, true for the default, or false for nothing. Default: the element that had focus when it opened, else the trigger.

  • containerPortalContainerOption

    Where to render: an element, a shadow root, or a function that returns one. Default document.body.

  • handleboolean

    Default true

    Draw the grab bar at the top of a bottom drawer.

Plus render, and className / style as functions of the part's state, and every <div> prop.

DrawerHandle

The grab bar of a bottom drawer (a drawer swiped down to close; on other sides it is hidden, and a theme hides it with --dk-drawer-handle). DrawerContent draws one first unless handle={false}; render this yourself to place or restyle it.

Plus every <div> prop.

DrawerProvider

Shares which drawers are open with DrawerIndent and DrawerIndentBackground. Renders no element.

  • storeDrawerProviderStore

    A store the host created (createDrawerProviderStore()), to drive or read the same state outside React. Default: one the provider makes.

  • childrenReact.ReactNode

    The app, including the Drawer.Indent parts and drawers that share the state.

DrawerIndent

Wrap the page in this: it scales back and rounds while a drawer is open, in step with a swipe.

Plus render, and className / style as functions of the part's state, and every <div> prop.

DrawerIndentBackground

A layer placed before DrawerIndent inside the same relative wrapper: the colour that shows around the scaled page.

Plus render, and className / style as functions of the part's state, and every <div> prop.

DrawerSwipeArea

An invisible strip along the edge a drawer comes from: swiping it opens the drawer. Put it inside Drawer, before DrawerContent.

  • disabledboolean

    Default false

    Whether the swipe area does nothing.

  • swipeDirectionSwipeDirection

    The direction the swipe travels to open the drawer. Default: the opposite of the drawer's swipeDirection (a bottom drawer opens by swiping up).

Plus render, and className / style as functions of the part's state, and every <div> prop.

DrawerHeader

The top of the drawer's panel: the title and description, centred on a top or bottom drawer.

Plus every <div> prop.

DrawerFooter

The bottom of the drawer's panel, pushed to the end, holding its actions.

Plus every <div> prop.

DrawerTitle

The drawer's heading; names the drawer for assistive tech.

Plus render, and className / style as functions of the part's state, and every <h2> prop.

DrawerDescription

The drawer's supporting text; describes the drawer for assistive tech.

Plus render, and className / style as functions of the part's state, and every <p> prop.

Keyboard

  • EnterSpaceDrawer.TriggerOpens the drawer and moves focus into it.
  • EscapeDrawer.ViewportCloses the drawer (the top-most one, when drawers are nested) and returns focus to the trigger.
  • EnterSpaceDrawer.CloseCloses the drawer.

Accessibility

  • Drawer follows the WAI-ARIA Dialog (Modal) pattern: roles dialog.

Design-language slot

slots.drawer Drawer (@kitora/ui/drawer): a panel swiped in from an edge, rounded on the edge that faces the page.

  • corner CornerThe corners on the edge that faces the page (the top of a bottom drawer).
  • surface SurfaceThe panel's surface: opaque or translucent.
  • blur PxBlur radius behind a translucent surface; ignored when surface is solid.
  • elevation ElevationHow much the panel lifts off the page.
  • backdrop numberHow dark the backdrop behind it is, 0–1 (black at this opacity).
  • handle FillThe grab handle at the top of a bottom drawer (none hides it); decoration, so it needs no contrast minimum.
