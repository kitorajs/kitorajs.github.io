03Jump to page and page size

showJumpToPage adds a labelled "Go to page" box (digits only; Enter or Go jumps, clamped to the last page, then clears; Escape clears; no inner <form>). pageSizeOptions with onPageSizeChange adds PaginationPageSize, a ui Select named by its label, with Infinity as "All". On a phone both wrap under the chips.

Props

Pagination

The pager's landmark: a centred <nav aria-label="pagination"> around PaginationContent.

Plus every HTML prop.

PaginationContent

The row of chips: a <ul> that goes in Pagination and holds PaginationItems.

Plus every <ul> prop.

PaginationControl

A complete pager: previous, the page chips with ellipses, next (and optionally first / last), built from the parts above on usePagination. Controlled (page + onPageChange) or not (defaultPage).

  • totalPagesrequirednumber

    How many pages exist; Infinity when unknown (next stays enabled, no last chip).

  • pagenumber

    The current page (1-based) when the parent owns it.

  • defaultPagenumber

    Default 1

    The starting page when the control owns it.

  • onPageChange(page: number, details: PaginationChangeEventDetails) => void

    Called with the new page; details.cancel() keeps the current one.

  • siblingCountnumber

    Default 1

    Pages either side of the current one.

  • boundaryCountnumber

    Default 1

    Pages always shown at each end.

  • showFirstLastboolean

    Default false

    Show the first / last chips.

  • showPreviousNextboolean

    Default true

    Show the previous / next chips.

  • disabledboolean

    Default false

    Whether every chip is disabled.

  • getPageHref(page: number) => string

    A URL per page: the chips become links (a router can intercept the click). Without it they are <button type="button">s over client state.

  • labelsPartial<PaginationLabels>

    Strings for localisation; any key left out keeps its English default.

  • showJumpToPageboolean

    Default false

    Add a "Go to page" input after the chips (PaginationJumpToPage); a jump reports onPageChange with the reason jump.

  • pageSizenumber

    The page size when the parent owns it. Giving this, defaultPageSize, pageSizeOptions or onPageSizeChange shows PaginationPageSize.

  • defaultPageSizenumber

    The starting page size when the control owns it.

  • pageSizeOptionsreadonly number[]

    Default [10, 20, 50, 100]

    The page sizes offered (Infinity shows as labels.all).

  • onPageSizeChange(size: number) => void

    Called once per pick with the new page size; the parent recomputes totalPages (and the page) from it.

Plus every HTML prop.

PaginationEllipsis

The gap between page runs: a "…" icon, hidden from screen readers, with label as screen-reader text.

  • labelstring

    Default "More pages"

    The screen-reader text for the hidden pages.

Plus every <span> prop.

PaginationFirst

Jump to the first page: an icon chip (double chevron, mirrored in right-to-left text).

  • isActiveboolean

    Whether this chip is the current page: drawn outlined and marked aria-current="page".

  • disabledboolean

    Default false

    Unavailable (the previous chip on page 1): aria-disabled="true" and data-disabled, faded, clicks and Enter swallowed. Focus is kept, so a keyboard user still hears that the edge exists; a link keeps its href.

  • renderReact.ReactElement<Record<string, unknown>>

    The element to draw instead of an <a>: <button type="button" /> for a pager over client state (no URL per page). Its own props are kept; the link's props merge onto it.

  • size"default" | "xs" | "sm" | "lg" | "xl" | "icon" | "icon-xs" | "icon-sm" | "icon-lg" | null

    Default "default"

    The height and padding; the icon-* sizes make a square button for a lone icon.

Plus every <a> prop.

PaginationItem

One slot in PaginationContent: an <li> around a link, a chip or an ellipsis.

Plus every <li> prop.

PaginationJumpToPage

"Go to page __": a labelled numeric text box (digits only). Enter or Go commits the typed page, clamped to 1…totalPages, then clears it; Escape clears the draft. It renders no <form> (so it sits inside a host form without nesting one; Enter never submits the host form), and its id is generated, so two pagers on a page never collide.

  • totalPagesnumber

    Default Infinity

    How many pages exist; a typed page is clamped to 1…totalPages (no upper bound for Infinity).

  • pagenumber

    The current page, shown as the input's placeholder.

  • onJumprequired(page: number) => void

    Called with the clamped page when Enter or Go commits a typed number.

  • labelReact.ReactNode

    Default "Go to page"

    The visible label, linked to the input.

  • goLabelstring

    Default "Go"

    The Go button's text.

  • showGoButtonboolean

    Default true

    Show the Go button (Enter commits either way).

  • disabledboolean

    Default false

    Whether the input and the Go button are disabled.

Plus every <div> prop.

PaginationPageSize

Rows per page: a ui Select (listbox semantics: arrows, typeahead, Enter, Escape) named by its visible label; Infinity shows as "All".

  • valuenumber

    The page size when the parent owns it (Infinity for every row on one page).

  • defaultValuenumber

    Default the first option

    The starting page size when the control owns it.

  • onValueChange(size: number) => void

    Called once per pick with the new size.

  • optionsreadonly number[]

    Default [10, 20, 50, 100]

    The sizes offered.

  • labelReact.ReactNode

    Default "Per page"

    The visible label; it names the select.

  • allLabelstring

    Default "All"

    The text of the Infinity option.

  • disabledboolean

    Whether the select is disabled.

Plus every <div> prop.

Hooks and functions

  • DEFAULT_PAGINATION_LABELS

    The English strings PaginationControl, PaginationJumpToPage and PaginationPageSize use for any label left out.

  • usePaginationJump({ totalPages, onJump, disabled }: { totalPages?: number; onJump: (page: number) => void; disabled?: boolean; }) => PaginationJump

    The behaviour of "Go to page __" for a box of your own: digits only, Enter or commit jumps to the typed page clamped to 1…totalPages and clears it (Enter never submits a host form), Escape clears a draft and stops there (with nothing typed it reaches the host, so a dialog closes). PaginationJumpToPage runs on it.
