Props

FilterBar

The row of applied filter chips above a list, with keyboard removal, an add menu, Clear all, a trailing slot and a polite count announcement.

  • filtersrequiredFilterChip[]

    The applied filters, one chip each.

  • onRemoverequired(id: string) => void

    Called with a chip's id when its remove button is pressed or Delete / Backspace is pressed on it.

  • onClear() => void

    Called when Clear all is pressed; without it there is no Clear all button.

  • available{ id: string; label: string }[]

    Available filter types to add.

  • onAdd(id: string) => void

    Called with a filter type's id when it is picked from the add menu; the add menu shows only with both available and this.

  • onEdit(id: string) => void

    Makes each chip's text a button that calls this with the chip's id (open a value editor).

  • renderChip(chip: FilterChip, helpers: FilterChipRenderHelpers) => React.ReactNode

    Draws a chip yourself. Delete / Backspace inside it still removes it; call helpers.remove from your own remove control.

  • trailingReact.ReactNode

    Content pushed to the bar's end (a sort control, a result count).

  • labelsPartial<FilterBarLabels>

    Override any of the bar's strings (see FilterBarLabels).

Plus every <div> prop.

Hooks and functions

  • FILTER_BAR_LABELS

    The bar's English strings, the defaults labels overrides.
