TransferList

Pick a subset by moving items between two lists, with search, select-all and counts per side, keyboard multi-select and virtual rows for long lists. The collections kit's TransferList.

Source: @kitora/collections (the single implementation; no other package ships one)

  • TransferList

Props

TransferList<T extends DisplayItem<T> = Entry>

See the file header.

  • itemsrequiredreadonly T[]

    Every item, flat, in the order the available side lists them.

  • valuereadonly string[]

    Controlled chosen ids (the target side, in its order); leave undefined to let the list keep its own, seeded by defaultValue.

  • defaultValuereadonly string[]

    Default []

    Chosen ids at the start when uncontrolled.

  • onChange(ids: string[]) => void

    Called when items move between the sides, with the chosen ids in order.

  • searchableboolean

    Default false

    Whether each side has a search box.

  • matchItemMatcher<T>

    Default defaultMatch

    How the search matches an item; the default wants every token in the label or keywords.

  • heightnumber

    Height of each list in px. Default 10 rows.

  • virtualboolean | "auto"

    Default "auto"

    Whether to mount only the visible rows: always, never, or past TRANSFER_VIRTUAL_THRESHOLD items ("auto").

  • disabledboolean

    Default false

    Whether the whole control is read-only.

  • namestring

    Posts the chosen ids with a surrounding <form>, one entry per id in the chosen list's order; inside a Field the Field's name wins.

  • formstring

    The form the value posts into (a control outside the <form> element).

  • requiredboolean

    Whether a surrounding <form> refuses to submit while nothing is chosen; focus moves to the lists.

  • idstring

    The id of the control's group (a Field's label names it).

  • renderItem(item: T, state: ItemState) => ReactNode

    Draws an item's content instead of its label, icon and description.

  • messagesPartial<TransferListMessages>

    Single-key overrides of the collections-transfer catalog (an I18nProvider translates the rest).

  • classNamestring

    Class names for the outer row, after classNames.root.

  • classNamesTransferListClassNames

    Default {}

    Class names for the parts, by name.

Hooks and functions

  • TRANSFER_SIDES

    The two sides: source (available, inline-start) and target (chosen, inline-end).

  • TRANSFER_VIRTUAL_THRESHOLD

    A side switches to the virtual window past this many items (when virtual is "auto").
