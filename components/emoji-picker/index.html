EmojiPicker

Pick an emoji from a popover or an inline panel: names for screen readers, search, categories, recently used, skin tones, and a value mode that posts with a form. The pickers kit's EmojiPicker.

Source: @kitora/pickers (the single implementation; no other package ships one)

Props

EmojiPicker

The emoji picker preset plus its parts for composing your own (see the file header).

  • triggerReactNode

    The content of the button that opens the picker; defaults to a smiley icon (or, in value mode, the chosen emoji).

  • labelstring

    The trigger's and the popover's accessible name; default the catalog's "Add reaction".

  • valuestring | null

    Value mode ("pick an icon for this project"): the chosen emoji, controlled (null = none). The trigger shows it and the grid marks it pressed. Value mode is on when any of value, defaultValue, onChange, name or required is set.

  • defaultValuestring | null

    Value mode: the initial emoji when uncontrolled (null = none).

  • onChange(emoji: string) => void

    Value mode: called with the chosen glyph (toned, when a skin tone is set).

  • namestring

    Value mode: posts the chosen glyph with a surrounding <form>; inside a Field the Field's name wins.

  • formstring

    The form the value posts into (a picker outside the <form> element).

  • requiredboolean

    Value mode: a surrounding <form> refuses to submit while nothing is chosen; focus moves to the trigger.

  • disabledboolean

    Whether the trigger is disabled (a disabled picker posts nothing).

  • invalidboolean

    Force the invalid look (a Field's error sets it too).

  • idstring

    The trigger's id (a <label htmlFor> names it; inside a Field the Field's label does).

  • openboolean

    Controlled popover state.

  • defaultOpenboolean

    Default false

    Whether the popover starts open when uncontrolled.

  • onOpenChange(open: boolean) => void

    Called when the popover opens or closes, with the new state.

  • sidePopoverSide

    Default "top"

    Which side of the trigger the popover opens on.

  • alignPopoverAlign

    Default "end"

    How the popover lines up with the trigger.

  • closeOnPickboolean

    Default true

    Close the popover when an emoji is picked.

  • columnsnumber

    Default 8

    Emoji per row of the grid.

  • recentreadonly string[]

    The recently used emoji (glyphs, newest first), shown as a first "Recently used" category; the host keeps the list (state, storage) and passes it back. Leave undefined for no recents.

  • skinTonenumber

    Controlled skin tone, 0 (default) to 5 (dark): every item with skins shows and is picked in it.

  • onPick(emoji: string, details: EmojiPickDetails) => void

    Called when an emoji is picked, with its glyph and the item.

  • emojisEmojiSource

    Default DEFAULT_EMOJI_ITEMS

    The emoji offered: a flat list of glyphs or items (one unnamed category), or categories (EmojiData). A bare glyph of the default set takes its English name.

  • itemLabel(item: EmojiItem) => string

    Each emoji button's accessible name; default the item's name ("thumbs up"). The chat kit passes React ${emoji}.

  • onRecentChange(recent: readonly string[]) => void

    Called after a pick with the new recent list: the picked glyph first, any other tone of it dropped, cut to recentLimit.

  • recentLimitnumber

    Default 16

    How many recently used emoji the list keeps.

  • defaultSkinTonenumber

    Default 0

    Initial skin tone when uncontrolled.

  • onSkinToneChange(skin: number) => void

    Called when the skin tone changes, with the new tone.

  • searchboolean

    Show the search box; default on for more than one category or more than 24 emoji.

  • previewboolean

    Show the preview footer; default on for more than one category or more than 24 emoji.

Hooks and functions

  • useEmojiPickerContext() => EmojiPickerContextValue

    The nearest EmojiPicker.Root's state; throws outside one so a misplaced part fails loudly.

Features

  • DP84 Emoji model: `EmojiItem` (glyph, name, keywords, skins) and `EmojiData` (named categories); a flat list of glyphs or items is one unnamed category; `DEFAULT_EMOJI_ITEMS` names the default 24; no emoji data set is bundled (the `EmojiData` docs map a full set) (pickers, live)
  • DP85 Each emoji button is named by `itemLabel(item)`, by default the emoji's name ("thumbs up"); 32 px cells (pickers, live)
  • DP86 Search by name and keyword, case-insensitive and prefix first (the collections kit's `rankItems`): focused when the popover opens, ArrowDown enters the grid, Enter picks the first result, a search that finds nothing is shown and announced (pickers, live)
  • DP87 Categories: one section per category, a group named by its heading; a roving category bar that scrolls to a section and focuses its first emoji; PageUp / PageDown by category, Up / Down across sections (pickers, live)
  • DP88 A preview of the hovered or focused emoji and its name; search, category bar and preview appear by default only for more than one category or more than 24 emoji (pickers, live)
  • DP89 Recently used emoji: the host keeps the list (`recent`, `onRecentChange`, `recentLimit`, default 16), shown as a first "Recently used" category with a clock in the category bar; a pick moves its glyph to the front, drops any other tone of it and cuts the list; no `recent` prop, no recents (pickers, live)
  • DP90 Skin tones: a radio group of six (one tab stop, arrows check), shown only when some emoji has `skins`; the tone applies to every emoji with skins in the grid and the preview, and `onPick` receives the toned glyph and the tone (`skinTone` / `defaultSkinTone` / `onSkinToneChange`) (pickers, live)
  • DP91 `EmojiPicker` value mode ("pick an icon for this project"): `value` / `defaultValue` / `onChange`, the trigger shows the chosen emoji and is named by it, the grid marks it pressed; `name` posts the glyph with a plain `<form>`, `form`, `required` (refuses an empty submit, focus to the trigger), `disabled`, and inside a ui `Field` the label, description, error, name and disabled reach the trigger (`ColorPickerPopover`'s form-binding pattern) (pickers, live)
  • DP92 `EmojiPicker.Panel`: the picker inline, without a popover, with search, categories, preview, skin tones and recents as the data calls for (pickers, live)
