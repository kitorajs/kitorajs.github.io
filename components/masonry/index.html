The display kit's Masonry.

03Packed and sequential

The trade-off: packed (the default) keeps the columns even and the visual order close to the source order; sequential puts item i in column i % columns, so it reads row by row exactly but the columns end ragged. Tab and a screen reader follow the source order in both, because the DOM is never reordered (no CSS columns, no wrapper per column).

Props

Masonry

Items of mixed heights in columns, with the DOM, Tab order and screen-reader order kept in source order. Columns come from a count, a responsive map or a minimum width; first paint is a plain grid of defaultColumns, then items are measured and packed.

  • columnsnumber | MasonryColumnsMap

    Default 3

    Columns: a fixed count, or a responsive map such as { base: 1, sm: 2, lg: 4 } whose breakpoints are the viewport's width, as Tailwind's sm: / lg: are (640, 768, 1024, 1280, 1536). For columns that follow the Masonry's own width (a side panel), use minColumnWidth.

  • minColumnWidthnumber

    As many columns as fit in the Masonry's own width at this width or wider (pixels), like a container query; used instead of columns when given.

  • gapMasonryGap

    Default 12

    Gap between items in pixels, or { x, y }.

  • sequentialboolean

    Default false

    false: each next item goes into the shortest column (columns end close together, the visual order stays close to the source order). true: item i goes into column i % columns, so the visual order matches the source order row by row exactly, with ragged column ends.

  • defaultColumnsnumber

    Columns for the server render and the first paint, before anything is measured; default columns (a map's base), else 1.

  • as"div" | "ul"

    Default "div"

    ul gives list semantics (each item becomes an li, named by label); div is a plain container.

  • labelstring

    The accessible name of the list (aria-label), for as="ul".

  • animateboolean

    Default false

    Ease items to their new place when the layout changes. Off by default, and never under reduced motion.

  • onLayoutChange(columns: number) => void

    Called with the column count whenever it changes (also once on the first measurement).

  • childrenReactNode

    The items: MasonryItems, or any elements (each is wrapped in one).

Plus every HTML prop.

MasonryItem

One item of a Masonry: an li inside as="ul", else a div. Its place is set by the Masonry; style its content freely.

  • childrenReactNode

    The item's content: a card, an image, anything of its own height.

Plus every HTML prop.
