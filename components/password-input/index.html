Props

PasswordInput

A password input with a show / hide toggle, optional Caps Lock warning and optional strength meter: the preset composed from PasswordInputRoot, PasswordInputInput, PasswordInputToggle, PasswordInputCapsLockHint and PasswordInputStrength (compose them yourself to rearrange or restyle a part). The single implementation for every kit: the reveal state is controlled (revealed + onRevealedChange) or uncontrolled (defaultRevealed), and the value is controlled (value + onChange) or uncontrolled (defaultValue). className and ref go to the input. Root and parts carry data-slot, and the root data-revealed / data-caps-lock, for host styling.

  • sizeInputSize | number

    Opt-in height (data-size): "sm", "default" or "lg". Unset keeps today's markup. A number is still the native size attribute (width in characters), so hosts that spread <input> props into Input keep type-checking and working.

  • labelsPartial<PasswordInputLabels>

    Translations of the toggle's names (default {@link PASSWORD_INPUT_LABELS}).

  • wrapperClassNamestring

    Classes for the positioning box around the input and its end adornments (the toggle).

  • showStrengthboolean

    Shows a four-segment strength meter and label under the input once it has a value.

  • revealedboolean

    Whether the password is shown as text. Set it to control the reveal state; leave it unset for an uncontrolled toggle.

  • defaultRevealedboolean

    Default false

    The starting reveal state when uncontrolled.

  • onRevealedChange(revealed: boolean) => void

    Told the new reveal state whenever the toggle is pressed (controlled or not).

  • capsLockHintboolean

    Default false

    Shows a warning under the input while Caps Lock is on (read from the key events, so it appears once the user types). Off so existing forms render unchanged.

  • capsLockLabelReact.ReactNode

    Default "Caps Lock is on"

    The Caps Lock warning text ({@link CAPS_LOCK_LABEL}).

  • renderToggleIcon(revealed: boolean) => React.ReactNode

    Replaces the eye icon; told whether the password is shown.

  • scorePasswordPasswordScorer

    The strength scorer (default {@link scorePasswordStrength}).

  • strengthLabelsreadonly string[]

    Words per strength score, index = score (default {@link PASSWORD_STRENGTH_LABELS}).

Plus every <input> prop.

PasswordInputCapsLockHint

A warning shown while Caps Lock is on (read from the input's key events, so it appears once the user types); announced with the input. Children default to {@link CAPS_LOCK_LABEL}.

Plus every <p> prop.

PasswordInputInput

The input, masked unless revealed, inside a positioning box whose children (the toggle) sit at the inline end. The value is controlled (value + onChange) or uncontrolled (defaultValue, the input keeps its own text); either way the root learns the text for the meter. Its aria-describedby joins a surrounding Field's messages, the caller's own ids and the mounted Caps Lock hint and strength text.

  • wrapperClassNamestring

    Classes for the positioning box around the input and its end adornments (the toggle).

  • sizeInputSize | number

    Opt-in height (data-size): "sm", "default" or "lg". Unset keeps today's markup. A number is still the native size attribute (width in characters), so hosts that spread <input> props into Input keep type-checking and working.

Plus every <input> prop.

PasswordInputRoot

The state holder and outer box of a password field: the reveal state (controlled or not), the Caps Lock state read from the input's key events, the text the meter scores and the ids the input is described by. Writes data-revealed and data-caps-lock for host styling.

  • revealedboolean

    Whether the password is shown as text. Set it to control the reveal state; leave it unset for an uncontrolled toggle.

  • defaultRevealedboolean

    Default false

    The starting reveal state when uncontrolled.

  • onRevealedChange(revealed: boolean) => void

    Told the new reveal state whenever the toggle is pressed (controlled or not).

Plus every <div> prop.

PasswordInputToggle

The show / hide toggle: a toggle button (aria-pressed) named for what a press does, placed at the input's inline end.

  • labelsPartial<PasswordInputLabels>

    Translations of the names (default {@link PASSWORD_INPUT_LABELS}).

  • renderIcon(revealed: boolean) => React.ReactNode

    Replaces the eye icon; told whether the password is shown.

Plus every <button> prop.

PasswordInputStrength

Four segments and the strength words, shown once the field has text. The segments are decoration (aria-hidden); the words are a polite live region and part of the input's description, so a screen reader hears the strength as it changes.

  • scorePasswordPasswordScorer

    Default scorePasswordStrength

    The scorer: a function from the password to a score and label.

  • strengthLabelsreadonly string[]

    Words per score, index = score; win over the scorer's own label. Default {@link PASSWORD_STRENGTH_LABELS}.

Plus every <div> prop.

Hooks and functions

  • scorePasswordStrength(pw: string) => PasswordStrength

    The default scorer: a length and character-variety heuristic (8 and 12 characters, mixed case, a digit, a symbol), enough for a hint under a sign-up field. It is not a policy; a real policy or a dictionary check plugs in through scorePassword.

  • PASSWORD_STRENGTH_LABELS

    The default words per score, index = score. Pass strengthLabels to translate them.

  • CAPS_LOCK_LABEL

    The default Caps Lock warning; pass capsLockLabel to translate it.

  • PASSWORD_INPUT_LABELS

    The reveal toggle's default names (it is a toggle button, so the name says what a press does). Pass labels to translate them.
