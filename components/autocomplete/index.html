Autocomplete

An input whose text is the value, with suggestions under it. Filter as you type, complete inline as you arrow, or both; groups, async suggestions, a search box that submits its form.

Source: @kitora/ui (the primitive the kits compose)

01Default

The text is the value: suggestions filter as you type, ↓ highlights one, Enter puts it in the input, Escape closes the list and again clears the text. A press on the input does not open it; typing does.

02Inline completion

mode="inline" lists every suggestion and writes the highlighted one into the input as you arrow; arrowing past the end gives your own text back.

03Filtered and inline

mode="both" filters by what you typed and also writes the highlighted suggestion into the input as you arrow; Enter keeps it.

04Groups

Suggestions in groups, with AutocompleteGroup, AutocompleteLabel and AutocompleteCollection; a group with no match leaves the list.

05Async suggestions

Suggestions fetched as you type: filter={null} turns the root's own filter off and AutocompleteStatus says "Searching…" while the request is out. The fake fetch is a timer that gives up when the text changes.

06Search box in a form

submitOnItemClick submits the owning form when a suggestion is pressed (Enter with nothing highlighted submits it too); name puts the text in the form data.

Props

Autocomplete<ItemValue>

An autocomplete root: the text, the open state, the suggestions. Renders no element.

  • modeAutocompleteMode

    Default "list"

    How the list and the text relate: list (filtered), both (filtered, inline completion), inline (all items, inline completion), none.

  • valuestring

    The text (controlled).

  • defaultValuestring

    The text at first (uncontrolled).

  • onValueChange(value: string, eventDetails: AutocompleteRootChangeEventDetails) => void

    Called when the text changes, with why.

  • itemToStringValue(itemValue: ItemValue) => string

    For object values: the text the input shows when an item is chosen (and a form submits). A { value, label } object needs none.

  • openOnInputClickboolean

    Default false

    Whether the popup opens when the input is pressed.

  • openboolean

    Whether the popup is open (controlled).

  • defaultOpenboolean

    Default false

    Whether the popup is initially open (uncontrolled).

  • onOpenChange(open: boolean, eventDetails: ComboboxChangeEventDetails) => void

    Called when the popup opens or closes, with why.

  • childrenReact.ReactNode

    The combobox's parts: Combobox.Input, Combobox.Portal and the rest.

  • idstring

    The id of the component (its input, or its trigger when the input is inside the popup).

  • formstring

    Identifies the form that owns the hidden input; useful when the combobox is rendered outside the form.

  • filternull | ListboxItemFilter<Value>

    Matches an item against the query; null lists every item. Default: contains under Intl.Collator.

  • disabledboolean

    Default false

    Whether the component should ignore user interaction.

  • namestring

    Identifies the field when a form is submitted.

  • readOnlyboolean

    Default false

    Whether the user should be unable to choose a different option from the popup.

  • requiredboolean

    Default false

    Whether the user must choose a value before submitting a form.

  • gridboolean

    Default false

    Whether the items are laid out as a grid (Combobox.Row rows).

  • itemsreadonly any[] | readonly ListboxGroup[]

    The items: a flat array or an array of groups ({ value, items }). With them the root filters, limits and labels the values itself.

  • virtualizedboolean

    Default false

    The items are virtualized by you: give each Combobox.Item its index.

  • inlineboolean

    Default false

    The list is rendered where you put it, with no popup.

  • limitnumber

    Default -1

    The most items listed (-1: no limit).

  • modalboolean

    Default false

    true: the page is blocked and its scroll locked while the popup is open.

  • localeIntl.LocalesArgument

    The locale of the string comparison. Default: the runtime's.

  • loopFocusboolean

    Default true

    Whether the arrow keys loop through the list and back to the input (APG: the input is part of the loop).

  • inputRefReact.Ref<HTMLInputElement>

    A ref to the hidden input element.

  • onOpenChangeComplete(open: boolean) => void

    Called after any animations complete when the popup opens or closes.

  • highlightItemOnHoverboolean

    Default true

    Whether moving the pointer over items highlights them. Off, CSS :hover and the keyboard highlight (data-highlighted) can differ.

  • actionsRefReact.RefObject<ComboboxRootActions | null>

    Imperative actions: unmount() (the popup then stays mounted after closing until it is called) and close().

  • autoHighlightboolean | "always"

    Default false

    Whether the first matching item is highlighted: true after the user types (kept while the query changes), "always" as soon as the list opens.

  • keepHighlightboolean

    Default false

    Whether the highlight stays when the pointer leaves the list.

  • homeEndKeysboolean

    Default false

    Whether Home and End on the input move the highlight to the first and the last item instead of the caret (a command menu, where the list is the point and the text is a filter). Only while the list is showing.

  • highlightedValueValue | null

    The value of the item to highlight (controlled from outside; onItemHighlighted reports every change the user makes). The highlight moves to the item whose value equals it whenever this prop or the listed items change; undefined leaves the highlight to the user. A value no listed item has is ignored.

  • onItemHighlighted(itemValue: Value | undefined, eventDetails: ComboboxHighlightEventDetails) => void

    Called when an item is highlighted or unhighlighted (undefined for none) with why (keyboard, pointer, none for code) and its index.

  • filteredItemsreadonly any[] | readonly ListboxGroup[]

    The items to list, filtered by you (see useFilter); the root then does not filter items.

  • submitOnItemClickboolean

    Default false

    Whether choosing an item submits the owning form.

AutocompleteCollection

Renders the filtered suggestions of a group (or of the list): give it a function of a suggestion. Renders no element.

  • childrenrequired(item: any, index: number) => React.ReactNode

    Renders one item: a function of the item and its index.

AutocompleteContent

The popup: portal, positioner and popup, as wide as the input group it is anchored to. Put an AutocompleteList in it.

  • initialFocusInitialFocusProp

    Where focus goes on open when the input is in the popup: true (default: the input), false, an element ref, or a function. Ignored while the input is beside the popup (it keeps focus).

  • finalFocusFinalFocusProp

    Where focus goes on close when the input is in the popup: true (default: the trigger), false, an element ref, or a function.

  • anchorPositionerAnchor

    What to place against instead of the trigger: an element, a virtual anchor (a point), a ref, or a function returning one.

  • sideAnchoredSideRequest

    Default "bottom"

    Which side of the anchor the popup sits on; inline-start / inline-end follow the text direction.

  • alignAnchoredAlign

    Default "start"

    Alignment along that side.

  • sideOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 4

    Gap between anchor and popup, px or a function of the placement.

  • alignOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 0

    Shift along the anchor's edge.

  • containerPortalContainerOption

    Render the popup into this element instead of document.body.

  • backdropboolean

    Default false

    Draw an overlay behind the popup.

Plus render, and className / style as functions of the part's state, and every <div> prop.

AutocompleteEmpty

Its children show only while no suggestion matches (a live region that is always in the document, so the text is announced when it appears).

Plus render, and className / style as functions of the part's state, and every <div> prop.

AutocompleteGroup

A group of suggestions under one AutocompleteLabel.

  • itemsreadonly any[]

    The items of this group (group.items of the root's grouped items), for the Combobox.Collection inside it.

Plus render, and className / style as functions of the part's state, and every <div> prop.

AutocompleteInput

The input, in a group the popup is anchored to. showTrigger puts a chevron button at the end, showClear a clear button (which replaces the chevron while there is text); children go in the group after them. className is the group's. Give the input its own aria-label, or a Field.Label.

  • disabledboolean

    Default false

    Whether the input should ignore user interaction.

  • classNamestring

    The group's class (the input inside it is styled by the group).

  • inputClassNamestring

    The <input>'s own class, merged after the group's control classes.

  • showTriggerboolean

    Default false

    A chevron button that opens the suggestions.

  • showClearboolean

    Default false

    A clear button, shown while there is text.

  • triggerLabelstring

    Default "Show suggestions"

    The chevron button's name for screen readers.

  • clearLabelstring

    Default "Clear"

    The clear button's name for screen readers.

Plus render, and className / style as functions of the part's state, and every <input> prop.

AutocompleteItem

One suggestion. The highlight is data-highlighted; choosing it puts its text in the input.

  • valueany

    Default null

    A unique value that identifies this item (what the root's items hold).

  • indexnumber

    The item's place in the list: required when the list is virtualized (only some items are mounted), optional otherwise.

  • labelstring

    The text typeahead and the input match; default: the item's text content.

  • disabledboolean

    Default false

    Whether the item cannot be chosen (it can still be highlighted).

  • nativeButtonboolean

    Default false

    Whether the rendered element is a native <button>. A <div> is better: a focusable item would take focus from the input.

Plus render, and className / style as functions of the part's state, and every <div> prop.

AutocompleteItemText

A suggestion's text with the typed query marked (@kitora/ui/highlight): <AutocompleteItem value={x}><AutocompleteItemText>{x}</AutocompleteItemText></AutocompleteItem>. The query is the input's current text, read from the root; pass query to mark something else (a server's match, the query before an inline completion rewrote the input in both / inline mode). The marks are presentational: the option's accessible name stays its full text.

  • classNamestring

    Classes on the wrapping <span>.

  • variantHighlightVariant

    Default "underline"

    Base look of each <mark>: an underline, a tint, or none (style it with markClassName).

  • markClassNamestring

    Classes for each <mark>, merged after the variant's classes.

  • matchOptionsHighlightMatchOptions

    How query matches (case-sensitive, whole words). Ignored for ranges and indices.

  • renderMatch(text: string, index: number, term: number) => React.ReactNode

    Draws a matched run yourself (a link, a coloured span); the default is a <mark>. index counts the marks; term is the index of the query term that hit it (the first one, where hits of several terms merged), so each term can take its own colour, or -1 for ranges / indices.

  • childrenrequiredstring

    The suggestion's full text, the string the marks are drawn in.

  • querystring

    The text to mark instead of the input's current text (a server's match, the query before an inline completion).

AutocompleteLabel

A group's heading (an Autocomplete.GroupLabel): it names the group.

Plus render, and className / style as functions of the part's state, and every <div> prop.

AutocompleteList

The list the input controls (role="listbox"); give it a function of a suggestion to render the filtered items. It scrolls when it is taller than the room.

  • childrenReact.ReactNode | ((item: any, index: number) => React.ReactNode)

    The items, or a function of an item and its index that renders one (a closed template over the root's filtered items).

Plus render, and className / style as functions of the part's state, and every <div> prop.

AutocompleteSeparator

A thin rule between suggestions or groups.

  • orientationOrientation

    Default "horizontal"

    The orientation of the separator.

Plus render, and className / style as functions of the part's state, and every <div> prop.

AutocompleteStatus

A message a screen reader announces politely: "Searching…", a count.

Plus render, and className / style as functions of the part's state, and every <div> prop.

AutocompleteTrigger

A button that opens the suggestions. Inside AutocompleteInput (showTrigger) it is an icon button of the group.

  • nativeButtonboolean

    Default true

    Whether the rendered element is a native <button>.

  • disabledboolean

    Default false

    Whether the trigger ignores user interaction; the combobox's and the field's disabled disable it too.

Plus render, and className / style as functions of the part's state, and every <button> prop.

AutocompleteValue

The text as a node (a preview of what is typed). Renders no element.

  • childrenReact.ReactNode | ((inputValue: string) => React.ReactNode)

    What to show: a node, or a function of the text. Default: the text.

Keyboard

  • ArrowDownArrowUpAutocomplete.InputGroupOpens the list of suggestions with nothing highlighted; in an open list it moves the highlight down (up), past either end back to the typed text.

Accessibility

  • Autocomplete follows the WAI-ARIA Combobox pattern: roles combobox.

Hooks and functions

  • useAutocompleteFilter(options?: ListboxFilterOptions) => ListboxFilter

    The bare collator matchers (contains, startsWith, endsWith, exact), for a list that filters items itself and hands them to the root's filteredItems.

  • useAutocompleteFilteredItems<Item = any>() => readonly Item[]

    The suggestions the root listed after filtering (groups when items are groups); call it inside the root.
