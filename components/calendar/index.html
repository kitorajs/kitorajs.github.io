Props

Calendar

A calendar in every mode (days, weeks, months, quarters, years; one, several or a range), plus its parts for composing your own.

  • mode"single"

    Picks one day. Toggles separate days on and off. Picks a start day, then an end day. The period unit picked, alone or as a -range.

  • valueIsoDate | null

    Controlled day; null is "nothing picked". Leave undefined for an uncontrolled calendar. Controlled picked days. Leave undefined for an uncontrolled calendar. Controlled range; end is null between the two clicks. Leave undefined for an uncontrolled calendar. The selected period(s) as days: first day of the first period to last day of the last; end null between range clicks.

  • defaultValueIsoDate | null

    The day picked at first when uncontrolled; null for none. The days picked at first when uncontrolled. The range picked at first when uncontrolled. The selected period(s) at first when uncontrolled, as days.

  • onChange(value: IsoDate) => void

    Called when a day is picked, with that day. Called when a day is toggled, with every picked day. Called on every click (end is null after the first) and on every moved end. Called on every period click and every moved end, with the selection as days and why it changed.

  • minIsoDate

    Earliest selectable day, inclusive.

  • maxIsoDate

    Latest selectable day, inclusive.

  • isDateDisabledDateDisabledFn

    Extra blocked days (weekends, holidays, booked slots): true blocks, { reason } blocks and says why.

  • rulesreadonly DateRule[]

    Blocked days as data with reasons ({ weekdays: [0, 6], reason }, { dates }, { ranges }, { before }, { after }); see core/rules.ts.

  • disablePastboolean

    Block every day before today.

  • disableFutureboolean

    Block every day after today.

  • dayDataDayDataLoader

    Async day data (labels such as prices, tones, blocked days with reasons), loaded per visible month; see useDayData.

  • dayDataKeystring

    Changing it drops the day data cache and ignores responses in flight (a new currency, a new filter).

  • dayDataSourceDayDataState

    A day data state hosted above the calendar (useDatePicker passes its own, so the cache outlives the surface); wins over dayData.

  • localestring

    BCP 47 tag; default the browser's. Drives labels and the week start.

  • weekStartsOnWeekday

    Override the locale's first day of the week.

  • numberOfMonthsnumber

    Default 1

    Months shown side by side.

  • defaultMonthIsoDate

    First visible month when uncontrolled; default the selection or today.

  • monthIsoDate

    Controlled first visible month (any day in it).

  • onMonthChange(month: IsoDate) => void

    Called when the visible month changes (paging, keyboard, drill-down), with the new first visible month's first day.

  • autoFocusboolean

    Focus the selected (or today's) day on mount, for popovers.

  • todayIsoDate

    "Today" for highlighting and for the default month; default the host clock.

  • showOutsideDaysboolean

    Default true

    Draw the leading and trailing days of the neighbouring months (one month only).

  • outsideDaysOutsideDays

    Outside days: selectable (default), visible (drawn, not pickable) or hidden. Wins over showOutsideDays.

  • pageBehaviorPageBehavior

    Default "single"

    Page by one month (single) or by every visible month (page).

  • fixedWeeksboolean

    Default true

    Always draw six week rows so the surface never changes height; false drops rows outside the month.

  • formatterCalendarFormatter

    Default `intlCalendarFormatter`

    Every label and announcement.

  • compareRangeDateRange

    A second range drawn on the cells (data-compare): a compare period beside the selection.

  • moveEndsboolean

    Default true

    Range modes: let a complete range's ends be dragged by pointer and moved with Shift+Arrow.

  • calendarCalendarId

    The calendar the day modes are drawn in; default the locale's -u-ca- extension, else Gregorian. The value stays ISO Gregorian.

  • weekNumbersboolean | WeekNumbering

    A week-number column: true or "iso" for ISO 8601 weeks, "locale" for the locale's week-of-year; default none.

  • classNamestring

    Extra classes for the root element.

  • classNamesCalendarClassNames

    One class per part (merged after the part's own classes).

  • renderDay(iso: IsoDate) => ReactNode

    Per-day decoration under the number (dots for events, prices…).

  • aria-labelstring

    Accessible name for the calendar.

MonthGrid

Twelve months of one year in a 3×4 grid, with year paging: Calendar in month mode showing only its month grid.

  • valuestring | null

    Controlled month, YYYY-MM (null = none); its year is the one shown first. Leave undefined for uncontrolled.

  • defaultValuestring | null

    Default null

    Initial month, YYYY-MM, when uncontrolled (null = none).

  • onChange(month: string) => void

    Called when a month is picked, with it as YYYY-MM.

  • localestring

    BCP 47 locale for the month names; default the host's.

  • minIsoDate

    Earliest month (any day in it, or YYYY-MM).

  • maxIsoDate

    Latest month (any day in it, or YYYY-MM).

  • onYearClick() => void

    Clicking the year caption. Without it the caption is static.

  • autoFocusboolean

    Whether to focus the selected (or current) month on mount.

  • todayIsoDate

    Default today in the time zone in effect (`useCalendar`'s)

    "This month" for highlighting, from the host clock unless given.

  • classNamestring

    Extra classes for the month grid.

QuarterGrid

The four quarters of one year in one row, with year paging: Calendar in quarter mode showing only its quarter grid.

  • valueIsoQuarter | null

    Controlled quarter, YYYY-Qn (null = none); its year is the one shown first. Leave undefined for uncontrolled.

  • defaultValueIsoQuarter | null

    Default null

    Initial quarter, YYYY-Qn, when uncontrolled (null = none).

  • onChange(quarter: IsoQuarter) => void

    Called when a quarter is picked, with it as YYYY-Qn.

  • localestring

    BCP 47 locale for the year and quarter names; default the host's.

  • minIsoDate

    Earliest quarter (any day in it).

  • maxIsoDate

    Latest quarter (any day in it).

  • onYearClick() => void

    Clicking the year caption. Without it the caption is static.

  • autoFocusboolean

    Whether to focus the selected (or current) quarter on mount.

  • todayIsoDate

    Default today in the time zone in effect (`useCalendar`'s)

    "This quarter" for highlighting, from the host clock unless given.

  • classNamestring

    Extra classes for the quarter grid.

WeekGrid

A month of weeks with week numbers: Calendar in week mode. A click (or Enter) on any day picks its whole week, and hovering a day bands its row; the caption drills up to months and years as in the day calendar.

  • valueDateRange | null

    Controlled week, as its days { start, end } (null = none); leave undefined for uncontrolled.

  • defaultValueDateRange | null

    Default null

    Initial week when uncontrolled (null = none).

  • onChange(week: DateRange, details: { readonly isoWeek: IsoWeekId }) => void

    Called when a week is picked, with its days and its ISO week id (2026-W46).

  • localestring

    BCP 47 locale for the names and, unless weekStartsOn is given, the first day of the week; default the host's.

  • weekStartsOnWeekday

    First day of the week (0 = Sunday); default the locale's.

  • weekNumbersboolean

    Default true

    Draw the week-number column.

  • weekNumberingWeekNumbering

    Default "iso"

    How the week rows are numbered: ISO 8601 weeks or the locale's week-of-year.

  • minIsoDate

    Earliest selectable day.

  • maxIsoDate

    Latest selectable day.

  • todayIsoDate

    Default today in the time zone in effect (`useCalendar`'s)

    "Today" for highlighting and the first month shown, from the host clock unless given.

  • autoFocusboolean

    Whether to focus the selected (or today's) day on mount.

  • aria-labelstring

    Accessible name for the calendar.

  • classNamestring

    Extra classes for the calendar root.

YearGrid

A page of twelve years in a 3×4 grid: Calendar in year mode showing only its year grid.

  • valuenumber | null

    Controlled year (null = none); leave undefined for uncontrolled.

  • defaultValuenumber | null

    Default null

    Initial year when uncontrolled (null = none).

  • onChange(year: number) => void

    Called when a year is picked, with it.

  • minnumber

    Earliest selectable year.

  • maxnumber

    Latest selectable year.

  • localestring

    BCP 47 locale for the year numbers; default the host's.

  • autoFocusboolean

    Whether to focus the selected (or current) year on mount.

  • todayIsoDate

    Default today in the time zone in effect (`useCalendar`'s)

    "This year" for highlighting (any day in it), from the host clock unless given.

  • classNamestring

    Extra classes for the year grid.

Hooks and functions

  • dateBlockText(block: DateBlock, msg: PickersMessages, bounds?: { readonly min?: IsoDate; readonly max?: IsoDate; readonly locale?: string; }) => string

    The words for a block: the rule's own reason, else the catalog's message for its code (min / max name the bound).

  • useCalendarContext() => CalendarContextValue

    The calendar state from the nearest Calendar.Root; throws outside one so a misplaced part fails loudly.

Features

  • DP79 `WeekGrid`: the calendar in week mode with week numbers on by default (ISO, or the locale's with `weekNumbering`); a click or Enter on any day picks its locale week, `onChange(week, { isoWeek })`, and hovering a day bands its row (`data-week-hovered`, as `DatePicker mode="week"` now does too) (pickers, live)
  • DP80 `QuarterGrid`: the four quarters of one year in a row with year paging, `YYYY-Qn` values, `min` / `max` as any day in the bound quarter, RTL arrows (pickers, live)
