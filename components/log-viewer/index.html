Props

LogViewer

The styled log viewer. Pass hook options (entries / lines / source…) or a viewer from useLogViewer.

  • viewerLogViewerState

    Use your own useLogViewer result (state lifted out); the hook options above are then ignored.

  • classNamestring

    Classes for the root element.

  • classNamesPartial<Record<LogViewerSlot, string>>

    Classes for each part of the preset, by slot (toolbar, row, time, level, message and so on).

  • levelClassNames{ readonly [level: string]: LogLevelStyle }

    Extra / replacement level colours.

  • toolbarboolean

    Hide the toolbar or the status line.

  • statusboolean

    Whether to show the status line; false hides it.

  • toolbarStartReactNode

    Slot at the toolbar's start (a title, a source picker).

  • toolbarEndReactNode

    Slot at the toolbar's end, before the view toggles.

  • statusEndReactNode

    Slot at the status line's end (counts, timings, a connection state).

  • renderRow(row: LogRowRenderProps) => ReactNode

    Replace the default row (wrap your markup in LogView.Row).

  • emptyReactNode

    Shown when no line is visible.

  • entriesreadonly LogEntry[]

    Already-parsed entries (static).

  • linesreadonly string[]

    Raw lines (static), parsed once with parser.

  • sourceLogSource

    A live source; when set it wins over entries / lines. Swap the object to reset.

  • parserLogParser

    Line parser for lines and string items from source (defaults to {@link defaultLogParser}).

  • levelsreadonly LogLevelSpec[]

    Known levels, in toggle order (defaults to {@link LOG_LEVELS}).

  • maxEntriesnumber

    Cap on entries kept from a live source.

  • lineHeightnumber

    Px height of one line.

  • filterLogFilter

    Controlled filter: hidden levels plus a text query; rows that do not match are hidden.

  • defaultFilterLogFilter

    Uncontrolled initial filter; when unset, {@link EMPTY_LOG_FILTER} (nothing hidden).

  • onFilterChange(filter: LogFilter) => void

    Called when the filter changes, with the new filter.

  • searchstring

    Controlled search query (substring or /regex/flags); hits are highlighted and stepped through, nothing is hidden.

  • defaultSearchstring

    Uncontrolled initial search query; when unset, empty.

  • onSearchChange(search: string) => void

    Called when the search query changes, with the new query.

  • followboolean

    Controlled follow tail: true keeps the list pinned to the newest entry.

  • defaultFollowboolean

    Uncontrolled initial follow tail; when unset, on for a live source and off otherwise.

  • onFollowChange(follow: boolean) => void

    Called when follow tail changes, with the new value.

  • wrapboolean

    Controlled line wrapping: whether long messages wrap instead of scrolling sideways.

  • defaultWrapboolean

    Uncontrolled initial line wrapping; when unset, off.

  • onWrapChange(wrap: boolean) => void

    Called when line wrapping changes, with the new value.

  • timeModeLogTimeMode

    Controlled timestamp mode: clock time, or time since the first entry.

  • defaultTimeModeLogTimeMode

    Uncontrolled initial timestamp mode; when unset, "absolute".

  • onTimeModeChange(mode: LogTimeMode) => void

    Called when the timestamp mode changes, with the new mode.

  • exportFileNamestring

    File name for {@link LogViewerState.exportVisible}.

  • copyTextCopier

    Where "Copy line" puts the raw line. Default: the browser clipboard (copyText). Return false to report a failed copy.

  • downloadTextDownloader

    Where "Export" sends the visible lines. Default: a browser download (downloadText).

  • formatTimeLogTimeFormatter

    Formats a timestamp for LogView.Time (a locale, a timezone, a dayjs call). Default {@link formatLogTime}.

LogViewerRow

The preset's row; exported so a custom renderRow can wrap or tweak it.

  • rowrequiredLogRowRenderProps

    The row to render, as LogView.List hands it to renderRow.

  • classNamesLogViewerProps["classNames"]

    Classes for each part of the row, by slot.

  • levelClassNamesLogViewerProps["levelClassNames"]

    Extra or replacement level colours.

Hooks and functions

  • LOG_LEVEL_STYLES

    Default level colours, light and dark. Merge your own through levelClassNames.

  • LOG_VIEWER_WRAP_INDENT

    Characters a styled row spends before its message: expander 2ch, time 12ch, level 5ch, source 10ch, plus the gaps and side padding. The wrap maths subtracts this from the list width.
