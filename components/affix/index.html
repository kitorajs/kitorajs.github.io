Props

Affix

Pins its content to a viewport corner. position is a logical corner (default bottom-end), offset the distance from the edges in px (default 20, plus the safe-area insets), zIndex its stacking (default 50). Portalled unless withinPortal={false}. render replaces the element.

  • positionAffixPosition

    Default "bottom-end"

    The corner, in logical terms (end is the right in left-to-right text).

  • offsetnumber

    Default 20

    The distance from the edges in px, before the safe-area insets.

  • zIndexnumber

    Default 50

    The stacking order.

  • withinPortalboolean

    Default true

    Render at the end of the body (or the portal container) instead of in place.

Plus render, and className / style as functions of the part's state, and every <div> prop.

BackToTop

A "back to top" button in a viewport corner, shown once target (default the window) has scrolled past threshold px. Pressing it scrolls to the top, smoothly unless the user prefers reduced motion. label is the button's accessible name and tooltip (default "Back to top"); children replaces the arrow icon. scrolled with onScrolledChange controls whether it shows (for a host that tracks scrolling itself).

  • variant"link" | "default" | "secondary" | "outline" | "ghost" | "soft" | "destructive" | "destructive-soft" | null

    Default "default"

    The colour scheme and emphasis.

  • size"default" | "xs" | "sm" | "lg" | "xl" | "icon" | "icon-xs" | "icon-sm" | "icon-lg" | null

    Default "default"

    The height and padding; the icon-* sizes make a square button for a lone icon.

  • loadingboolean

    Default false

    Busy: aria-busy="true" and data-loading, activation blocked but focus kept (focusable-disabled semantics, so focus is not dropped mid-submit), full opacity. The children stay in place, invisible, so the width does not jump, with a spinner centred over them. Controlled by this prop only.

  • renderUseRenderRenderProp

    The primitives' render prop, an alias of asChild with the element given here instead of as the child: an element (cloned with the button's props) or a function (props) => element. asChild wins when both are given.

  • asChildboolean

    Default false

    Render the single child element instead of a <button>, merging the button's props onto it (classes joined, handlers chained, the child's other props win). Built on useRender from

  • focusableWhenDisabledboolean

    Default false

    Keep a disabled button in the tab order: aria-disabled="true" instead of disabled, clicks and every key but Tab blocked (the primitive useButton), hover kept so a Tooltip can explain why.

  • nativeButtonboolean

    Whether the rendered element is a native <button>. Only read with focusableWhenDisabled or loading (it decides aria-disabled vs role="button" handling). Defaults to true unless render/asChild gives an element other than <button>.

  • loadingTextReact.ReactNode

    While loading, show the spinner beside this text instead of over the hidden children.

  • thresholdnumber

    Default 300

    Show after scrolling this many px.

  • target() => HTMLElement | null

    The scroll container to watch and scroll; default the window.

  • labelstring

    Default "Back to top"

    The button's accessible name and native tooltip.

  • scrolledboolean

    Whether the button shows (controlled); default it follows the scroll position.

  • onScrolledChange(scrolled: boolean) => void

    Called when the scroll position crosses threshold, with whether it is past it.

  • childrenReact.ReactNode

    Default an arrow-up icon

    The button's content.

  • affixClassNamestring

    Classes for the Affix around the button (className styles the button); absolute with withinPortal={false} pins it inside a positioned box.

  • offsetnumber

    Default 20

    The distance from the edges in px, before the safe-area insets.

  • positionAffixPosition

    Default "bottom-end"

    The corner, in logical terms (end is the right in left-to-right text).

  • withinPortalboolean

    Default true

    Render at the end of the body (or the portal container) instead of in place.

  • zIndexnumber

    Default 50

    The stacking order.

Plus every <button> prop.

Hooks and functions

  • floatButtonVariants(props?: ({ size?: "default" | "xs" | "sm" | "lg" | null | undefined; shape?: "circle" | "square" | null | undefined; extended?: boolean | null | undefined; } & ClassProp) | undefined) => string

    The floating button's look on a Button (size="icon"): a shadow, the size and the shape. xs is Button's own 32px icon size (BackToTop's, which follows a design language's button height); sm 40px, default 48px, lg 56px. shape circle is round, square keeps the button slot's corner. extended (icon plus text) is as tall as the size and as wide as its text.
