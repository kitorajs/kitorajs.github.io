Item

A row of media, title, description and actions (notifications, settings, people, files) with outline and muted surfaces, three sizes, link or button rendering, a selected state on the list slot and actions that wrap in a narrow container.

Source: @kitora/ui (the primitive the kits compose)

Props

Item

A row: ItemMedia, ItemContent (ItemTitle, ItemDescription) and ItemActions, with an optional ItemHeader and ItemFooter spanning the row. variant is default, outline (an edge) or muted (a fill); size is default, sm or xs. Presentational only: put inputs in a Field, not in the Item.

  • variant"default" | "outline" | "muted" | null

    Default "default"

    The row's surface: plain, an edge (outline) or a fill (muted).

  • size"default" | "xs" | "sm" | null

    Default "default"

    The row's padding and gaps.

  • selectedboolean

    Mark the row as the selected one (data-selected, the list slot's fill). A selectable list sets it for you.

  • disabledboolean

    Dim the row and ignore the pointer (data-disabled, aria-disabled). A rendered <button> still needs its own disabled.

  • interactiveboolean

    Style as a control (hover fill, focus ring) when the row handles clicks itself; set for you when render is an <a> or <button> element (pass it with a function render).

Plus render, and className / style as functions of the part's state, and every <div> prop.

ItemActions

Buttons, a switch, a badge or a menu trigger, on the end side. Below 22rem of the row's width it wraps under the content.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ItemContent

The text column: ItemTitle over ItemDescription. It takes the free width and may shrink, so long text clamps instead of pushing the actions out.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ItemDescription

Secondary text, clamped to two lines. On a selected row it reads the list slot's secondary colour.

Plus render, and className / style as functions of the part's state, and every <p> prop.

ItemFooter

A full-width band under the row's media and content (a timestamp, a progress bar).

Plus render, and className / style as functions of the part's state, and every <div> prop.

ItemGroup

A list of Items (role="list", a column): each Item inside is a role="listitem". Name it with aria-label when it stands alone.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ItemHeader

A full-width band above the row's media and content (a meta line, a tag row).

Plus render, and className / style as functions of the part's state, and every <div> prop.

ItemMedia

The leading visual of a row, on the start side. variant: default (as given), icon (a bordered square holding an icon), image (a clipped thumbnail) or avatar (a ui Avatar at 40px).

  • variant"image" | "default" | "icon" | "avatar" | null

    Default "default"

    How the media is framed: as given, a bordered icon square, a clipped thumbnail, or a 40px avatar.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ItemSeparator

A rule between Items of a group: a ui Separator with no role of its own (role="none"). Inside the group's role="list" only list items are allowed as children, and the rule is decoration: the list items already mark where one row ends. A rule outside a group keeps the separator role.

  • orientationOrientation

    Default "horizontal"

    The orientation of the separator.

  • variantSeparatorVariant

    Default "solid"

    Line style.

  • labelReact.ReactNode

    Text in the rule ("or", a date); children work too. A horizontal rule only.

  • labelPosition"start" | "center" | "end"

    Default "center"

    Where the label sits along the rule, in reading order.

Plus render, and className / style as functions of the part's state, and every <div> prop.

ItemTitle

The row's name. A <div> by default; render={<h3 />} makes it a heading.

Plus render, and className / style as functions of the part's state, and every <div> prop.

03As a link or a button

render draws the row as an <a> or a <button>: the hover fill and focus ring apply to it, and it keeps its role inside an ItemGroup. selected and disabled are the other row states.

Profile

A link: `render=<a href />` gives it the hover fill and the focus ring.

Security

`selected` draws the list slot's selected fill; this row is plain text.

Danger zone

`disabled` dims the row and ignores the pointer.

Button pressed: none
