NavigationMenu

A site or app navigation bar: links and triggers that disclose panels of links in one shared popup that morphs between them. Disclosure navigation, not a role=menu: Tab, arrows, Escape, hover with a delay, nested menus, vertical, RTL.

Source: @kitora/ui (the primitive the kits compose)

01Default

Tab walks the triggers and links, ← / → move along the list and ↓ opens a panel and moves into it; Escape closes it and returns to its trigger. Resting the pointer on a trigger opens it, and moving to the next one switches at once. A link with active is the current page.

  • GitHub

02Mega menu with a morphing popup

Three panels of different sizes share one popup: it follows the active trigger and animates its size (--popup-width, --popup-height, --positioner-width, --positioner-height), and each panel slides toward the side the new trigger is on (data-activation-direction).

  • Pricing

03Vertical

orientation="vertical": ↑ and ↓ walk the list, → (← in right to left text) opens a panel beside its trigger.

  • Help

04Nested

A menu inside a panel: positioner={false} and a NavigationMenuViewport of its own, so its panels open inline. Escape closes the nested panel first.

05Responsive header menu

ShellNavigationMenu from @kitora/shell draws one list of items as this menu from collapseBelow (768px by default) up, and below it as a menu button that opens a sheet with each item that has children as an accordion section.

Acme

Current page: #analytics. Narrow the window below 768 px to get the menu button and its sheet.

06Restyled with slot variables

--dk-navmenu-radius, --dk-navmenu-hover and --dk-navmenu-popup-radius set on an ancestor turn the triggers and links into pills with an accent hover and give the popup a squarer corner.

  • Blog

07App header

A menu next to a Button in a Card; the current page is the active link (aria-current="page") and closeOnClick closes the panel when a link is chosen.

  • Settings

Current page: Overview

08Build your own

The same navigation menu from the primitives' NavigationMenu parts; a rebuild test compares it with ui's (opening and switching panels by mouse and keys, Escape, vertical, controlled).

Props

NavigationMenu

A bar of links and triggers that disclose panels of links (APG Disclosure Navigation, not a role="menu"): Tab walks the triggers and links, the arrow keys move along the list (↓ in a horizontal bar, → in a vertical one, opens the panel and moves into it), Escape closes the panel and returns focus to its trigger, and the pointer opens a panel after a short rest and switches between them at once. The panels share one popup that follows the active trigger and morphs its size (NavigationMenuPositioner, drawn for you unless positioner={false}). A menu inside a panel passes positioner={false} and renders a NavigationMenuViewport of its own.

  • valueValue | null

    Default null

    The controlled value of the item that is open; nullish closes the menu. Use defaultValue for an uncontrolled menu.

  • defaultValueValue | null

    Default null

    The value of the item that starts open (uncontrolled).

  • onValueChange(value: Value | null, details: NavigationMenuChangeEventDetails) => void

    Called when the open item changes (or the menu closes: null); details.cancel() refuses the change.

  • actionsRefReact.RefObject<NavigationMenuRootActions | null>

    A ref to imperative actions. Given one, a closed menu stays mounted at its exit style until actions.unmount() is called.

  • onOpenChangeComplete(open: boolean) => void

    Called after the exit animation, once the menu is closed and gone.

  • delaynumber

    Default 50

    How long the pointer must rest on a trigger before the menu opens, in ms.

  • closeDelaynumber

    Default 50

    How long after the pointer leaves before the menu closes, in ms.

  • orientationNavigationMenuOrientation

    Default "horizontal"

    The direction the list lies in: it decides the arrow keys, which arrow opens a trigger and the direction content slides from.

  • positionerboolean

    Default true

    Draw the shared popup after the children. Set false for a menu nested in a panel, or to compose the popup parts yourself.

NavigationMenuPositioner

The popup for the panels, in a portal: it follows the active trigger and morphs between their sizes. Pass backdrop to dim the page and arrow for a pointer.

  • anchorPositionerAnchor

    What to place against instead of the trigger: an element, a virtual anchor (a point), a ref, or a function returning one.

  • positionMethodPositionStrategy

    absolute (default) follows the page while it scrolls; fixed places in the viewport.

  • sideAnchoredSideRequest

    Default "bottom"

    Which side of the anchor the popup sits on; inline-start / inline-end follow the text direction.

  • alignAnchoredAlign

    Default "center"

    Alignment along that side.

  • sideOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 8

    Gap between anchor and popup, px or a function of the placement.

  • alignOffsetnumber | ((data: { side: AnchoredSideRequest; align: AnchoredAlign; anchor: { width: number; height: number }; positioner: { width: number; height: number } }) => number

    Default 0

    Shift along the anchor's edge.

  • collisionBoundaryCollisionBoundary

    Default "clipping-ancestors"

    What the popup must stay inside.

  • collisionPaddingnumber | Partial<PlacementPadding>

    Default 5

    Space kept from the boundary's edges.

  • arrowPaddingnumber

    Default 5

    Space kept between the arrow and the popup's corners.

  • stickyboolean

    Default false

    Keep the popup against its anchor's edge while the anchor scrolls away.

  • disableAnchorTrackingboolean

    Default false

    Do not follow the anchor after the first placement.

  • collisionAvoidanceCollisionAvoidance

    Flip, shift or neither, per axis.

  • lazyFlipboolean

    Default false

    Flip lazily: once the popup is placed, the side it settled on is the side it starts from, so it flips back only when that side no longer fits (a list that filters while open). Base UI applies this inside its Combobox positioner only; here every positioner takes it.

  • adaptiveOriginboolean

    Default false

    Keep --transform-origin right while the popup resizes or morphs: a popup on the left or top side is written from its far edge (right / bottom), so a size transition grows toward the anchor. Only a popup with a CSS transition is affected. Base UI turns this on when the popup has a Viewport part; here every positioner takes it.

  • backdropboolean

    Default false

    Draw an overlay behind the popup.

  • arrowboolean

    Default false

    Draw an arrow pointing at the trigger.

Plus render, and className / style as functions of the part's state, and every <div> prop.

Keyboard

  • ArrowRightNavigationMenu.TriggerMoves focus to the next trigger or link of a horizontal list, without wrapping (the previous one right to left).
  • ArrowLeftNavigationMenu.TriggerMoves focus to the previous trigger or link of a horizontal list, without wrapping (the next one right to left).
  • HomeNavigationMenu.TriggerMoves focus to the first trigger or link of the list.
  • ArrowDownNavigationMenu.TriggerOpens the item's content and moves focus into it (in a vertical menu the inline-end arrow, ArrowLeft right to left).
  • EnterSpaceNavigationMenu.TriggerOpens the item's content and moves focus into it; pressed again, closes it.
  • EscapeNavigationMenu.TriggerCloses the open content and returns focus to its trigger.

Accessibility

  • NavigationMenu follows the WAI-ARIA Disclosure (Show/Hide) pattern: roles button.

Design-language slot

slots.navigationMenu NavigationMenu (@kitora/ui/navigation-menu): the triggers and links in the bar, the popup they open and the optional backdrop behind it. The popup's fill, blur and shade follow the popover slot; its corner is its own (a navigation popup is larger than a popover).

  • corner CornerA trigger's and a link's corner.
  • hover PerScheme<Fill>A trigger or link under the pointer or focused, per scheme (none for no fill); the text keeps its own colour.
  • popupCorner CornerThe popup's corner.
  • backdrop numberHow dark the optional backdrop behind an open popup is, 0–1 (black at this opacity).
