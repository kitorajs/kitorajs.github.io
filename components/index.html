Catalogue

144 components, one design language.

Every component reads from the same token system. Pick one to see its variants, states, and usage notes. 82 primitives from @kitora/ui, 62 parts owned by a kit. Each component has one implementation, and its page names the package it comes from.

Actions

11
Button

Eight intents, five sizes, icon-only variants. Compact-first — 32px default. Slot-based via asChild.

IconButton

Icon-only button with a required label, a pressed state for toggles and a native or styled tooltip. The one every kit toolbar uses.

CloseButton

The one × for every dismissable surface: an IconButton preset named "Close" by default, 24px minimum pointer target, drawn as a primitive Close part through `render`.

ButtonGroup

Joined buttons. Shares borders, rounds only outer corners. Plus SegmentedGroup for toolbars.

SplitButton

Main action + dropdown chevron in one joined unit. Deploy ▼ / Save ▼ patterns.

Toggle

Two-state pressable button — bold/italic/underline-style controls.

ToggleGroup

Single or multi-select group of toggle buttons. Type, alignment, view-style toolbars.

SegmentedControl

One value of a few as segments in a track, never empty. Toggle or radio semantics, three sizes, an optional sliding indicator.

FloatButton

A floating action button pinned to a logical viewport corner above the safe area: an Affix holding a Button, in three sizes, round or square, extended with text, as a link, with a count or dot badge and a tooltip. BackToTop is its preset.

Toolbar

A row of buttons, toggles, links, inputs and menu triggers with one tab stop and arrow-key movement.

CopyButtonkit

Icon button that copies a value, swaps to a check and announces the result politely. The display kit's CopyButton.

Forms

31
Input

Single-line text. Includes invalid state via aria-invalid.

Textarea

Multi-line text. Auto-resizes when configured by host.

Label

Accessible form label. Pairs with every input.

Field

A label, a control, a description and an error wired together, with the field state (valid, invalid, dirty, touched, filled, focused) and validation on submit, blur or change. Works with Input, Checkbox, Switch, RadioGroup and Slider.

Fieldset

A native fieldset named by its legend. A disabled fieldset disables the fields inside it.

Form

A native form over Field: blocks a submit while a field is invalid, focuses the first one, hands the values to onFormSubmit and shows server errors under their fields.

Select

Kitora's select: a button that opens a list of options, laid over the trigger with the chosen item on its value. Single or multiple, groups, scroll arrows, typeahead, a search box (`searchable`), Field and Form. The kits use it, and the collections kit's Select (items as data) is an adapter over it. Use NativeSelect instead where the platform's own control is wanted: a form that must work without JavaScript, or the native picker on a phone.

Slider

Range / value picker. Single or multi-thumb.

Calendarkit

Month grid with single, multiple and range modes, whole weeks, and month, quarter and year grids; Intl names and month/year drill-up. The pickers kit's Calendar.

DatePickerkit

One date picker for every mode: a day, several days, a range, or one or a range of weeks, months, quarters or years, as ISO strings; with a time granularity a date-time or a date-time range (floating, a UTC instant or RFC 9557 zoned, in a display zone with a zone switch, a second-zone hint and fixed offsets), and time and time-range modes. Presets in every mode (rolling presets that stay relative to today), compare periods (previous period or year), nights or days, open-ended ranges, one field or two, ranges across disabled days, and range ends dragged by pointer or moved with Shift+arrows. Rules as data with reasons (weekdays, holidays, ranges, past or future only) shown on the day and announced, and async day data such as prices under the days. Typed segments or free text with natural language, calendar popover with a time list or columns, min / max bounds, clear, Apply / Cancel in every mode. Beside it the SlotPicker: free time slots from an availability adapter on the same calendar and zone parts, in a month or week layout. The pickers kit's DatePicker.

TagsInputkit

Type a tag, hit Enter and a chip appears; Backspace removes. The collections kit's TagsInput.

MaskInput

Text that formats as you type (phone, card, IBAN, codes): the caret stays where you type, Backspace skips the literals, a paste fills in order, and the raw value posts with the form.

SearchInput

Search field with icon + ⌘K hint chip + optional clear button.

Combobox

An input you search a list with: type to filter, arrows to highlight (focus stays in the input), Enter to choose. Single or multiple with chips, groups, async lists, a search box inside the popup, Field and Form. The collections kit's Combobox (items as data, free text, async loading built in) builds on the same core.

Autocomplete

An input whose text is the value, with suggestions under it. Filter as you type, complete inline as you arrow, or both; groups, async suggestions, a search box that submits its form.

PasswordInput

Password with reveal toggle + optional strength meter.

NumberField

Locale-aware number input with steppers: Intl formatting, min / max / step (Shift and Alt for large and small), the arrow keys, press and hold, the wheel, a scrub area to drag a value, and a Field-aware label, description and error. The `NumberFieldControl` preset (commit on blur or Enter, steppers on or off, `name` posting the raw number) over the styled Base UI NumberField parts; the pickers kit's `NumberInput` renders them.

OTPField

One box per character of a one-time code: typing moves on, a paste or an autofill spreads the code, Backspace steps back, digits, letters or your own rule, a mask, completion and auto-submit. The `OTPField` preset (groups, sm / md / lg boxes from the `otp` slot, `name` posting the code) over the styled Base UI OTPFieldPreview parts; the pickers and auth kits' `OtpField` render them.

Dropzonekit

Drag-drop or click to pick files, with accept and size limits, rejection reasons and a file list. The upload kit's Dropzone.

FileTriggerkit

A "Choose file" button with no drop area: any button opens the file dialog, every pick is split by the upload rules, folders and the phone camera are one prop away, and with a name a plain form posts the files. The upload kit's FileTrigger.

InputGroup

Input or textarea with inline addons — icons, text, buttons — sharing one border and focus ring.

NativeSelect

The platform's own select, styled, at h-7. For a form that must work without JavaScript, or where the native picker on a phone is wanted; everywhere else use Select.

InlineEditkit

Text that turns into a field in place: Enter saves, Escape restores, with validation, async saves and optional Save / Cancel buttons. The pickers kit's InlineEdit.

ColorPickerkit

Colour panel with area, hue and alpha sliders, typed values and presets, inline or in a popover, plus ColorSwatches on its own. The pickers kit's ColorPicker.

EmojiPickerkit

Pick an emoji from a popover or an inline panel: names for screen readers, search, categories, recently used, skin tones, and a value mode that posts with a form. The pickers kit's EmojiPicker.

Cascaderkit

Pick a path through nested options, one column per level, leaf-only or any level, with lazy children. The collections kit's Cascader.

TreeSelectkit

A select whose options are a tree, with a filter box, single or multiple selection with chips, and lazy children. The collections kit's TreeSelect.

Rating

Star rating on a radio group: arrow keys, half stars, clearable, read-only, custom icons, right-to-left.

TransferListkit

Pick a subset by moving items between two lists, with search, select-all and counts per side, keyboard multi-select and virtual rows for long lists. The collections kit's TransferList.

Mentionkit

A plain textarea where @ or # opens ranked or loaded suggestions and picking one inserts its name as text. The collections kit's Mention.

ModelSelectorkit

A model picker for a chat composer or a settings form: models grouped by provider with an icon, a description and tags (context window, reasoning, vision), a search box above 8 models, a bottom sheet on a phone and a `name` that posts the chosen id. A preset of the ui Select; the ai-chat kit's ModelSelector.

Selection

6
Checkbox

Boolean toggle for forms — pair with Label.

Switch

Boolean toggle that suggests an immediate effect (vs Checkbox = stage).

CheckboxGroup

Checkboxes that share one value, with a parent checkbox that ticks or clears them all (mixed while some are ticked).

RadioGroup

Mutually exclusive choice. Pair with Label per option.

ChoiceCard

Radio cards and checkbox cards: the whole card is the control, with an icon, a title, a price or other meta, a description and the radio or checkbox indicator; arrow keys in a radio group, a tab stop per checkbox card, form posting and Field wiring.

Tabs

Mutually exclusive panels — one tab visible at a time.

Navigation

9
BottomNavkit

The phone tab bar: 3 to 5 destinations as links along the bottom edge above the safe area, the current one marked by aria-current and more than a colour, count and dot badges with spoken labels, labels always or only on the current item, and hide on scroll. The shell kit's BottomNav parts and ShellBottomNav preset; AppShell draws it on phones from its bottomNav slot.

Breadcrumbskit

Hierarchical nav trail that collapses the middle into a dropdown. The shell kit's Breadcrumbs parts and ShellBreadcrumbs preset.

Menubar

A bar of menus (File, Edit, View) with arrow-key movement between them and hover switching while one is open.

NavigationMenu

A site or app navigation bar: links and triggers that disclose panels of links in one shared popup that morphs between them. Disclosure navigation, not a role=menu: Tab, arrows, Escape, hover with a delay, nested menus, vertical, RTL.

Pagination

Page jumps + prev/next. Keyboard-friendly, ellipsis for long ranges.

Stepskit

Multi-step flow indicator for wizards, onboarding and checkout: Stepper parts, the Steps preset and useStepper with linear or free navigation. The feedback kit's Stepper (tour re-exports it).

Sidebarkit

App sidebar with sections, nested trees, badges, an icon rail and resizing, marking the active route from the location. The sidebar kit's Sidebar preset.

Link

Inline text link with hover, always or no underline, safe external links with an announced new-tab hint, and render for router links or buttons. LinkBox and LinkOverlay make a whole card one link while its inner links and buttons keep working.

TableOfContentskit

The "On this page" list: headings from the page or a list, nested by level, a scroll spy that marks the section being read, smooth scrolling and sticky placement. The shell kit's TableOfContents.

Display

40
Badge

Compact label. Status, category, or count.

Avatar

Image with deterministic initials fallback.

Item

A row of media, title, description and actions (notifications, settings, people, files) with outline and muted surfaces, three sizes, link or button rendering, a selected state on the list slot and actions that wrap in a narrow container.

Highlight

Search-hit marks over text: give it a query (case- and accent-insensitive), ranges from your own matcher, or a fuzzy matcher's indices. Exports the pure helpers queryRanges, indexRanges, mergeRanges and splitRanges.

AvatarStackkit

Overlapping avatars with an overflow count, tooltips and presence. The display kit's AvatarStack.

Card

Surface container — header, content, footer slots.

StatCardkit

KPI tile with delta, hint and optional sparkline. The display kit's StatCard.

Skeleton

Pattern-shaped loading placeholder. Shape it to your real content.

Meter

A scalar inside a known range (disk used, strength), role=meter, with Intl formatting for units and currencies. For progress toward a goal use Progress.

Progress

Linear progress bar — uploads, steps, build state.

Separator

Horizontal or vertical hairline divider.

Accordion

Collapsible sections — FAQs, settings groups, file trees.

Collapsible

Single-section accordion. Show/hide a single block.

AspectRatio

Lock content to a specific ratio — video, image, embed.

ScrollArea

Scroll container with thin, styled scrollbars on both axes. @kitora/primitives underneath.

ShellPagekit

Page title, kicker, description, actions and tabs above the page body. The shell kit's ShellPage and Page parts.

PersonCardkit

Avatar, name, presence and a second line (role, handle or email), static or clickable. The display kit's PersonCard.

PricingTablekit

Plan cards with interval toggle, prices, features and a call to action, plus an optional comparison table. The commerce kit's PricingTable and Pricing parts.

Hero

Centered hero composition — kicker chip, huge headline, dual CTA. Pairs with BackgroundGrid.

QrCodekit

QR code drawn as one SVG path with selectable error correction, used for authenticator setup links. The auth kit's QrCode.

FormatNumberkit

Locale-aware numbers, currency, bytes, dates and relative times as components; a DisplayProvider sets the locale. The display kit's FormatNumber, FormatBytes, FormatDate and RelativeTime.

SplitViewkit

Resizable panes with pixel limits, collapsible panes, nesting and a keyboard-operable sash. The dock kit's SplitView, used without a dock.

DescriptionListkit

Term and value pairs inline, stacked or in a grid, with mono values, copy buttons and hints. The display kit's DescriptionList.

Carouselkit

Scroll-snap slides with arrows, dots, several per page, loop and autoplay that pauses on hover, focus and reduced motion. The display kit's Carousel.

Masonrykit

Items of mixed heights packed into columns with the DOM, Tab order and screen-reader order kept in source order: a column count, a responsive map or a minimum column width, a gap, packed or sequential placement, a server-rendered first paint, re-layout when an image loads late. The display kit's Masonry.

Tagkit

Coloured labels that can be removed or toggled; TagList folds the overflow into "+N". The display kit's Tag and TagList.

Heading

Heading, Text, Blockquote and List: level picks the element and size the look, tones, truncate and line clamp, render for any element.

OverflowList

One row of tags, avatars, chips or breadcrumbs that keeps what fits and puts the rest behind a +N button opening a popover, by measuring on every resize: collapse from the end or the start, a maxVisible cap, a custom overflow control, and focus that never drops when an item leaves.

Prose

One look for rendered markdown, rich text and CMS HTML: headings, lists and task lists, quotes, links, inline code, pre, kbd, images, figures and tables on the table slot, in three sizes, mirrored in right-to-left text, with not-prose to keep a part out. The editors and ai-chat kits draw through it.

Indicator

A dot or count (99+) pinned to a logical corner of any child, with offset, a processing pulse and a screen-reader label.

Image

Image with a loading skeleton, a fallback source, a fallback node, fit and radius.

Spoiler

Long content cut to a max height with a fade and a show more / show less button, controlled or uncontrolled.

Shimmer

Text with a light band sweeping across it while work runs ("Thinking…", a running step); plain muted text under reduced motion.

MessageScroller

A focusable chat or log viewport that follows the newest content at the live edge, lets go when the reader scrolls up, keeps their place when older rows load, and shows Jump to latest while away.

Message

Store-free chat message parts: a sender group, start or end rows with avatar or time gutter, header, footer, status in words (Sending…, Not sent. Retry) and a hover action toolbar.

Bubble

The surface a message sits on: sizes to its content up to 85% of the row, its tail on the sender's side (mirrored in right to left), seven variants, and interactive content through render.

Marker

A line in a conversation that is not a message: a named day separator (optionally sticky), a "New messages" row or a boxed status line.

Attachment

One file card for messages and composers: icon slot, name, size, upload progress and a named remove button, as a card or a chip.

Tracekit

An agent's steps as an ordered list: status icon and text, a title that shimmers while it runs, duration, folded detail and nested steps, with plan, queue and subagent presets. The ai-chat kit's Trace.

ContextUsagekit

How much of a model's context window a conversation has used: a ring and percent for a composer toolbar, with the used and maximum tokens, a bar, a breakdown and the cost in a popover. Built on the feedback Meter; the ai-chat kit's ContextUsage.

Overlays

14
Tooltip

Hint that appears on hover/focus. Wrap with TooltipProvider in root.

DropdownMenu

Context menu / action menu with sub-menus, separators, destructive items.

ContextMenu

Right-click menu. Same items as dropdown, different trigger.

Popover

Floating surface for inline edits, settings, quick forms.

HoverCard

Rich preview on hover — user profile, link previews, citation popovers.

Dialog

Declarative modal primitive (the primitives Dialog): focus-trapped, ESC closes, scroll lock. For modals that must stack, open from code or survive navigation, use Modal (managed) from the overlay kit.

AlertDialog

Critical confirmation modal — destructive actions, data loss warnings.

Sheet

Slide-in panel from any edge. Mobile menus, settings drawers.

Drawer

Bottom-sheet style drawer (the primitives Drawer: swipe to dismiss, snap points). Mobile-first.

Command

A filterable command list on the primitives' Autocomplete: groups of items with keyboard selection. The ⌘K dialog itself is CommandPalette from the overlay kit, which renders through this.

Overlaykit

Modal (managed): the overlay kit's modal engine. Stacks modals, sheets and drawers, opens them from code with open(), guards dirty forms and survives route changes. Use Dialog for a single declarative modal, this when modals stack or open from code.

CommandPalettekit

⌘K palette: fuzzy-search actions, navigate and run commands, inside the overlay stack. The overlay kit's CommandPalette, rendered through the ui Command primitive.

Affix

Content pinned to a viewport corner through a portal, clear of the safe-area insets, plus a BackToTop button that appears after scrolling.

Popconfirmkit

A small confirm anchored to the button that asked: focus on Cancel, Escape or a press outside cancels, async actions with a busy state and inline retry. The overlay kit's Popconfirm.

Feedback

11
Alert

Inline alert / callout — info, warning, danger, success.

Toast

Stacked notifications: typed, promise-based, hover and focus to expand and pause, F6 to reach them, swipe to dismiss, anchored to an element. The feedback kit's toaster (undo, positions, an inbox) builds on the same store.

EmptyStatekit

Icon, headline, one line of copy and the action that fills the space, in two sizes and an optional dashed frame; ResultPage is the whole-page 404 / 500 / success sibling. The feedback kit's EmptyState.

StatusDotkit

Status dot in six tones and four sizes, with a visible label or an aria-label, and a pulse for live states that stops under reduced motion. The display kit's StatusDot.

Kbdkit

A key binding drawn as key caps with the platform's glyphs (⌘K on macOS, Ctrl K elsewhere), fixed or detected by the provider. The keyboard kit's Kbd.

CodeBlockkit

Code with a title bar, language chip, copy button, line numbers and highlighted lines; CodeTabs holds several files in one frame. The display kit's CodeBlock.

Bannerkit

Full-width message strip in four tones, soft or solid, with actions and an optional dismiss. The feedback kit's Banner.

NotificationBellkit

Bell with an unread count that opens the inbox list: tabs, unread filter, mark all read. The feedback kit's NotificationBell and Inbox parts.

TopProgresskit

A thin bar along the top of the page while a route change or a long save is under way: a store (start, set, increment, decrement, done, reset) that trickles and never finishes on its own, a loading boolean for router adapters with a delay against flashes, aria-busy on the page and a polite one-time announcement, and a fixed partial width under reduced motion.

Spinnerkit

Loading ring in four sizes or three dots, announced as a status with its own label. The feedback kit's Spinner.

LoadingOverlaykit

Covers a region while it loads: dimmed or blurred, inert and aria-busy under a named spinner, its content kept mounted. The feedback kit's LoadingOverlay.

Data

22
Table

Bare-bones HTML table primitives — TableHeader, TableBody, TableRow, TableCell.

DataGridkit

Sortable, filterable, selectable grid with sticky header, pagination and per-row actions, on a data adapter (in-memory or server), with optional spreadsheet-style cell ranges (`cellSelection`), TSV copy and paste, undo of edits and grouped column headers (`columnGroups`). The datagrid kit's DataGrid; the full API lives on /kits/datagrid.

RadarChartkit

Radar (spider) chart comparing several metrics across series on plain SVG: polygon or circle grid, rings, stripes, fill and dots, highlight by axis with a tooltip, legend toggles, arrow-key reading and a table view. The charts kit's RadarChart; every chart lives on /kits/charts.

RadialBarChartkit

Concentric bars against one full sweep (the largest value or a goal) on plain SVG: faint tracks, rounded ends, a 0° to 270° default sweep, input order or sorted, labels at the bar starts or a legend, arrow-key reading and a table view. The charts kit's RadialBarChart.

GaugeChartkit

One value on a dial between a minimum and a maximum: a 240° sweep by default, coloured bands with a legend, the formatted value in the centre and a WAI-ARIA meter root. Its arc is the same drawing as the feedback kit's Meter.Ring and CircularProgress. The charts kit's GaugeChart.

FunnelChartkit

Conversion funnel on plain SVG: stages in their given order as joined trapezoids or centred bars, vertical or horizontal, labels with the value and the share of the first or previous stage, a tooltip with both, arrow-key reading and a table view. The charts kit's FunnelChart.

BarsListkit

Ranked list of horizontal bars in HTML ("top pages"): names and values as real text over tinted bars sized by share of the largest, sorted, limited with a count of the rest, optional column headers, and rows as links or buttons. The charts kit's BarsList.

FilterBar

Chip-based filter row — add filter, clear all, saved views.

BulkActionBar

Sticky action bar that appears when rows are selected — count + bulk verbs.

Timelinekit

Timeline of events: actor, verb, object and relative time, with icons and connectors. The display kit's Timeline.

TreeViewkit

Nested, collapsible tree with arrow-key navigation, ARIA tree roles, optional checkboxes and lazy-loaded children. The collections kit's TreeView.

FileTreekit

Folders and files on TreeView: built from a list of paths or your own nodes, folders first in natural order, the upload kit's icon per file kind, sizes and dates as the hint, Enter opens a file, and a folders-only picker; every TreeView feature (selection, checkboxes, lazy loading, filter, virtual rows) works unchanged. The collections kit's FileTree.

KanbanCard

Compact card for board columns — title, badges, assignee, due.

KanbanBoardkit

Columns by status (or priority) with KanbanCards. Drag tasks across columns to change status.

TaskListkit

Compact list of tasks — checkbox, title, status, priority, owner, due. Optional grouping.

TaskListBoardkit

Multiple TaskLists, drag-to-reorder, collapsible, add/delete. Things-style.

JsonViewerkit

Syntax-highlighted, collapsible JSON for API responses and configs, with parts and a preset. The display kit's JsonViewer.

LogViewerkit

Streaming log lines with level filters, timestamps, search and follow-tail. The terminal kit's LogViewer.

APIKeyCard

Reveal/copy/regenerate pattern for secret tokens. Mask by default.

VirtualListkit

Renders only the visible rows of a huge list, fixed or measured heights, with scrollToIndex. The collections kit's VirtualList.

ItemListkit

A selectable list of Item rows that can hold buttons and links: single or multiple selection, checkboxes, row actions with Left and Right, Enter or double click to act, typeahead, and a virtual window for 10,000 rows. The collections kit's ItemList, the grid pattern of React Aria's GridList.

SortableListkit

Reorder a list by pointer or keyboard, vertical or horizontal, with handles, pinned rows and announced moves. The dnd kit's SortableList.
