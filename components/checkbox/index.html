Props

Checkbox

A checkbox with an optional label and description beside it and opt-in sizes; the box is Checkbox.Root from

  • size"sm" | "lg"

    Opt-in box size, written as data-size; no size keeps today's box. sm and lg read --dk-checkbox-size-sm / --dk-checkbox-size-lg (box) and --dk-checkbox-mark-sm / --dk-checkbox-mark-lg (tick) with 14px / 20px and 12px / 16px as the Kitora values.

  • checkedboolean

    Whether the checkbox is checked (controlled).

  • defaultCheckedboolean

    Default false

    Whether the checkbox is checked at first (uncontrolled).

  • onCheckedChange(checked: boolean, eventDetails: ChangeDetails) => void

    Called when the user checks or unchecks the box, with the new state and the change details (details.cancel() vetoes).

  • indeterminateboolean

    Default false

    The mixed state: aria-checked="mixed" and data-indeterminate, in place of checked or unchecked.

  • parentboolean

    Default false

    This checkbox is the parent of the enclosing CheckboxGroup (which needs allValues): it ticks or clears every child.

  • disabledboolean

    Default false

    Whether the checkbox ignores user interaction.

  • readOnlyboolean

    Default false

    Whether the user cannot change the checkbox; it stays focusable.

  • requiredboolean

    Default false

    Whether the checkbox must be checked before its form submits.

  • namestring

    The form field name; a checkbox without one submits nothing.

  • valuestring

    Default "on"

    The form value submitted while checked.

  • uncheckedValuestring

    A value submitted while unchecked (a hidden input is rendered for it).

  • idstring

    The id of the hidden input, which is what a <label for> targets.

  • formstring

    The id of the <form> the hidden input belongs to, when the checkbox sits outside it.

  • inputRefReact.Ref<HTMLInputElement>

    A ref to the hidden input.

  • nativeButtonboolean

    Default false

    Whether the rendered element is a native <button> (set it true when render gives one).

  • labelReact.ReactNode

    Visible label text rendered in a <label htmlFor> next to the control.

  • descriptionReact.ReactNode

    More about the choice, rendered under the label and announced with the control (aria-describedby).

  • wrapperClassNamestring

    Classes for the wrapper <span> that holds the control, label and description (only with label or description).

  • labelClassNamestring

    Classes for the rendered <label> (only with label).

  • descriptionClassNamestring

    Classes for the description <span> (only with description).

Plus render, and className / style as functions of the part's state, and every <span> prop.

Design-language slot

slots.checkbox Checkbox (@kitora/ui/checkbox). The box is square; a checked or mixed box is filled with the primary colour, plus a sheen when fill is gradient.

  • size PxSide of the box (no size prop).
  • smallSize PxSide of the opt-in size="sm" box.
  • largeSize PxSide of the opt-in size="lg" box.
  • corner CornerThe box's corner.
  • surface PerScheme<Fill>The empty box's own fill per scheme; none shows the surface behind it.
  • edge PerScheme<Fill>The box's 1px edge per scheme while empty (a checked box's edge is primary); non-text UI wants 3:1 against the page.
  • fill ButtonFillFlat primary when checked, or a soft top-lit sheen over it (macOS).
  • elevation ElevationHow much the box lifts off the page.
  • markSize PxSide of the tick or dash drawn inside.
  • smallMarkSize PxSide of the tick or dash inside a size="sm" box.
  • largeMarkSize PxSide of the tick or dash inside a size="lg" box.
  • focusRing FocusRingThe keyboard-focus indicator.
