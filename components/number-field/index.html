NumberField

Locale-aware number input with steppers: Intl formatting, min / max / step (Shift and Alt for large and small), the arrow keys, press and hold, the wheel, a scrub area to drag a value, and a Field-aware label, description and error. The `NumberFieldControl` preset (commit on blur or Enter, steppers on or off, `name` posting the raw number) over the styled Base UI NumberField parts; the pickers kit's `NumberInput` renders them.

Source: @kitora/ui (the primitive the kits compose)

01Preset

NumberFieldControl is the group, the input and − / + steppers (out of the tab order) in one: typing commits on blur or Enter, the arrow keys step (Shift or PageUp for ten steps, Alt for a tenth), a percent steps by one percent, stepOnWheel steps with the wheel only while the input has focus, steppers={false} drops the buttons and labels names them.

Committed: 3

A percent steps by one percent; the wheel steps while the input has focus (stepOnWheel)
No steppers, a placeholder and your own stepper names (labels)

02Submits with a form

name posts the raw number, not the formatted text (1234.5 for "1.234,50 €"); required refuses the submit while the field is empty.

FormData: not submitted

03Parts

The parts the preset is made of: steppers, the arrow keys (Shift for ten steps, Alt for a tenth) and press and hold; the value stays inside min and max.

04Format and locale

format takes Intl.NumberFormat options and locale a tag: a German euro price, a percent, a unit. The raw number is what value and onValueChange carry; allowWheelScrub steps with the wheel while the input has focus.

Raw value of the first field: 1234.5. Arrows step, Shift takes ten steps, Alt a tenth; the wheel steps the speed while it has focus.

05Scrub area

Press the label and drag: the pointer is locked while you scrub and NumberFieldScrubAreaCursor follows it (the native cursor stays where the lock is refused).

Press the label and drag sideways to change the value.

06In a Field

The label names the input, the description is announced with it and required validates natively on blur.

Between 1 and 12. Clear the field and leave it to see the error.

07The pickers kit's NumberInput

NumberInput from @kitora/pickers/ui is this preset in the pickers' compact look (a 28px shell, 160px wide, 20px steppers) with its catalog's stepper names; the form kit's NumberField builds on its parts.

Props

NumberField

A number input with steppers: locale-aware typing and formatting (locale, format as Intl.NumberFormat options), min, max, step (Shift takes largeStep, Alt smallStep), the arrow keys, press and hold on the buttons, allowWheelScrub, and a NumberFieldScrubArea to drag a value. Works with Field: the label names the input, the description and the error are announced with it, and name submits the raw number. Compose NumberFieldGroup, NumberFieldInput, NumberFieldDecrement and NumberFieldIncrement inside it.

  • idstring

    The id of the input element.

  • minnumber

    The minimum value.

  • maxnumber

    The maximum value.

  • allowOutOfRangeboolean

    Default false

    Direct text entry may be outside min and max without clamping, so native range validation can report it. Steps still clamp.

  • smallStepnumber

    Default 0.1

    The step while Alt is held; the value snaps to multiples of it.

  • stepnumber | "any"

    Default 1

    The amount the buttons and arrow keys step, or a pixel of scrubbing is worth. "any" turns native step validation off.

  • largeStepnumber

    Default 10

    The step while Shift is held, and for PageUp and PageDown.

  • requiredboolean

    Default false

    Whether the user must enter a value before submitting a form.

  • disabledboolean

    Whether the field ignores user interaction.

  • readOnlyboolean

    Whether the user cannot change the value; it stays focusable.

  • namestring

    Identifies the field when a form is submitted.

  • formstring

    Identifies the form that owns the hidden input, for a field rendered outside it.

  • valuenumber | null

    The raw numeric value of the field.

  • defaultValuenumber | null

    The uncontrolled starting value.

  • allowWheelScrubboolean

    Default false

    Step with the mouse wheel while the input is focused and hovered.

  • snapOnStepboolean

    Default false

    Snap to the nearest step when stepping.

  • formatNumberFormatOptions

    Options to format the value (Intl.NumberFormat).

  • localeIntl.LocalesArgument

    The locale of the input. Defaults to the runtime's.

  • onValueChange(value: number | null, details: NumberFieldChangeEventDetails) => void

    Called when the value changes; details.reason says why (input-change, input-clear, input-blur, input-paste, keyboard, increment-press, decrement-press, wheel, scrub).

  • onValueCommitted(value: number | null, details: NumberFieldCommitEventDetails) => void

    Called when an interaction ends: the input blurs after typing, the pointer is released after a press or scrub, a key steps.

  • inputRefReact.Ref<HTMLInputElement>

    A ref to the hidden input.

  • formatterNumberFormatter

    The text <-> number adapter (Kitora): a domain format such as "1h 30m". Default Intl.

  • commitOnInputboolean

    Default true

    Commit while typing (Base UI). false commits on blur, Enter or a step only (Kitora).

  • clampOnBlurboolean

    Default !allowOutOfRange

    Whether blur holds the value inside min and max (Kitora).

  • snapGrid"amount" | "step"

    Default "amount"

    What snapOnStep snaps a step to: "amount" the multiples of the step taken (Base UI), "step" the step's own grid even for a large step (Kitora).

  • emptyStart"zero" | "bound"

    Default "zero"

    Where a step from an empty field starts: "zero" at max(0, min) (Base UI), "bound" at min going up and max going down (Kitora).

Plus render, and className / style as functions of the part's state, and every <div> prop.

NumberFieldControl

The number-input preset: the bordered group with the input and − / + steppers (out of the tab order: the input's arrow keys do the same; press and hold repeats), set up the way Kitora's number inputs always have been (numberFieldModelOptions: commit on blur or Enter, one percent per step for a percent format, Shift / PageUp for ten steps and Alt for a tenth, stepOnWheel only while the input has focus, locale, format, formatter, min, max, step, largeStep). name posts the raw number. The pickers kit's NumberInput renders this with its own look and its catalog's stepper names.

  • idstring

    The input's id (default generated).

  • namestring

    Submits the raw number (not the formatted text) under this name with a surrounding <form>.

  • formstring

    The form the number posts into.

  • requiredboolean

    A surrounding <form> refuses to submit while the field is empty.

  • placeholderstring

    Text shown in the input while it is empty.

  • steppersboolean

    Default true

    Whether to show the − / + steppers.

  • labelsPartial<NumberFieldLabels>

    The steppers' names; each one left out falls back to DEFAULT_NUMBER_FIELD_LABELS.

  • icons{ readonly increment?: React.ReactNode; readonly decrement?: React.ReactNode }

    The steppers' content; default a plus and a minus glyph.

  • classNamestring

    Classes for the root, merged after classNames.root.

  • classNamesPartial<Readonly<Record<NumberFieldControlPart, string>>>

    Default {}

    Classes for each part, by part name.

  • inputPropsNumberFieldControlInputProps

    Default {}

    Props for the input (extra handlers, autoFocus…); its onChange, onKeyDown and onBlur run after the field's own.

  • aria-labelstring

    The input's accessible name, when no Field label or aria-labelledby names it.

  • aria-labelledbystring

    The id of the element that names the input.

  • aria-describedbystring

    The ids of the elements that describe the input (help text, an error).

  • valuenumber | null

    The controlled value; null is a real "empty" value, undefined hands the state to the hook.

  • defaultValuenumber | null

    Initial value when uncontrolled. Default null (empty).

  • onValueChange(value: number | null) => void

    Every committed change (typing commits on blur or Enter; steps commit at once).

  • localestring

    BCP 47 locale for separators and formatting; default the host's.

  • formatNumberFormatOptions

    Intl options: { style: "currency", currency: "EUR" }, { style: "percent" }, { style: "unit", unit: "kilogram" }…

  • formatterNumberFormatter

    Text ↔ number adapter; default intlNumberFormatter.

  • minnumber
  • maxnumber
  • stepnumber

    Default 1, or 0.01 for style: "percent" (one percent).

  • largeStepnumber

    PageUp/PageDown and Shift+↑/↓; default step × {@link LARGE_STEP_FACTOR}.

  • disabledboolean
  • readOnlyboolean
  • stepOnWheelboolean

    Step with the mouse wheel while the input is focused. Default false.

  • commitOnInputboolean

    Commit while typing, like a native <input type="number">: every accepted keystroke whose text parses (or is empty) becomes the value at once, unclamped and without re-formatting the text; blur and Enter still round, clamp and re-format. For hosts that react to each keystroke (a form's live totals and validation). Default false (commit on blur or Enter only).

NumberFieldDecrement

The − stepper: a ghost icon button with a minus glyph (pass children to replace it). Press and hold repeats.

  • nativeButtonboolean

    Default true

    Whether the part renders a native <button>; set false when render gives another element.

Plus render, and className / style as functions of the part's state, and every <button> prop.

NumberFieldGroup

The bordered shell around the input and its buttons; it shows the focus ring when the input has focus.

Plus render, and className / style as functions of the part's state, and every <div> prop.

NumberFieldIncrement

The + stepper: a ghost icon button with a plus glyph (pass children to replace it). Press and hold repeats.

  • nativeButtonboolean

    Default true

    Whether the part renders a native <button>; set false when render gives another element.

Plus render, and className / style as functions of the part's state, and every <button> prop.

NumberFieldInput

The text input of the number field: a spinbutton.

Plus render, and className / style as functions of the part's state, and every <input> prop.

NumberFieldScrubArea

A label (or any element) that changes the value when pressed and dragged: the pointer is locked while it is, and NumberFieldScrubAreaCursor follows it.

  • direction"horizontal" | "vertical"

    Default "horizontal"

    The direction the pointer moves to change the value.

  • pixelSensitivitynumber

    Default 2

    How many pixels the pointer moves per change; higher is less sensitive.

  • teleportDistancenumber

    How far (px) the virtual cursor may go from the centre of the area before it wraps around; default the viewport.

Plus render, and className / style as functions of the part's state, and every <span> prop.

NumberFieldScrubAreaCursor

The cursor that replaces the pointer while a scrub area is dragged.

Plus render, and className / style as functions of the part's state, and every <span> prop.

Keyboard

  • ArrowUpNumberField.InputSteps the value up by `step` (`largeStep` with Shift, `smallStep` with Alt).
  • ArrowDownNumberField.InputSteps the value down by `step` (`largeStep` with Shift, `smallStep` with Alt).
  • PageUpNumberField.InputSteps the value up by `largeStep`.
  • PageDownNumberField.InputSteps the value down by `largeStep`.
  • HomeNumberField.InputSets the value to `min` (with no `min`, moves the caret as in any text field).
  • EndNumberField.InputSets the value to `max` (with no `max`, moves the caret as in any text field).

Accessibility

  • NumberField follows the WAI-ARIA Spinbutton pattern: roles spinbutton.

Hooks and functions

  • DEFAULT_NUMBER_FIELD_LABELS

    The English stepper names NumberFieldControl uses for any label labels leaves out.

  • renderWithFieldHandlersFirst({ onChange, onKeyDown, onBlur }: Pick<NumberFieldControlInputProps, "onChange" | "onKeyDown" | "onBlur">) => (props: React.ComponentProps<"input">) => JSX.Element

    A NumberFieldInput render that runs the field's own onChange, onKeyDown and onBlur first and then the host's, so a host handler sees the committed value (the primitives' parts run a caller's handlers first). NumberFieldControl's inputProps and the pickers kit's NumberInput.Input use it.
