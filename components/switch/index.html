Anatomy

Which part renders inside which in the examples above, from @kitora/ui/switch: each part's data-slot, the @kitora/primitives part it renders, its role, the state attributes it writes and the CSS variables it sets (style them with data-open:, data-checked: and the rest). Build your own builds the same thing from the parts alone.

    data-checkeddata-unchecked

      data-checkeddata-unchecked

Props

Switch

An on / off switch: Switch.Root from

  • size"sm" | "default" | "lg"

    Default "default"

    Track and thumb size. lg is opt-in; default is today's switch.

  • labelPositionChoiceLabelPosition

    Default "end"

    Where the label (and description) sit: after the switch (end, the default) or before it (start, a settings row).

  • thumbChildrenReact.ReactNode

    Content of the default thumb (an icon). Ignored when you pass your own SwitchThumb as children.

  • loadingboolean

    Default false

    A change is in flight: a spinner replaces the thumb's content, the switch is aria-busy and data-loading, and presses (pointer and keyboard) are refused through the change details' cancel(), so onCheckedChange is not called and an uncontrolled switch keeps its state. It stays focusable (unlike disabled) so focus is not lost.

  • childrenReact.ReactNode

    Your own thumb (<SwitchThumb>…</SwitchThumb>); without children the switch renders the default thumb.

  • checkedboolean

    Whether the switch is on (controlled).

  • defaultCheckedboolean

    Default false

    Whether the switch is on at first (uncontrolled).

  • onCheckedChange(checked: boolean, eventDetails: ChangeDetails) => void

    Called when the user turns the switch on or off, with the new state and the change details (details.cancel() vetoes).

  • disabledboolean

    Default false

    Whether the switch ignores user interaction.

  • readOnlyboolean

    Default false

    Whether the user cannot change the switch; it stays focusable.

  • requiredboolean

    Default false

    Whether the switch must be on before its form submits.

  • namestring

    The form field name; a switch without one submits nothing.

  • valuestring

    Default "on"

    The form value submitted while on.

  • uncheckedValuestring

    A value submitted while off (a hidden input is rendered for it); without it nothing is submitted while off.

  • idstring

    The id of the hidden input, which is what a <label for> targets.

  • formstring

    The form the input belongs to.

  • inputRefReact.Ref<HTMLInputElement>

    A ref to the hidden input.

  • nativeButtonboolean

    Default false

    Whether the rendered element is a native <button> (set it true when render gives one).

  • labelReact.ReactNode

    Visible label text rendered in a <label htmlFor> next to the control.

  • descriptionReact.ReactNode

    More about the choice, rendered under the label and announced with the control (aria-describedby).

  • wrapperClassNamestring

    Classes for the wrapper <span> that holds the control, label and description (only with label or description).

  • labelClassNamestring

    Classes for the rendered <label> (only with label).

  • descriptionClassNamestring

    Classes for the description <span> (only with description).

Plus render, and className / style as functions of the part's state, and every <span> prop.

SwitchThumb

The movable thumb. Switch renders one for you; render your own as the switch's child to put an icon in it (<Switch><SwitchThumb><MoonIcon /></SwitchThumb></Switch>), or pass thumbChildren to Switch. The icon is sized per switch size and coloured like the track when on, the muted foreground when off.

Plus render, and className / style as functions of the part's state, and every <span> prop.

Design-language slot

slots.switch Switch (@kitora/ui/switch): a pill track with a round thumb that slides.

  • widths PerSwitchSize<Px>Track width per size.
  • heights PerSwitchSize<Px>Track height per size.
  • thumbs PerSwitchSize<Px>Thumb diameter per size; it travels the track's inside width (width - 2 * SWITCH_BORDER) minus its own, so it must be narrower than that and no taller than height - 2 * SWITCH_BORDER.
  • track PerScheme<Fill>The off track's fill per scheme.
  • edge PerScheme<Fill>The off track's 1px edge per scheme (none for no visible edge); non-text UI wants 3:1 against the page.
  • trackOn FillThe on track's fill.
  • thumb PerScheme<Fill>The thumb's fill when off, per scheme.
  • thumbOn PerScheme<Fill>The thumb's fill when on, per scheme.
  • thumbElevation ElevationHow much the thumb lifts off the track.
  • focusRing FocusRingThe keyboard-focus indicator.
