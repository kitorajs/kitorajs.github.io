JsonViewer

A collapsible, searchable JSON tree with copy path and copy value on each row and the WAI-ARIA tree keys. Compose your own from JsonViewer.Root, Toolbar, Search, MatchCount, ExpandAll, CollapseAll, CopyAll, Tree and Row.

  • toolbarboolean

    Default true

    Show the search box and expand/collapse-all toolbar.

  • rootNamestring

    The name drawn for the root (response, $); none when omitted.

  • pathFormatJsonPathFormat

    Default "js"

    Path style for "Copy path": js ($.a[0]), pointer or jq.

  • maxHeightnumber

    Max height in px before the tree scrolls.

  • maxStringLengthnumber

    Default 120

    Collapse strings longer than this behind "…".

  • classNamestring

    Class for the frame.

  • classNamesJsonViewerClassNames

    A class per part: root, toolbar, search, tree, row.

  • valuerequiredJsonValue

    The JSON value to show.

  • defaultExpandDepthnumber

    Default 2

    Containers open on first render when uncontrolled, by depth (root = 0).

  • expandedReadonlySet<string>

    Controlled open containers, as path keys (pathKey(path)).

  • defaultExpandedReadonlySet<string>

    Open containers on first render when uncontrolled, as path keys; overrides defaultExpandDepth.

  • onExpandedChange(expanded: ReadonlySet<string>) => void

    Called when containers open or close, with the new set of open path keys.

  • querystring

    Controlled search text.

  • defaultQuerystring

    Default ""

    Search text on first render when uncontrolled.

  • onQueryChange(query: string) => void

    Called when the search text changes, with the new text.

  • onSelect(path: JsonPath, value: JsonValue) => void

    A row was chosen (click or Enter).

Hooks and functions

  • useJsonViewerContext() => JsonViewerContextValue

    The tree state of the nearest JsonViewer.Root; throws outside one.
