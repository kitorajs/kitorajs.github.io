BottomNav

The phone tab bar: 3 to 5 destinations as links along the bottom edge above the safe area, the current one marked by aria-current and more than a colour, count and dot badges with spoken labels, labels always or only on the current item, and hide on scroll. The shell kit's BottomNav parts and ShellBottomNav preset; AppShell draws it on phones from its bottomNav slot.

Source: @kitora/shell (the single implementation; no other package ships one)

Full API on the shell kit gallery

Anatomy

Which part renders inside which in the examples above, from @kitora/shell: each part's data-slot, the @kitora/primitives part it renders, its role, the state attributes it writes and the CSS variables it sets (style them with data-open:, data-checked: and the rest).

  • ShellBottomNav

Props

BottomNav.Root

The bar: a navigation landmark holding a list of BottomNav.Items.

  • aria-labelstring

    Default "Primary"

    The landmark's name.

  • labelsBottomNavLabels

    Default "always"

    always draws every label; active only the current item's (the others are still read).

  • hiddenboolean

    Default false

    Whether the bar is slid out of view (hide on scroll); it comes back when this is false.

  • childrenrequiredReactNode

    The BottomNav.Items.

Plus every HTML prop.

BottomNav.Item

One destination: an icon over a label, a link through the shell's link seam. Exactly 56 px tall (a 28 px icon pill, a 2 px gap, a 16 px label line and 4 px above and below), so the bar is BOTTOM_NAV_HEIGHT_PX with its border and the main region's padding fits.

  • hrefrequiredstring

    Where the destination links to.

  • iconrequiredReactNode

    The icon above the label.

  • labelrequiredstring

    The destination's name, drawn under the icon (or only read, per labels).

  • badgenumber | boolean

    A count, or true for a dot, on the icon.

  • badgeLabelstring

    What a screen reader hears for the badge ("3 unread").

  • activeboolean

    Default false

    Whether this is the current destination (aria-current="page").

  • renderLinkRenderShellLink

    Draws the link; default the shell's renderer (a plain <a> outside a shell).

  • classNamestring

    Extra classes on the item.
