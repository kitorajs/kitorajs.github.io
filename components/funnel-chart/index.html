FunnelChart

Conversion funnel on plain SVG: stages in their given order as joined trapezoids or centred bars, vertical or horizontal, labels with the value and the share of the first or previous stage, a tooltip with both, arrow-key reading and a table view. The charts kit's FunnelChart.

Source: @kitora/charts (the single implementation; no other package ships one)

Full API on the charts kit gallery

Built fromChartFrame · chartsLiveRegion · chartsTooltipBox · charts

01Default

label and value per stage, in the order given. Hover a stage, or focus the plot and use the arrow keys: the tooltip shows its value, its share of the first stage and of the previous step.

02Orientation

orientation="horizontal" reads from the inline start, names under the stages; the default vertical funnel puts the first stage on top.

03Shape and gap

shape="bars" draws centred bars with no joins; gap sets the space between stages.

04Labels

labels shows the value, the percent, both or none; percentOf picks the first or the previous stage for that percent.

05Colours

One colour darkening by step by default, each stage its own slot with colorBy="stage", or any colour from color.

06Download as SVG or PNG

exportFormats adds a download button per format before the Table toggle; the file carries the title and the legend, so it stands alone outside the page.

07Funnel report card

A FunnelChart in a ui Card with a Badge for the overall conversion and a Separator above the footnote.

Props

FunnelChart<T>

A conversion funnel. Hover or arrow keys pick a stage; the tooltip shows its value, % of the first and % of the previous step.

  • datarequiredreadonly T[]

    The stages, in order; never sorted (a stage larger than the one before it is drawn as it is).

  • labelrequired(row: T) => string

    Reads a stage's name.

  • valuerequired(row: T) => number

    Reads a stage's count; negative values count as zero.

  • color(row: T, index: number) => string

    Per-stage colour; default one palette slot darkening by step (or each stage's slot with colorBy="stage").

  • colorBy"step" | "stage"

    Default "step"

    step shades one colour darker per stage; stage gives each stage its own categorical slot.

  • titlerequiredstring

    The chart's name; shown in the header and used as the accessible name and table caption.

  • orientation"vertical" | "horizontal"

    Default "vertical"

    vertical puts the widest stage on top; horizontal reads from the inline start.

  • shapeFunnelShape

    Default "funnel"

    funnel joins each stage to the next as a trapezoid; bars draws centred bars with no joins.

  • gapnumber

    Default 2

    The space between stages in pixels.

  • labelsFunnelLabels

    Default "both"

    What each stage's label shows: the value, the percent, both, or nothing.

  • percentOf"first" | "previous"

    Default "first"

    What the label's percent is a share of; the tooltip and the table always show both.

  • formatValue(value: number) => string

    Formats values in the labels, the tooltip, the live region and the table. Default: the formats adapter's number.

  • heightnumber

    Default 260

    Plot height in pixels.

  • tooltipboolean

    Default true

    Whether to show the tooltip for the active stage.

  • renderTooltip(readout: Readout, index: number) => ReactNode

    Replaces the tooltip's content; given the readout and the active stage's index.

  • onActiveChange(index: number | null) => void

    Called as the reader moves between stages (pointer or keyboard), with the stage's index; null when they leave.

  • hideTitleboolean

    Whether to hide the title visually; screen readers still hear it.

  • descriptionReactNode

    One sentence under the title.

  • summarystring

    Screen reader summary; each chart has an automatic one.

  • tableToggleboolean

    Default true

    Whether to show the "Table" toggle in the header. The hidden table for screen readers is always there.

  • animateboolean

    Whether marks animate in; on unless false (the reader's reduced-motion setting still wins).

  • classNamestring

    Classes added to the figure element.

  • classNamesChartClassNames

    Extra classes per frame part.

  • actionsReactNode

    Extra header controls (a range picker, a mode switch), placed left of the Table toggle.

  • exportFormatsreadonly ChartExportFormat[]

    Default []

    Download buttons in the header, one per format, before the Table toggle (Chart.Export); none unless set.

  • showTableboolean

    Show the table instead of the plot (controlled).

  • defaultShowTableboolean

    Default false

    Whether the table shows at first (uncontrolled).

  • onShowTableChange(showTable: boolean) => void

    Called when the reader switches between plot and table, with true for the table.

  • activeIndexnumber | null

    The active row index, null for none (controlled).

  • defaultActiveIndexnumber | null

    The active row at first (uncontrolled); null for none.

  • onActiveIndexChange(index: number | null) => void

    Called when the active row changes, with its index or null when the reader leaves.
